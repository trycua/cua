# Provenance: MB-11

**Read a native tooltip and type its code.** An original Cua task, written for this benchmark (first committed
2026-10-05). It runs in BenchLab, the test app in [`../../swift`](../../swift), and
is checked by [`evaluate.py`](evaluate.py) from the app's own state and event
log.

* **Author:** Cua AI, Inc. The task, its brief, its seeded data, the BenchLab
  mode it uses and its checker are original. Names, values and labels are
  generated from the trial seed or invented.
* **Sources:** none. No task text, data, code or asset comes from another
  benchmark, a third party or a customer corpus. BenchLab uses system fonts
  only and draws its icons in code.
* **Related work:** Reading a tooltip is a generic GUI primitive. No public benchmark task matched.
* **Review:** a Cua similarity review on 2026-10-10 compared the BenchLab
  tasks with public desktop, web and terminal benchmarks (OSWorld, OSWorld 2.0
  from its paper, WindowsAgentArena, macOSWorld, Mac Agent Bench, Hunch Bench,
  Terminal-Bench and others) and found no near-copy or structural copy.
