## `cua-driver check-update`

Check whether a newer cua-driver release is available.

Read-only. Uses the same update-state payload as the check_for_update MCP tool.

```text output
cua-driver check-update [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-driver-check-update--json"></span>`--json` | boolean | `false` | Emit a machine-readable JSON payload. |
| <span id="cua-driver-check-update--no-cache"></span>`--no-cache` | boolean | `false` | Skip the 20-hour on-disk cache and force a GitHub request. |

**Examples**

```bash test="cli-shape" id="ref-cua-driver-check-update"
# Check for a newer release
cua-driver check-update

# Check now, as JSON
cua-driver check-update --json --no-cache
```

## `cua-driver update`

Check for an update and optionally apply it.

The apply path delegates to the canonical platform installer scripts.

```text output
cua-driver update [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-driver-update--apply"></span>`--apply` | boolean | `false` | Download and install the latest release when one is available. |
| <span id="cua-driver-update--json"></span>`--json` | boolean | `false` | Emit the structured update-state payload. |

**Examples**

```bash test="cli-shape" id="ref-cua-driver-update"
# Check and print the install command
cua-driver update

# Install the latest release
cua-driver update --apply
```

## `cua-driver channel`

Inspect or change the stable/nightly update channel.

Selection is persistent but never installs by itself; use cua-driver update --apply after changing it.

```text output
cua-driver channel [COMMAND]
```

Without a subcommand, runs `cua-driver channel status`.

**Examples**

```bash test="cli-shape" id="ref-cua-driver-channel"
# Show the selected release channel
cua-driver channel
```

### `cua-driver channel set`

Save stable or nightly as the update channel.

```text output
cua-driver channel set [OPTIONS] <channel>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<channel>` | string | required | Release channel: stable or nightly. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-driver-channel-set--json"></span>`--json` | boolean | `false` | Emit machine-readable channel state. |

**Examples**

```bash test="cli-shape" id="ref-cua-driver-channel-set"
# Follow nightly builds (then run update --apply)
cua-driver channel set nightly
```
