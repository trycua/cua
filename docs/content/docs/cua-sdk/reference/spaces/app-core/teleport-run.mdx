`app_teleport_run_event` maps one `Teleport.run` event for the picker, `app_teleport_run_status` sums a run's events into its status line, and `app_picker_status` says what the picker is doing.

## `app_picker_status`

What the run is doing, in words ("Packing profile", "Uploading 12 /
80 MB"), for the line under the progress bar; none unless running.
