## `teleport_browser_session`

Teleport the user's signed-in session for specific sites (for example github.com) from their Firefox or Chrome into a sandbox, through the Cua Keyvault. Name each site: nothing is selected by default and there is no all-sessions option. The first call moves nothing: it files a Keyvault request and returns consent_required, a summary and a request_id. Show the summary to the user; they approve it in Cua (Touch ID or password). Then call again with the request_id to move exactly those sites. Use it only when the user asks to browse as themselves.

Permission: `teleport:browser`.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="teleport_browser_session--browser"></span>`browser` | `"firefox" \| "chrome"` | required | firefox or chrome (chromium, brave and edge profiles use chrome). |
| <span id="teleport_browser_session--duration_minutes"></span>`duration_minutes` | `integer` |  | How long the sandbox may keep them (default 15, at most 1440). |
| <span id="teleport_browser_session--name"></span>`name` | `string` | required | Sandbox ref (local:&lt;name&gt;, cloud:&lt;name&gt;, direct:&lt;host:port&gt;) or a name unique across locations. |
| <span id="teleport_browser_session--reason"></span>`reason` | `string` |  | Why, in a few words; shown to the user as unverified. |
| <span id="teleport_browser_session--request_id"></span>`request_id` | `string` |  | The request_id from the first call, after the user approved it in Cua. |
| <span id="teleport_browser_session--sites"></span>`sites` | `string[]` | required | The exact sites to teleport, for example ["github.com"]. |

**Example arguments**

```json
{"name":"<name>","browser":"firefox","sites":["<site>"]}
```
