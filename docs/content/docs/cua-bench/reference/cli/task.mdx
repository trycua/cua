## `cb task generate`

Generate a task from a prompt using Claude.

```text output
cb task generate [OPTIONS] <prompt> [<output>]
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<prompt>` | string | required | Natural language description of the task to generate (e.g., "2048 game"). |
| `<output>` | string | optional | Output directory (default: named after the prompt). |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cb-task-generate--no-interaction"></span>`--no-interaction` | boolean | `false` | Skip interactive prompts and run Claude non-interactively. |

**Examples**

```bash test="cli-shape" id="ref-cb-task-generate"
# Generate a task
cb task generate '2048 game'

# Generate into a directory without prompts
cb task generate 'Sort a spreadsheet column' ./tasks/sort_column --no-interaction
```
