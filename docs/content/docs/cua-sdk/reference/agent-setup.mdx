## `AgentInfo` record

One AI coding agent and what cua configured for it.

Returned by [`AgentSetup.detect`](#agentsetup), [`AgentSetup.status`](#agentsetup).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `String` |  | Registry id (`claude-code`, `codex`, `cursor`, ...). |
| `name` | `String` |  | Display name. |
| `installed` | `bool` |  | Whether it looks installed. |
| `evidence` | `Vec<String>` |  | What gave it away (`bin:<path>`, `path:<dir>`, `app:<bundle>`). |
| `skills_dir` / `skillsDir` | `Option<String>` |  | User skills directory, when the agent supports Agent Skills. |
| `mcp_config` / `mcpConfig` | `Option<String>` |  | User MCP config file, when the agent supports MCP. |
| `mcp_format` / `mcpFormat` | `Option<String>` |  | `json`, `toml` or `yaml`. |
| `cua_configured` / `cuaConfigured` | `bool` |  | A `cua` MCP server launching a cua binary is configured. |
| `cua_managed` / `cuaManaged` | `bool` |  | That entry is the one cua wrote. |
| `cua_driver_configured` / `cuaDriverConfigured` | `bool` |  | A `cua-driver` MCP server (background computer-use) is configured. |
| `skills_installed` / `skillsInstalled` | `Vec<String>` |  | Bundled skills present in the skills directory. |
| `skills_outdated` / `skillsOutdated` | `Vec<String>` |  | Installed bundled skills that differ from this SDK's copy. |
| `error` | `Option<String>` |  | Problem reading the MCP config (for example a malformed file). |
| `unverified` | `Option<String>` |  | What could not be verified from the agent's official docs. |
| `sign_in` / `signIn` | `Option<String>` | `None` | The account the agent signs in with on its own (`ChatGPT` for Codex), when cua can see that sign-in. |
| `signed_in` / `signedIn` | `bool` | `false` | That sign-in is on this computer. |

## `AgentMcpServer` record

The MCP server to register.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
