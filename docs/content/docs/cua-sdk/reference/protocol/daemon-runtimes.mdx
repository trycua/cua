### RuntimeService.Doctor

`/cua.daemon.v1.RuntimeService/Doctor`, unary: [`DoctorRequest`](#doctorrequest) to [`DoctorResponse`](#doctorresponse).

Inspects local runtimes (Lume, QEMU, container engine, runsc) without
changing anything.

### RuntimeService.Setup

`/cua.daemon.v1.RuntimeService/Setup`, unary: [`SetupRequest`](#setuprequest) to [`SetupResponse`](#setupresponse).

Installs or starts missing local runtime components. Every step is
explicit and logged in the response.

### RuntimeService.PullImage

`/cua.daemon.v1.RuntimeService/PullImage`, unary: [`PullImageRequest`](#pullimagerequest) to [`PullImageResponse`](#pullimageresponse).

Pulls an image into the local cache or container engine.

### RuntimeService.BuildImage

`/cua.daemon.v1.RuntimeService/BuildImage`, unary: [`BuildImageRequest`](#buildimagerequest) to [`BuildImageResponse`](#buildimageresponse).

Builds an image from an `images.cua.ai/v1alpha1` Image resource.

### RuntimeService.PushImage

`/cua.daemon.v1.RuntimeService/PushImage`, unary: [`PushImageRequest`](#pushimagerequest) to [`PushImageResponse`](#pushimageresponse).

Copies an image (host architecture) to another registry reference.
