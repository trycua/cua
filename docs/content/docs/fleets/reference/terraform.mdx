The `trycua/fleets` provider manages Fleet pools. Install it from the Terraform Registry with `terraform init`; OpenTofu works the same with `tofu`.

```hcl
terraform {
  required_providers {
    fleets = {
      source = "trycua/fleets"
    }
  }
}
```

## Provider arguments

Use either `access_token`, or all three of `client_id`, `client_secret` and `token_url` (an [API key](/fleets/reference/api-key)). An argument wins over its environment variable.

| Argument | Type | Default | Environment variable | Description |
| --- | --- | --- | --- | --- |
| `endpoint` | `string` | required | `CYCLOPS_ENDPOINT` | Fleet API base URL, for example `https://run.cua.ai`. |
| `access_token` | `string` | none | `CYCLOPS_ACCESS_TOKEN` | Bearer token. Sensitive. |
| `client_id` | `string` | none | `CYCLOPS_CLIENT_ID` | Fleet user-key client ID. |
| `client_secret` | `string` | none | `CYCLOPS_CLIENT_SECRET` | Fleet user-key client secret. Sensitive. |
| `token_url` | `string` | none | `CYCLOPS_TOKEN_URL` | OAuth token endpoint returned with the Fleet user key. |

`CUA_CLIENT_ID`, `CUA_CLIENT_SECRET`, `FLEETS_TOKEN` and `cua auth login` do not configure the provider.

## Resources

| Resource | Manages | Reference |
| --- | --- | --- |
| `fleets_pool` | A Cua Fleet computer-use pool: an OSGymSandboxWarmPool and its OSGymSandboxTemplate. The pool name also owns its same-named namespace. | [Pool](/fleets/reference/pool#terraform) |
