## `KeyvaultClient`

The Keyvault broker client: the verified connection to the broker
`cua daemon` hosts on `$CUA_HOME/keyvault.sock`. The broker checks this
process's code signature; approvals, re-enabling and unattended-on make
the daemon ask for Touch ID. No call returns a secret value.

| Method | Description |
| --- | --- |
| [`new`](#keyvaultclientnew) | The broker in `cua_home` (`None`: `$CUA_HOME`, else `~/.cua`). |
| [`execute`](#keyvaultclientexecute) | Runs one page action (a broker request). |
| [`favicons`](#keyvaultclientfavicons) | Site icons the vault holds (not secret; empty while names are hidden). |
| [`inventory`](#keyvaultclientinventory) | What `app` holds, per domain with counts (the daemon asks for Touch ID when the browse window is closed). |
| [`lock`](#keyvaultclientlock) | Locks the vault. |
| [`overview`](#keyvaultclientoverview) | Everything the page shows. |
| [`setup_with_passphrase`](#keyvaultclientsetup_with_passphrase) | Creates the vault with a passphrase (and a recovery key, returned once). |
| [`unlock_with_passphrase`](#keyvaultclientunlock_with_passphrase) | Unlocks with the passphrase (sent only to the broker; zeroized here). |

| `Unlock` | Unlock with the OS key store (a passphrase goes to `KeyvaultCommands::unlock_with_passphrase`). |
| `SetDisabled` | The kill switch (turning it off asks for Touch ID). Fields: `disabled: bool` |
| `SetUnattended` | Per-item unattended (turning on asks for Touch ID): the same as `KvCommand.SetLocked` with `locked` the other way round. Fields: `item_ids: Vec<String>`, `unattended: bool` |
| `SetLocked` | Lock or unlock items together. Unlocking allows unattended access and asks for Touch ID once for the whole batch; locking does not. Fields: `item_ids: Vec<String>`, `locked: bool` |
| `DeleteItems` | Delete items, wiping every live copy of them in Spaces. Fields: `item_ids: Vec<String>` |
| `SetSkipUnlockPrompt` | "Never ask again" on the unlock prompt (Settings turns it back on). Fields: `on: bool` |
| `Browse` | Show item names for a few minutes (the daemon asks for Touch ID). |
| `EndBrowse` | Hide item names again. |
| `RevokeGrant` | Revoke a grant (`*`: all). Fields: `id: String` |
| `RemoveRule` | Remove a rule. Fields: `id: String` |
| `SetAutoWipe` | Auto-wipe of delivered copies (turning it off asks for Touch ID). Fields: `on: bool` |
| `Release` | Wipe a Space's copies. Fields: `target: String` |
| `Approve` | Approve a request for exactly these items (the daemon asks for presence). `None` keeps everything the request asked for, which the approval sheet only sends when the user ticked every row. Fields: `request_id: String`, `items: Option<Vec<String>>` |
| `Deny` | Deny a request. Fields: `request_id: String` |
