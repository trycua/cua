## `cua host setup`

Set this machine up for unattended access: install cua-spacesd as a service that joins the cua.ai relay as your account (default) or serves on a direct ip:port.

```text output
cua host setup [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-host-setup--relay"></span>`--relay` | string |  | Relay URL (default $CUA_RELAY_URL, else https://relay.cua.ai). |
| <span id="cua-host-setup--direct"></span>`--direct` | string |  | Serve directly on ip:port with a local env token (LAN / port-forwarded) instead of joining a relay. |
| <span id="cua-host-setup--name"></span>`--name` | string |  | Display name (default: the host name). |
| <span id="cua-host-setup--allow"></span>`--allow` | string |  | Also allow this account (id or email). Repeatable. |
| <span id="cua-host-setup--driver-bin"></span>`--driver-bin` | path |  | cua-spacesd binary (default $CUA_SPACESD_BIN, a bundled one, or the release download). |
| <span id="cua-host-setup--runner"></span>`--runner` | string | `auto` | auto \| systemd \| launchd \| windows-task \| process. |
| <span id="cua-host-setup--profile"></span>`--profile` | `desktop` \| `spare` | `desktop` | What this machine is for: `desktop` (share this desktop; the default) or `spare` (do not share the desktop; provide Spaces). |
| <span id="cua-host-setup--max-spaces"></span>`--max-spaces` | integer |  | Provided Spaces at once (default 4; 0: no limit). |
| <span id="cua-host-setup--desktop"></span>`--desktop` | boolean | `false` | Share this machine's own desktop as a Space. |
| <span id="cua-host-setup--no-desktop"></span>`--no-desktop` | boolean | `false` | Do not share this machine's own desktop (screen, input, shell, files): relayed callers reach only the Spaces it provides. |
| <span id="cua-host-setup--provide-spaces"></span>`--provide-spaces` | boolean | `false` | Create Spaces for your enrolled devices on this machine's runtimes (Lume macOS VMs, Docker Linux containers). |
| <span id="cua-host-setup--no-provide-spaces"></span>`--no-provide-spaces` | boolean | `false` | Do not create Spaces for other devices. |
| <span id="cua-host-setup--allow-any-address"></span>`--allow-any-address` | boolean | `false` | With --direct and Spaces: take host calls, and connections to the Spaces this machine forwards, from any address (and allow a public --direct address). By default only loopback, Tailscale and private LAN addresses may. The direct listener is plaintext and its token is a shell on this machine: prefer Tailscale. |

**Examples**

```bash test="cli-shape" id="ref-cua-host-setup"
# Join the cua.ai relay as your account (shares this desktop)
cua host setup

# A spare machine: do not share its desktop, run Spaces for your devices
cua host setup --profile spare --name "Mac mini (spare)"
cua host setup --no-desktop --provide-spaces

# Serve on the LAN instead of the relay
cua host setup --direct 0.0.0.0:3211 --name studio-mac

# A spare Mac on your tailnet that runs Spaces, without the relay (prints the command that adds it on your laptop)
cua host setup --direct 100.101.102.103:3211 --profile spare
```

## `cua host config`

Show or change what this machine shares: its own desktop, and whether it creates Spaces for your other devices.

```text output
cua host config [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-host-config--desktop"></span>`--desktop` | `on` \| `off` |  | Share this machine's own desktop: on \| off. |
| <span id="cua-host-config--provide-spaces"></span>`--provide-spaces` | `on` \| `off` |  | Create Spaces for your enrolled devices: on \| off. |
| <span id="cua-host-config--max-spaces"></span>`--max-spaces` | integer |  | Provided Spaces at once (0: no limit). |
| <span id="cua-host-config--max-macos-vms"></span>`--max-macos-vms` | integer |  | macOS VMs at once, 0 to 2 (Apple's license allows two per Mac). |

**Examples**

```bash test="cli-shape" id="ref-cua-host-config"
cua host config

# Stop sharing this desktop; keep providing Spaces
cua host config --desktop off --provide-spaces on
cua host config --max-spaces 6
```

## `cua host share`

Share a relay machine (this one, or `--machine`) with other cua.ai accounts (id or verified email). Run from an enrolled device; every change is in the owner's audit log (`cua devices audit`).

```text output

```

| Flag | Type | Default | Description |

| <span id="cua-host-share--relay"></span>`--relay` | string |  | Relay URL (default: the one this machine joined, else $CUA_RELAY_URL / https://relay.cua.ai). |


| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-host-remove--force"></span>`--force` | `-f` | boolean | `false` | Skip the confirmation prompt. Required when there is no terminal to ask on (scripts, agents): without it nothing is removed. |

**Examples**

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
