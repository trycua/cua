A persistent agent keeps its harness memory in its home in the Cua Volume (`agents/<name>/`). The daemon restores the home before each run, saves it after each turn, fires routines with or without an app open, and posts notifications. See [Persistent agents](/spaces/guides/persistent-agents).

## `PersistentAgentInfo` record

A persistent agent: a named harness whose memory (its home in the Cua
Drive) outlives its runs and its Space.

Returned by [`Spaces.persistent_agent_create`](#spacespersistent_agent_create), [`Spaces.persistent_agent_remove`](#spacespersistent_agent_remove), [`Spaces.persistent_agents`](#spacespersistent_agents).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `String` |  |  |
| `harness` | `String` |  | Harness id. |
| `space` | `String` |  | The Space it works in. |
| `model` | `Option<String>` |  |  |
| `base_url` / `baseUrl` | `Option<String>` |  |  |
| `env_from_host` / `envFromHost` | `Vec<String>` |  |  |
| `paused` | `bool` |  |  |
| `space_state` / `spaceState` | `String` |  | `running`, `suspended` (a paused local Space) or `released` (a paused cloud Space). |
| `run_id` / `runId` | `Option<String>` |  | The current run. |
| `saved_ms` / `savedMs` | `u64` |  | Unix ms of the last home save. |
| `created_ms` / `createdMs` | `u64` |  |  |
| `last_error` / `lastError` | `Option<String>` |  |  |

## `PersistentAgentOptions` record

How to create a persistent agent.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `model` | `Option<String>` | `None` |  |
| `base_url` / `baseUrl` | `Option<String>` | `None` |  |
| `env_from_host` / `envFromHost` | `Vec<String>` | `[]` | Provider key variables forwarded from the host's environment at each start. |
| `env` | `HashMap<String, String>` | `[:]` | More environment for every run (not secrets). |
