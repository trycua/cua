The Cua Sandbox SDK represents one isolated computer. It can run locally or on
Cua Fleet capacity. Cua Fleets adds hosted pools, claims, authentication, and
service routing so workloads can reserve and use managed cloud computers.

Start with [Your first Cloud Fleet](/tutorials/your-first-cloud-fleet) to provision
a pool, transform a file, verify the result, and clean up the cloud resources.

## One claim, one cloud computer

With Fleet, the SDK connects to a claimed cloud guest. Shell commands and GUI
actions through that sandbox act inside the guest. A pool owns reusable hosted
capacity; a claim reserves one computer from that capacity for a workload.
Declared guest services provide the connection routes the client needs. See
[Pools, claims, and guest services](/concepts/pools-claims-and-guest-services)
for the hosted model.

Looking for execution on your own hardware? Start with
[Local Sandboxes](/local-sandboxes). Its setup and lifecycle are separate from
hosted Fleet credentials, claims, and capacity.

Fleet manages capacity; the Sandbox SDK acquires and uses a guest. The SDK's
default guest endpoint is computer-server. Cua Driver can control the desktop
where it is installed and targeted, but using it inside a Fleet guest requires
a compatible image and a validated connection path. Choosing a Fleet image does
not by itself establish Driver integration. Check the [image and runtime limits](/reference/sandbox-sdk/runtime-support)
before selecting your environment.

## Claims and capacity have separate lifetimes

Exiting a `pool.claim()` context releases the claim. The pool can still retain
warm sandboxes, and cloud resources can incur usage charges after your workload
finishes. The hosted tutorial removes its dedicated Fleet resources; reusable
pools need an explicit cleanup or expiry policy. See [Pool lifecycle](/reference/sandbox-sdk/pool)
for connection and release semantics, and [Expire pools and claims automatically](/how-to-guides/sandbox/expire-pools-and-claims)
for deadlines and their effect on active work.
