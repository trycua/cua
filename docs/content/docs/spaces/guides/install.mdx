Cua Spaces runs on macOS, Windows (preview) and Linux. One command installs the
`cua` CLI and the app. The [download page](https://cua.ai/download) has the
app for each system, and every installer is attached to the
[GitHub releases](https://github.com/trycua/cua/releases).

| System | Needs |
|---|---|
| macOS | macOS 26 or later |
| Windows (preview) | Windows on x64 or Arm |
| Linux | Ubuntu 24.04 on x64 or arm64 for the supported package. Other distributions and desktops are untested. |

<Tabs items={['macOS', 'Windows (preview)', 'Linux']}>
  <Tab value="macOS">
    ```bash skip="host-install"
    curl -fsSL https://cua.ai/install.sh | sh
    ```

    Or open the universal `.dmg` (or `.pkg`) from the release.
  </Tab>
  <Tab value="Windows (preview)">
    <Callout type="warn">
      Cua Spaces for Windows is a preview. Expect rough edges and tell us what
      you hit.
    </Callout>

    ```powershell skip="host-install"
    irm https://cua.ai/install.ps1 | iex
    ```

    Or run `cua-spaces-<version>-windows-x64-setup.exe` (`windows-arm64` on Arm)
    from the release. Windows may show a SmartScreen prompt the first time:
    choose **More info**, then **Run anyway**.
  </Tab>
  <Tab value="Linux">
    ```bash skip="host-install"
    curl -fsSL https://cua.ai/install.sh | sh
    ```

    The installer picks the supported **.deb** on Ubuntu 24.04. To install it by
    hand, run `sudo apt install ./cua-spaces_<version>_<arch>.deb`. See
    [Linux packages](#linux-packages).
  </Tab>
</Tabs>

At a console the installer shows a checklist first. Add `--cli-only`
(`-CliOnly` on Windows) to install the CLI alone. Other flags are `--select`,
`--only`, `--app-only`, `--mode host|client`, `--version`, `--no-onboarding`,
`--dry-run` and `--yes` (`-Select`, `-CliOnly` and so on on Windows).

## First run

The first time you open the app, it walks you through a few screens. You can
skip most of them and change every choice later in **Settings**.

| Screen | What it does |
|---|---|
| Welcome | Starts the setup. |
| Command line | Installs the `cua` command and adds it to your PATH. It shows only when the command is missing or out of date. |
| Where should Cua Spaces show up? | Chooses how the app appears, for example the notch and menu bar, or the menu bar only. |
| Sign in | Signs you in to reach your computers from other devices. You can skip it. |
| AI agents | Gives your coding agents the `cua` skills and MCP server. See [Connect your agent](/spaces/guides/connect-your-agent). |
| This machine | Chooses between reaching other machines, and setting this one up so your other devices can reach it ([Add a computer](/spaces/guides/add-a-computer)). |
| You're all set | Offers a first Space and three prompts to try with your agent. |

Cua Spaces launches at login by default, so the Spaces this computer provides
and your persistent agents come back after a restart. Turn it off in **Settings,
General**.

## Linux packages

The supported package is the **.deb** on Ubuntu 24.04. It is sandboxed and
installs the confirmation prompt the Keyvault needs. `sudo apt remove cua-spaces`
turns off what the app set up (see
[Check, pause or remove](/spaces/guides/add-a-computer#check-pause-or-remove)).

The **AppImage** is a portable build, not a supported one. It cannot use the
browser sandbox (it starts with `--no-sandbox`), and without the system's
confirmation prompt the Keyvault is unavailable. Use it to try Cua Spaces
without installing, and install the .deb to keep it.

For Linux Spaces created on this computer, the `cua` CLI uses Docker (gVisor
`runsc`, when installed, adds isolation) or QEMU. QEMU needs read and write
access to `/dev/kvm` to run same-architecture guests quickly. Run
`cua runtime doctor` to see what this computer has.

## Updates

Cua Spaces checks for new versions and downloads them in the background on
macOS, Windows and Linux. The settings are in **Settings, About**, which also
shows your version.

The app checks when it starts and again every few hours. When a new version is
ready, **Update ready** appears at the bottom of the sidebar, with **Restart to
update** and a **What's new** link to the release notes. Nothing restarts until
you click. If an agent is still working, the app asks first.

In **Settings, About**:

- **Check for and download updates automatically** turns the background checks on
  or off. With it off, press **Check Now** to check by hand.
- **Install a downloaded update when Cua Spaces quits** installs a downloaded
  update when you quit the app. It needs automatic checks.
- **Last check** says when the app last looked.

On macOS, every update is the same notarized disk image as the download on the
release page, and the app installs it only when its signature matches the key
built into the app. Windows and Linux update through their own updater.

### Stable or Beta

**Update to:** picks the channel.

- **Stable**: tested releases.
- **Beta**: releases and prereleases, with new features sooner and rough edges.

Going back to Stable from a newer beta keeps the version you have until a newer
stable release is out.

### After an update

The first time the new version opens, it refreshes what Cua installed into your
AI agents, the way `cua agents update` does: the Cua skill folders and the Cua
MCP entries in Claude Code, Cursor and the other agents you set up. A skill
folder you edited is left as you left it. It also restarts the Cua daemon when
the app started it, so the daemon runs the new version too.

This happens without any window. If something fails, the app shows one notice
with what to run.
