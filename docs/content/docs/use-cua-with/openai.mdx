OpenAI Codex supports local MCP servers in its CLI, IDE extension, and desktop app. Register Cua Driver once, then use its tools from a Codex session.

| Start here when…                           | Recommended path                                                                               |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| You use Codex                              | [Connect Codex to Cua Driver](/use-cua-with/codex)                                             |
| You use another MCP-capable OpenAI harness | [Use the generic MCP configuration](/how-to-guides/driver/connect-your-agent#generic-mcp-json) |
| You are building your own agent            | [Read the MCP tool reference](/reference/cua-driver/mcp-tools)                                 |

Cua Driver supplies desktop state and actions. Codex owns the model interaction, reasoning loop, and tool selection.

For recorded GPT-6 Astra + Cua Driver examples with starter files and output
checks, try [map layout](/how-to-guides/recipes/build-and-inspect-a-map),
[PDF review](/how-to-guides/recipes/redact-and-annotate-a-pdf), or
[exhibition-panel editing](/how-to-guides/recipes/prepare-an-exhibition-panel).
The clips show selected macOS interactions, including foreground/desktop input.

See OpenAI's current [Codex MCP documentation](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) for supported transports and configuration.
