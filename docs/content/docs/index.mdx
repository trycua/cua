## Start with Cua Spaces

- [Quickstart](/spaces/quickstart): install the app, connect your agent and run a first task in about five minutes.
- [Connect your agent](/spaces/guides/connect-your-agent): add Spaces to Claude Code, Codex, Cursor and other agents.
- [Add a machine](/spaces/guides/add-a-machine): connect another Mac, Linux or Windows computer you own.
- [Plans](/spaces/guides/plans): what Free, Pro and Teams include.

## More walkthroughs

- [Sandbox images](/start-here/sandbox-images): the desktop and benchmark images, and one line to start each.
- [Drive your first app with Cua Driver](/start-here/drive-your-first-app): let your agent operate a native app on the machine you already have.
- [Create a local macOS sandbox with the Cua CLI](/start-here/create-a-local-macos-sandbox): a macOS Tahoe sandbox on Apple silicon with `cua sb create macos`.
- [Run a sandbox in GitHub Actions](/start-here/run-in-github-actions): a Linux sandbox per CI job, with logs and a screenshot as artifacts.
- [Build your first Cua Bench task](/start-here/your-first-cua-bench-task): create a task, score it with its oracle, then hand it to an agent.

## Examples

- [Cua Bots](/spaces/examples/cua-bots): persistent bots on Cua Spaces, each with its own computer, in a Mac and iPhone app. The same kind of app in TypeScript, Rust (Tauri) and Swift is in [Examples in other languages](/spaces/examples/other-languages).
- [Background computer-use with Cua Driver](/cua-driver/guides/recipes): an MCP tool for your agent. In this example, it builds and QAs a WPF app on Windows ([video](https://x.com/trycua/status/2059688966085853245)).
