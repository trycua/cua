## Approval

- `cua mcp --permissions` (or `CUA_MCP_PERMISSIONS`) gates each tool as `spaces:<tool>`. `spaces:all` grants every tool, `spaces:readonly` only the read-only ones.
- Each tool publishes MCP annotations (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`); clients use them to decide what to confirm. The **Approval** row of each tool shows them.
- Metered tools () allocate or extend a billed cloud Space. Everything else is free.
- Agent runs are auto-approved inside the Space: the Space is the sandbox. A session teleport needs an approval minted from its manifest, and `acknowledge_sensitive` for sensitive items.

## Errors

A tool that fails returns a normal result with `isError: true`, never a protocol error:

```json
{
  "content": [{ "type": "text", "text": "error: <message>" }],
  "isError": true,
  "structuredContent": { "error": { "kind": "<kind>", "message": "<message>" } }
}
```

Branch on `kind`; the message is for people. Every tool can return `invalid_argument`. A tool that takes `space` can also return `not_found` and `ambiguous_sandbox`; one with spacesd `requires`, `spacesd_not_available` and `capability_missing`; one with host requirements, `host_capability_missing`. Each tool lists the rest.

#### invalid_argument

An argument is missing, malformed or out of range.

Fix: Check the call against the tool's input schema; the message names the argument.

Listed by [`resize_space`](/spaces/reference/spaces#resize_space), [`volume_storage_set`](/spaces/reference/agents#volume_storage_set), [`volume_cache_set`](/spaces/reference/agents#volume_cache_set), [`relay_unregister_space`](/spaces/reference/spaces#relay_unregister_space), [`cloud_add_host`](/spaces/reference/spaces#cloud_add_host), [`cloud_budget`](/spaces/reference/spaces#cloud_budget), [`prewarm`](/spaces/reference/spaces#prewarm).

#### not_found

No Space, run, window, service, tool or file with that id.

Fix: List what exists first (list_spaces, agent_list, list_space_windows, list_tools).

Listed by [`volume_sync_resolve`](/spaces/reference/agents#volume_sync_resolve), [`cloud_remove_host`](/spaces/reference/spaces#cloud_remove_host).

#### spacesd_not_available

The computer answered but runs no cua-spacesd, so the spacesd primitives cannot work.

Fix: Use an image that runs cua-spacesd (for example ghcr.io/trycua/linux:24.04), or reach the Space's own services with list_tools and call_tool.

#### capability_missing

The Space's cua-spacesd reports a feature this tool needs as unsupported; the message names it and the driver's limitation.

Fix: Use a Space whose spacesd supports the feature (see the tool's `requires`).

#### host_capability_missing

A prerequisite on this computer is missing: a local runtime, an operator display or app-session providers.

Fix: Set up what the message names (see the tool's `host_requires`).

#### wrong_provider

The operation does not apply to this kind of Space.

Fix: Use a tool that serves the Space's provider (see the tool's `providers`).

Listed by [`stop_space`](/spaces/reference/spaces#stop_space), [`resize_space`](/spaces/reference/spaces#resize_space), [`start_space`](/spaces/reference/spaces#start_space).

#### unauthenticated

The Space's spacesd or the cua.ai relay rejected the token.

Fix: Re-add the Space with a valid token, or sign in again with `cua auth login`.

Listed by [`add_space`](/spaces/reference/spaces#add_space), [`list_spaces`](/spaces/reference/spaces#list_spaces), [`share_space`](/spaces/reference/spaces#share_space), [`unshare_space`](/spaces/reference/spaces#unshare_space), [`space_shares`](/spaces/reference/spaces#space_shares), [`relay_register_space`](/spaces/reference/spaces#relay_register_space), [`relay_unregister_space`](/spaces/reference/spaces#relay_unregister_space).

#### permission_denied

The signed-in account may not reach that relay computer.

Fix: Sign in with the account that owns the computer.

Listed by [`stop_space`](/spaces/reference/spaces#stop_space), [`start_space`](/spaces/reference/spaces#start_space), [`share_space`](/spaces/reference/spaces#share_space), [`unshare_space`](/spaces/reference/spaces#unshare_space), [`relay_unregister_space`](/spaces/reference/spaces#relay_unregister_space).

#### ambiguous_host

The computer name given to on="host:&lt;name&gt;" fits several of your computers equally well; the message lists them.

Fix: Ask the user which computer they meant, then pass on="host:&lt;computer id&gt;" from the list.

Listed by [`create_space`](/spaces/reference/spaces#create_space).

#### limit_exceeded

The host is at a capacity limit: two macOS VMs per Mac (Apple's macOS license, enforced by Apple Virtualization) or the host's own Space limit.

Fix: Delete a Space on that host (delete_space), pick another computer, or create a Linux Space instead.

Listed by [`create_space`](/spaces/reference/spaces#create_space), [`cloud_plan`](/spaces/reference/spaces#cloud_plan), [`prewarm`](/spaces/reference/spaces#prewarm).

#### host_capacity

The machine has no room for another Space now: its VMs are at their memory limit (shared snapshot memory counted once) or CPU limit, or it is low on memory. Nothing was started; the message says which limit and by how much.

Fix: Delete a Space (delete_space), create it smaller (cpus, memory_mb), or create it with on="auto" so another machine takes it.

#### ambiguous_sandbox

A short name matches more than one sandbox.

Fix: Use the full id (`local:<name>` or `cloud:<name>`).

#### transfer_failed

A file transfer did not land, or landed with a different sha256.

Fix: Retry; check free space and permissions at the destination.

Listed by [`space_write`](/spaces/reference/spaces#space_write), [`upload`](/spaces/reference/spaces#upload), [`send_file`](/spaces/reference/spaces#send_file), [`download`](/spaces/reference/spaces#download), [`teleport_app`](/spaces/reference/agents#teleport_app).

#### teleport_refused

Listed by [`teleport_app`](/spaces/reference/agents#teleport_app).

#### login_refused

The Keyvault refused a site login: the user declined, no saved password matches the page's origin, the tab is on another origin, or the Keyvault is locked or off.

Fix: Ask the user to approve the sign-in in Cua, import the site's saved password, or open the site's sign-in page and try again.

Listed by [`request_site_login`](/spaces/reference/agents#request_site_login).

#### agent

### Protocol errors

JSON-RPC errors are about the message, not the tool.

| Code | Name | When |
| --- | --- | --- |
| `-32700` | `PARSE_ERROR` | The message is not valid JSON. |
| `-32600` | `INVALID_REQUEST` | The message is not a JSON-RPC request: an empty batch, or no `method`. |
| `-32601` | `METHOD_NOT_FOUND` | An unknown method, or `tools/call` of a tool this server does not expose (not in the contract, or filtered out by permissions). |
| `-32602` | `INVALID_PARAMS` | `tools/call` without a tool `name`. |
