## Act on a window without focusing it
AT-SPI acts on an element through the accessibility bus, not through the pointer or keyboard: Atspi.Action.do_action(acc, i) (look up the index with get_n_actions / get_action_name), Atspi.EditableText.set_text_contents(acc, s) or insert_text, Atspi.Value.set_current_value(acc, v), Atspi.Selection.select_child(container, i), Atspi.Component.grab_focus(acc) (moves focus inside the app only). None of these warps the pointer or activates the window. X11 alone: XSendEvent (python-xlib `window.send_event(event)`, or `xdotool key --window W` / `type --window W`) delivers a synthetic KeyPress/ButtonPress to one window without changing the focus or stacking; the event carries send_event=True and some toolkits ignore it, so read the result back. XTest (XTestFake*), XWarpPointer, XSetInputFocus, XRaiseWindow and _NET_ACTIVE_WINDOW all change what the user sees. Opening a combo box or menu with its press action pops up a window that may grab input; selecting the hidden child item or using Selection avoids the popup.

## Read text from the accessibility tree
Start at Atspi.get_desktop(0); each child is an application (get_name, get_process_id). Walk with get_child_count / get_child_at_index, and check get_state_set().contains(Atspi.StateType.SHOWING) to skip hidden subtrees. Labels and buttons usually carry their text in get_name(); text widgets expose it through Atspi.Text.get_text(acc, 0, -1) (get_character_count for the length); numeric widgets through Atspi.Value.get_current_value. Atspi.Collection.get_matches(root, rule, ...) with Atspi.MatchRule finds nodes by role, state or attribute in one bus call. Tables: Atspi.Table.get_n_rows / get_n_columns / get_accessible_at(t, row, col), and Atspi.TableCell; a large table can report millions of children, so address cells by row and column instead of iterating. Relations (get_relation_set, LABELLED_BY) link a field to its label. Every call is a D-Bus round trip; Atspi.set_timeout bounds a slow app.

## Save an image to disk
Gdk 3: window = Gdk.get_default_root_window() (or GdkX11.X11Window.foreign_new_for_display(Gdk.Display.get_default(), xid) for one window); pixbuf = Gdk.pixbuf_get_from_window(window, x, y, w, h); pixbuf.savev(path, "png", [], []). GdkPixbuf.Pixbuf.savev takes the format name ("png", "jpeg", "bmp", "ico", "tiff") and option key/value lists (["quality"], ["90"] for jpeg). python-xlib: window.get_image(x, y, w, h, X.ZPixmap, 0xffffffff) returns raw pixel data that GdkPixbuf.Pixbuf.new_from_bytes can wrap. An image already shown inside an app can sometimes be reached through the AT-SPI Image interface (get_image_extents) and then captured from the screen at those extents.

## Drag
A real drag is press, motion in several steps, release on the same pointer: XTestFakeButtonEvent(dpy, 1, True, 0), XTestFakeMotionEvent repeatedly with small pauses, XTestFakeButtonEvent(dpy, 1, False, 0), then XFlush; xdotool mousedown / mousemove / mouseup does the same. Toolkits start a drag only after the pointer moves a few pixels with the button held, and many accept a drop only after a short hover over the target. It moves the user's real pointer.

## Open a file in an app
From inside the app: its File menu item (do_action on the "menu item" node), then the file chooser dialog. In a GTK file chooser, typing a path that starts with "/" or "~", or ctrl+L, opens a location entry; set_text_contents on that entry and activate the dialog's Open button. Outside the app: the org.freedesktop.portal.OpenURI interface (OpenFile / OpenURI) on the session bus asks the desktop to open a file with its default handler; Gio.AppInfo.launch_default_for_uri does the same from a process. Each of these may raise a new window: find it again by title or _NET_CLIENT_LIST before acting on it.

## Find windows and their apps
python-xlib: root.get_full_property(d.intern_atom("_NET_CLIENT_LIST"), X.AnyPropertyType) lists managed windows; _NET_WM_NAME (UTF8_STRING) gives the title, _NET_WM_PID the process, _NET_WM_WINDOW_TYPE the kind (dialog, normal), _NET_CLIENT_LIST_STACKING the stacking order bottom to top. window.get_geometry() and translate_coords(root, 0, 0) give the frame. Match an X window to its AT-SPI application by pid (Atspi.Accessible.get_process_id). Wnck.Screen and xdotool search --name / --pid / --class are other ways to list them.
