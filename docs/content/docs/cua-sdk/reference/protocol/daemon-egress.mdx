## Types in `cua/daemon/v1/egress.proto`

### EgressPolicy

Which destinations a Space may open connections to. Everything is
allowed unless a rule says otherwise: every `deny` entry blocks that
destination, every `allow` entry is an exception that wins over `deny`
(deny "all" with allow "1.1.1.1" leaves only 1.1.1.1 reachable), and an
`allow` list with no `deny` blocks nothing. Entries are IPv4/IPv6
addresses or CIDRs; "all" is 0.0.0.0/0 and ::/0; a hostname is refused.
DNS works only while the resolver's address is not blocked (or is
allowed). Loopback, replies to connections made to the guest and IPv6
neighbor discovery are never filtered.

| Field | # | Type | Description |
| --- | --- | --- | --- |
| `allow` | 1 | repeated `string` | Destinations that stay reachable where `deny` blocks them. |
| `deny` | 2 | repeated `string` | Destinations that are blocked. |

### NetworkSettings

A Space's network settings: a preset, the user's own lists, and what the
host compiles them to. `Space.network_settings` and
`CreateSpaceRequest.network_settings` carry it. The presets:

- "internet" (the default): the public internet and the Space's own
  tree; the host, the local network, cloud metadata, other trees and the
  daemon are blocked;
- "none": no network;
- "localhost": "internet", plus the host's loopback on
  `localhost_ports` (every port only with `all_localhost_ports`; the ports
  go with "localhost+lan" too);
- "lan": "internet", plus the local network (not the host itself);
- "localhost+lan": "internet", plus both of the above (the two extras are
  independent; this is the one preset with both);
- "custom": `custom_base` ("internet" or "none") plus `allow` and `deny`;
- "unprotected": everything but cloud metadata, other trees and the
  daemon.

`allow` and `deny` apply on top of any preset but "none": an allow is an
exception to a deny and to the default blocks (not the host itself, which
only "localhost" opens).

| Field | # | Type | Description |
| --- | --- | --- | --- |
| `preset` | 1 | `string` | The preset word; empty is "internet". |
| `localhost_ports` | 2 | repeated `uint32` | "localhost": the host loopback ports the Space may reach. |
| `all_localhost_ports` | 3 | `bool` | "localhost": every port (the daemon's stay blocked). |
| `allow` | 4 | repeated `string` | Destinations that stay reachable (addresses or CIDRs). |
| `deny` | 5 | repeated `string` | Destinations that are blocked (addresses, CIDRs or "all"). |
| `custom_base` | 6 | `string` | "custom": what it starts from, "internet" (empty) or "none". |
| `widened_by` | 7 | `string` | Set when the Space was allowed more than its parent: who and when. |
| `via` | 8 | `string` | Where its internet traffic leaves ("Exit through"): empty or "internet" for its own network, "this-machine" (the hotspot), "space:&lt;id&gt;" (a Space of its tree) or `socks5://host:port`. With an exit the Space's own internet is closed, and the exit applies its rules first. A child keeps its parent's exit. |
