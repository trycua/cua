# Calibration registry reference

This directory publishes the task-calibration schema and method without
publishing the held-out candidate registry or its evidence.

The registry is separate from task manifests. Task manifests define execution;
the registry records pilot targets, clean-room controls, observed statistics,
and keep, revise, or drop decisions.

A candidate cannot be accepted until its required pilot statistics and decision
fields are present. Those records remain with the controlled task pack.

The method is defined in
[task-difficulty calibration](../docs/explanation/task-difficulty-calibration.md).
