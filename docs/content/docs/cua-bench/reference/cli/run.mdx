## `cb run`

Run a task or dataset, and manage runs.

Run a task (a directory with main.py) or a dataset, with an agent or the task's oracle. `cb run <path>` is shorthand for `cb run task|dataset <path>`.

```text output
cb run [COMMAND]
```

**Examples**

```bash test="cli-shape" id="ref-cb-run"
# Run a task with its oracle solution
cb run ./tasks/hello_file_env

# Run a dataset with an agent, four variants at once
cb run cua-bench-basic --agent cua-agent --model anthropic/claude-sonnet-4-20250514 -j 4

# List runs
cb run list
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success: every variant completed. |
| `1` | Failure: a variant failed or was cancelled, or the command could not run. |
| `2` | Usage error: an unknown command, flag or value. |
| `130` | Interrupted (Ctrl-C); running variants are cancelled. |
