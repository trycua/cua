Cua Driver lets an AI agent use the apps on your computer: it can click
buttons, type, scroll and move between browser tabs. It works in the
background, so you can keep using your mouse and keyboard while the agent
works. The agent gets its own cursor, so you can see what it is doing.

It works with agents such as Claude Code, Codex and Cursor. You install it
once, add it to your agent, and then ask the agent to do things in your apps.

## Get started

1. [Quickstart](/cua-driver/quickstart): install Cua Driver and have your agent
   use a calculator. About five minutes.
2. [Connect your agent](/cua-driver/guides/connect-your-agent): add Cua Driver
   to Claude Code, Codex, Cursor and other agents.
3. [Recipes](/cua-driver/guides/recipes): real tasks to try next.

## Where it works

| Computer | What you need | Works? |
| --- | --- | --- |
| Mac | macOS 14 or later. You allow Accessibility and Screen Recording once. | Yes |
| Windows | Windows 10, 11 or Server, with a user signed in at the desktop | Yes |
| Linux | A 64-bit (x86_64) desktop | Yes, with some limits |

Some apps and some Linux desktops only work while the app is in front. See
[Platform support](/cua-driver/concepts/platform-support) for the details.
