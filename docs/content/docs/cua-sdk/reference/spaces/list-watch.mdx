`Spaces.watch_list` calls a `SpacesListListener` once at the start and again whenever the list changes: this computer's Spaces within a second, your other computers on the mesh within about a second of connecting or going away, the others within 10 seconds. Read the list again (`Spaces.list`) when it is called. It reopens by itself after a daemon restart; `SpacesListWatch.stop` ends it.

## List changes

Methods of [`Spaces`](/cua-sdk/reference/spaces#spaces).

### `Spaces.watch_list`

Tells `listener` when the Space list changed: once at the start, then
on every change. This computer's Spaces within a second; your other
computers on the mesh within about a second of connecting or going
away; the others within 10 seconds. Reopens by itself if the daemon
restarts (and then calls `listener` again). Stop it with
`SpacesListWatch.stop`.

## `SpaceList` record

The Spaces known now (`Spaces.list_known`) and how far the read got.

Returned by [`Spaces.list_known`](/cua-sdk/reference/spaces#spaceslist_known).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `spaces` | [`Vec<SpaceInfo>`](/cua-sdk/reference/spaces#spaceinfo-record) |  | This machine's Spaces, and the account's other computers' as far as they answered (the last known ones meanwhile). |
| `incomplete` | `bool` |  | Some of the account's computers have not answered yet: the list may grow, and an empty one is not "no Spaces". Always false from a daemon that predates it (it answers once every computer did). |
| `reaching` | `u32` |  | How many computers are still being reached (0 when unknown). |
| `stale` | `bool` |  | The other computers' rows are the last known ones, not yet confirmed by the relay. |
| `notice` | `String` |  | Why the account's computers could not be read, when they could not. |

## `SpacesListListener`

Hears that the Space list changed (`Spaces.watch_list`). Called on an
SDK worker thread; return quickly (read the list on your own queue).
