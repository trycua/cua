## list_tools

List the MCP services and tools reachable inside the Space.

Lists the tools of an MCP service INSIDE the Space. `service` is any service the Space declares (an MCP server the image runs, reached over streamable HTTP; no spacesd needed) or `driver`, the spacesd's own cua-driver registry (screenshot, click, type, launch apps, accessibility, ...). The default is `driver`, or the only declared service of a Space without spacesd. With no `name`, returns a scannable overview; pass name=&lt;substring&gt; for full input schemas. Then invoke them with call_tool. The reply names every service the Space exposes.

| | |

| Providers | all (cloud, local, direct, relay) |
| Platforms | all (macos, windows, linux) |
| Metering | free |
| Approval | permission `spaces:list_tools`, in `spaces:readonly`; read-only, idempotent |
| Swift SDK | `space.services.list()` |
| Rust | `Services::list_tools` |

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | none | Substring filter; matching tools come back with full input schemas. |
| `service` | `string` | `driver` | Service. A service the Space declares (see `list_spaces`), reached over generic MCP (streamable HTTP), or `driver` (the spacesd's cua-driver registry; `mcp`, `cua-driver` and `computer-server` are aliases unless the Space declares a service by that name). Default: `driver`, or the only declared service of a Space without spacesd. |
| `space` | `string` | required | Space id or name. |

### Result

JSON: `service`, `count`, `tools` (`name` and `description`; with `name`, also `inputSchema`), `services`, `contract_version`, and a `hint` when no filter was given.

## call_tool

Call a service tool inside the Space.

Returns the tool's content parts unchanged, images included. A tool-level failure comes back with isError, not as a transport error.

| | |

| Approval | permission `spaces:call_tool`; destructive |

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `arguments` | `object` | `{}` | Arguments object for the tool. Default `{}`. |
| `service` | `string` | `driver` | Service (see `list_tools`). Default: `driver`, or the only declared service of a Space without spacesd. |

### Result
