`app_drag_classify` tells a move from a resize by the window's frame. `app_drag_trigger_initial` and `app_drag_trigger_apply` run the trigger: the cursor passes a line 5 pt above the notch's bottom edge, or rests 0.3 s in the Teleport to Cua box. `app_drag_displays` and `app_drag_portal_displays` give the notch geometry of each display.
