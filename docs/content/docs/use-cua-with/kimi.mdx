Kimi Code CLI supports local stdio MCP servers. Configure Cua Driver in the CLI, then let Kimi Code invoke its desktop tools as part of the agent loop.

| Start here when…                    | Recommended path                                                                                                                 |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| You use Kimi Code CLI               | [Connect Kimi Code to Cua Driver](/use-cua-with/kimi-code)                                                                       |
| You manage MCP with a project file  | Add Cua Driver to `.kimi-code/mcp.json` using the [generic MCP shape](/how-to-guides/driver/connect-your-agent#generic-mcp-json) |
| You are building another Kimi agent | Use the [MCP tools](/reference/cua-driver/mcp-tools) or Cua Driver CLI                                                           |

See Kimi Code CLI's [MCP customization guide](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/mcp.html) and [`kimi mcp` reference](https://moonshotai.github.io/kimi-cli/en/reference/kimi-mcp.html).
