`app_driver_preview` and `app_presentation_preview` return the miniatures of the AI agents and presentation cards; the `*_frame` functions give one frame of the loop and the `*_still` functions the frame shown with Reduce Motion. The onboarding flow itself is on [Onboarding and settings](/cua-sdk/reference/spaces/app-core/onboarding-settings).

## `AppPreviewFrame` record

Returned by [`app_presentation_preview_frame`](#app_presentation_preview_frame), [`app_presentation_preview_still`](#app_presentation_preview_still).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `pointer` | [`AppPreviewPoint`](#apppreviewpoint-record) |  | The pointer's tip. |
| `pressed` | `bool` |  | The pointer presses (drawn a little smaller). |
| `hover` | `f64` |  | Notch: the hover cue, 0 to 1 (the closed notch and its tab grow by 1 + (hover_scale - 1) * hover horizontally, about the top centre). |
| `open` | `f64` |  | Notch: the shape, closed 0 to open 1 (a spring: it can pass 1); menu: the menu's opacity. |
| `content` | `f64` |  | Notch: the content's fade, 0 to 1 (it also grows from `content_scale`, anchored at the top); menu: the same as `open`. |
| `tab` | `f64` |  | Notch: the tab, 1 shown to 0 tucked under the notch. |
| `highlighted` | `Option<u32>` |  | Menu: the row under the pointer (an enabled item), highlighted. |
| `active` | `bool` |  | Menu: the status item is highlighted (pressed, or its menu open). |
