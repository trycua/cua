| `symbol` | `String` |  | SF Symbol (`POWER_SYMBOL`). |

## `AppSpacePower` record

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `control` | [`AppPowerControl`](#apppowercontrol-enum) |  | How it turns off. |

| `turning_on` / `turningOn` | `Option<bool>` |  | Being turned on (`true`) or off (`false`) now. |
