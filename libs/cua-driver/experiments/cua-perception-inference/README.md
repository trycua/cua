# Cua perception inference spike

This non-workspace crate demonstrates that a Rust binary can decode a PNG and
execute a 169-byte synthetic ONNX identity graph through `tract-onnx` without
Python at runtime. It does not exercise ONNX Runtime, YOLO, OCR, a product
model, or a public contract.
`fixtures/screenshot.png` is a copy of the repository-owned
`docs/public/favicon.png`, used only as a small deterministic decode fixture.

```sh
cargo run --locked --release --manifest-path \
  libs/cua-driver/experiments/cua-perception-inference/Cargo.toml
```

Pass an alternate PNG and ONNX model as the first and second arguments. The
program expects the model to accept a `[1, 3, 2, 2]` `f32` tensor and return it
unchanged; this intentionally tests runtime portability rather than detector
quality or post-processing.

`fixtures/identity.onnx` is generated by `generate_fixture_model.py`. Python is
needed only to regenerate that development fixture, never to build or run the
Rust program.

```sh
uv run --isolated --no-project --with onnx==1.19.0 \
  python generate_fixture_model.py
```
