<Callout title="Cua Spaces app export">
These APIs are part of the Cua Spaces app export for building Spaces UIs. They are source-available under FSL-1.1-MIT and ship for Swift only (`import CuaSpacesFFI`); the Rust tab shows the `cua-spaces-ffi` crate they come from. The open source SDK packages for Python, TypeScript and Kotlin do not include them.
</Callout>

Each `app_telemetry_*` function takes a reducer step (the state before it and the action) and returns the `AppTelemetrySignal`s it means: first-run pages, Space creates, Settings, Storage, sharing and enrollment, as fixed words only. `app_telemetry_record` sends them on the SDK's telemetry client, where every switch and the first-run notice apply. `app_telemetry_start` and `app_telemetry_welcome_left` hold the first events until the first run's Welcome page is left, with its usage-data switch deciding. What is sent: [Telemetry and privacy](/cua-sdk/concepts/telemetry).

| `DeviceEnroll` | This device enrolled with the relay, or failed to (`cua_device_enroll`). Fields: `method: String`, `outcome: String` |
| `Experiment` | An experiment was turned on or off in Settings, Experiments (`cua_experiment`). Fields: `action: String`, `experiment: String` |
| `ExperimentsOn` | Which experiments are on now (no event of its own: the daily `cua_app_active` carries them as `experiments_on`). Fields: `experiments: Vec<String>` |

## `app_telemetry_start`

The app started: attributes this process's events to `spaces_app` at
`version`, lets the app show the first-run notice itself (nothing is
sent before it has been shown once), and records `app_launched` (on a
first run, once the notice shows). Call once at launch, before the
first `Cua`. Returns whether the notice was already shown here.

## `app_telemetry_welcome_left`

The first run left Welcome with its usage-data switch at `on`: writes
the machine's setting when it changed (the same as Settings and `cua
telemetry off`), then records that the notice was shown. Nothing is
queued or sent before; with the switch off, nothing after either.
