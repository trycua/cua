## `cua sandbox exec`

Run a command (joined into one shell line, as `sh -c`). Exits with the command's own status. A local Lume sandbox without cua-spacesd runs it via SSH (`lume ssh`).

```text output
cua sandbox exec [OPTIONS] <NAME> <COMMAND>...
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<NAME>` | string | required | Sandbox name or ref (`local:NAME`, `cloud:NAME`). |
| `<COMMAND>...` | string | required | Command and arguments. Repeatable. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-sandbox-exec--local"></span>`--local` | boolean | `false` | Look NAME up among local sandboxes only (same as `local:NAME`). |
| <span id="cua-sandbox-exec--cloud"></span>`--cloud` | boolean | `false` | Look NAME up among cloud sandboxes only (same as `cloud:NAME`). |

**Examples**

```bash test="cli-shape" id="ref-cua-sandbox-exec"
cua sb exec dev uname -a
cua sb exec dev 'ls /tmp | wc -l'
```

## `cua sandbox port-forward`

Forward a guest port: `port-forward NAME PORT[:LOCAL]` (a local sandbox's port not published at create, and cloud sandboxes, tunnel through cua-spacesd when the image has it; cloud images without it get HTTP and WebSocket through a loopback proxy to the cloud gateway).

```text output

```

Alias: `cua sandbox forward`.

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<NAME>` | string | required | Sandbox name or ref (`local:NAME`, `cloud:NAME`). |
| `<SPEC>` | string | required | PORT or PORT:LOCAL_PORT. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-sandbox-port-forward--local"></span>`--local` | boolean | `false` | Look NAME up among local sandboxes only (same as `local:NAME`). |
| <span id="cua-sandbox-port-forward--cloud"></span>`--cloud` | boolean | `false` | Look NAME up among cloud sandboxes only (same as `cloud:NAME`). |
| <span id="cua-sandbox-port-forward--no-wait"></span>`--no-wait` | boolean | `false` | Print the target and exit instead of forwarding until Ctrl-C. |

**Examples**

```bash test="cli-shape" id="ref-cua-sandbox-port-forward"

```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
