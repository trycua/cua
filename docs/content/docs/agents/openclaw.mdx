## Cua Driver

`cua-driver mcp-config --client openclaw` prints the command to register Cua Driver, `openclaw mcp set cua-driver '{…}'`. Run it, then restart OpenClaw. On macOS, a server spawned by the OpenClaw gateway does not inherit OpenClaw.app's permissions.

OpenClaw can also install the skill from ClawHub: `clawhub install @cua/driver`. See [Connect your agent](/agents) for permissions and the other clients.

## Cua Spaces

`cua agents setup --agents openclaw --yes` adds the `cua` skills and MCP server to `~/.openclaw/openclaw.json`. See [Give your agent Spaces](/agents/spaces-mcp).
