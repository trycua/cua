`app_wizard_placement_options` lists where a new Space can run: This Mac, each machine that provides Spaces (greyed out with why when offline or at its limit), and, with the Your cloud experiment on, each connected cloud.

## `AppPlacementOption` record

Returned by [`app_wizard_placement_options`](#app_wizard_placement_options).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `String` |  | What choosing it sets as the create's `on`: `local`, `cloud`, `host:<machine>`, or a connected cloud's word (`aws`). |
| `label` | `String` |  | The menu's text: "This Mac", "Mac mini", "Mac mini (offline)", "AWS · us-west-2". |
| `group` | `String` |  | Its group, in menu order (a separator between groups): `this-mac`, `hosts`, `clouds`. |
| `selected` | `bool` |  | Chosen. |
| `enabled` | `bool` |  | It can be chosen now (offline, at its limit: not). |
