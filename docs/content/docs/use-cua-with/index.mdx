Cua Driver is the computer-use layer. An agent harness connects to it over MCP or through the Cua Driver CLI, then gives a model screenshots, accessibility state, and input tools. Pick the part of the stack you are starting from.

## Models and providers

These pages show the verified harnesses and local runtimes that can put each model family in front of Cua Driver. Cua Driver does not connect directly to a model API.
