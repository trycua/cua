### `cua spaces ls`

Registered Spaces and your computers on the relay.

CPU, MEMORY and DISK ON THIS MAC show what each Space was given and what it
uses now (the numbers the Cua Spaces app shows); for another of your


| --- | --- | --- | --- |

### `cua spaces add`

Register a Space after a capabilities handshake with its cua-spacesd (or, for another URL, an MCP initialize). Re-adding an address updates it. The token is stored apart from the registry, 0600.

```text output
cua spaces add [OPTIONS] <URL>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<URL>` | string | required | The Space's cua-spacesd (`http(s)://host:port`, `host:port`, default port 3211), a Space id (`local:<name>`), or any MCP endpoint URL. |

| Flag | Type | Default | Env var | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-spaces-add--token"></span>`--token` | string |  | `CUA_ENV_TOKEN` | spacesd token (or the bearer an MCP endpoint needs). |
| <span id="cua-spaces-add--name"></span>`--name` | string |  |  | Display name (default: the guest's hostname). |
| <span id="cua-spaces-add--service"></span>`--service` | string |  |  | For an MCP endpoint URL: the service name to register it under (default `mcp`). |
| <span id="cua-spaces-add--host"></span>`--host` | boolean | `false` |  | It is a computer that provides Spaces over its direct address (Tailscale or LAN): `--on host:<name>` finds it without the relay. Its token is stored like any direct Space's. |

**Examples**

```bash test="cli-shape" id="ref-cua-spaces-add"
cua spaces add 10.0.0.5:3211 --token "$TOKEN" --name studio
cua spaces add local:my-sandbox
cua spaces add http://127.0.0.1:8765/mcp --service tools

# A computer that provides Spaces over Tailscale, without the relay (`cua host setup --direct ... --provide-spaces` on it prints this)
cua spaces add 100.101.102.103:3211 --host --name "Mac mini (spare)" --token "$TOKEN"
```

### `cua spaces share`

Let someone in your team watch (viewer) or use (editor) a Space, through the relay. They open it as `relay:<computer>`. Sharing is for teams: you need a team, and they must be in it (or share with the whole team as `team:<id>`).

```text output
cua spaces share [OPTIONS] <SPACE> <WHO>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<SPACE>` | string | required | Space id, address or display name. |
| `<WHO>` | string | required | Their email (verified by cua.ai) or account id, in your team; or `team:<id>` for the whole team. |

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-spaces-share--role"></span>`--role` |  | `viewer` \| `editor` | `viewer` | `viewer`: presence and a view-only stream. `editor`: full use. |
| <span id="cua-spaces-share--yes"></span>`--yes` | `-y` | boolean | `false` | Confirm without a terminal prompt. Without a daemon the share happens at once. A running daemon still asks with Touch ID or your password on this computer; without a terminal, `--yes` says someone will answer there (otherwise the command fails at once instead of waiting for a prompt nobody sees). |

**Examples**

```bash test="cli-shape" id="ref-cua-spaces-share"
cua spaces share local:studio bob@example.com
cua spaces share local:studio bob@example.com --role editor
cua spaces share relay:0123abcd4567ef89 acct-42 --role viewer

# The whole team, to watch
cua spaces share local:studio team:acme --role viewer

# From a script or agent: confirm with Touch ID or your password here
cua spaces share local:studio bob@example.com --yes
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no provider credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
