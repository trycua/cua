## `cua agents setup`

Install the default cua skills and configure the cua MCP server.

```text output
cua agents setup [OPTIONS]
```

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-agents-setup--agents"></span>`--agents` |  | string |  | Agents: `all` (installed), `none`, or ids such as `claude,codex,hermes` (`cua agents detect` lists every supported agent). |
| <span id="cua-agents-setup--mcp-command"></span>`--mcp-command` |  | string |  | Command agents launch for the MCP server (default: the `cua` on PATH, else this binary). |
| <span id="cua-agents-setup--skills-only"></span>`--skills-only` |  | boolean | `false` | Only install skills. Alias: `--no-mcp`. |
| <span id="cua-agents-setup--mcp-only"></span>`--mcp-only` |  | boolean | `false` | Only configure the MCP server. Alias: `--no-skills`. |
| <span id="cua-agents-setup--yes"></span>`--yes` | `-y` | boolean | `false` | Answer yes to every prompt. |
| <span id="cua-agents-setup--force"></span>`--force` |  | boolean | `false` | Replace skill folders cua did not write (the old one is backed up). |
| <span id="cua-agents-setup--cua-driver"></span>`--cua-driver` |  | boolean | `false` | Set up background computer-use instead: the cua-driver skill and the cua-driver MCP server (`cua-driver mcp`). --mcp-command then names the cua-driver binary. |

**Examples**

```bash test="cli-shape" id="ref-cua-agents-setup"
# Every installed agent, asking before each change
cua agents setup

# Claude Code and Codex, no prompts
cua agents setup --agents claude,codex -y

# Hermes Agent (Nous Research): ~/.hermes/skills and ~/.hermes/config.yaml
cua agents setup --agents hermes -y

# Only the MCP server entry
cua agents setup --mcp-only

# Background computer-use: the cua-driver skill and MCP server
cua agents setup --cua-driver --agents all -y
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
