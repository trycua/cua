## Cua Driver

Hermes has Cua Driver built in. Turn it on, then start a chat with it:

```bash skip="third-party-cli"
hermes tools enable computer_use --platform cli
hermes -t computer_use chat
```

Repair it with `hermes computer-use install` and `doctor`. Do not add a second raw MCP server. See [Connect your agent](/cua-driver/guides/connect-your-agent) for the other clients.

## Cua Spaces

`cua agents setup --agents hermes --yes` adds the `cua` skills and MCP server to `~/.hermes/config.yaml`. Start a new Hermes session, or run `/reload-mcp`, to load the server. On Windows, Hermes lives in `%LOCALAPPDATA%\hermes`. See [Give your agent Spaces](/cua-cli/guides/mcp-server).
