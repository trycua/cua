Each recipe is one page with one goal. Follow the numbered steps, then check
"It worked if". If something goes wrong, "If it didn't" lists the common fixes.

| I want to | Recipe |
|-----------|--------|
| Use my other Mac from this one | [Connect your other Mac](/spaces/recipes/connect-your-other-mac) |
| Use a Windows PC from my Mac | [Connect a Windows PC](/spaces/recipes/connect-a-windows-pc) |
| See what my agent is doing, as it does it | [Watch your agent work live](/spaces/recipes/watch-your-agent-work) |
| Use an app I'm signed in to inside a Space | [Teleport a signed-in app into a Space](/spaces/recipes/teleport-a-signed-in-app) |
| Let a teammate see or use a Space | [Share a Space with a teammate](/spaces/recipes/share-a-space-with-a-teammate) |

Before you start, install Cua Spaces from [spaces.cua.ai](https://spaces.cua.ai)
(a Mac with macOS 26 or later) and sign in. The
[Quickstart](/spaces/quickstart) covers the install in more detail.

Looking for commands and options instead? See the
[guides](/spaces/guides/add-a-space) and the [reference](/spaces/reference).
