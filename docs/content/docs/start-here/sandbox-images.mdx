Cua publishes these images on `ghcr.io/trycua`. The Linux, Windows, benchmark and macOS 26 images include [cua-spacesd](/spaces) and [cua-driver](/cua-driver), making them ready for agentic workloads; macOS 15 runs the legacy guest agent for now. Windows, macOS and tags ending in `-disk` are VMs; the rest are containers. [Image catalog details](/cua-sdk/reference/os-image-catalog).
