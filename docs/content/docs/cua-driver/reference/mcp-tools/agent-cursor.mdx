## `set_agent_cursor_enabled`

Show or hide the agent cursor owned by a session.

Effect: mutating, idempotent. Platforms: macOS, Linux, Windows.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="set_agent_cursor_enabled--enabled"></span>`enabled` | `boolean` | required | `true` shows the session's agent cursor overlay; `false` hides it. |
| <span id="set_agent_cursor_enabled--session"></span>`session` | `string` | required | Public label of the session that owns the cursor. |

**Example arguments**

```json
{"session":"<session>","enabled":false}
```

## `set_agent_cursor_motion`

Configure only movement physics and visibility timing for a session cursor.

Effect: mutating, idempotent. Platforms: macOS, Linux, Windows.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="set_agent_cursor_motion--arc_flow"></span>`arc_flow` | `number` |  | Arc asymmetry: positive puts the apex near the destination, negative near the start. Clamped to -1..1 (default 0). |
| <span id="set_agent_cursor_motion--arc_size"></span>`arc_size` | `number` |  | Sideways arc deflection as a fraction of the distance. Clamped to 0..1 (default 0.25). |
| <span id="set_agent_cursor_motion--dwell_after_click_ms"></span>`dwell_after_click_ms` | `number` |  | Pause after a click animation, in milliseconds. Clamped to 0..5000 (default 80). |
| <span id="set_agent_cursor_motion--end_handle"></span>`end_handle` | `number` |  | Path control-point offset from the end, as a fraction of the distance. Clamped to 0..1 (default 0.3). |
| <span id="set_agent_cursor_motion--glide_duration_ms"></span>`glide_duration_ms` | `number` |  | Fixed glide duration in milliseconds. 0 (the default) uses speed-based timing. Clamped to 0..5000. |
| <span id="set_agent_cursor_motion--idle_hide_ms"></span>`idle_hide_ms` | `number` |  | Hide the cursor after this many idle milliseconds; 0 never hides it. Clamped to 0..60000 (default 15000). |
| <span id="set_agent_cursor_motion--session"></span>`session` | `string` | required | Public label of the session that owns the cursor. Omitted or null motion fields keep their current value. |
| <span id="set_agent_cursor_motion--spring"></span>`spring` | `number` |  | Post-arrival spring damping: 1 is critically damped, 0.3 is bouncy. Clamped to 0.3..1 (default 0.72). |
| <span id="set_agent_cursor_motion--start_handle"></span>`start_handle` | `number` |  | Path control-point offset from the start, as a fraction of the distance. Clamped to 0..1 (default 0.3). |
| <span id="set_agent_cursor_motion--turn_radius"></span>`turn_radius` | `number` |  | Minimum turning radius of the glide path, in points; smaller turns tighter. Clamped to 1..1000 (default 80). |

**Example arguments**

```json
{"session":"<session>"}
```
