<span id="cua-doctor"></span>

Check the host, an image and a sandbox's guest in one report (`cua doctor [REF]`), or eval parity between two variants (`cua doctor parity A B`).

```text output
cua doctor [OPTIONS] [TARGET]
       cua doctor <COMMAND>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<TARGET>` | string | optional | Sandbox to check: `local:<name>`, `cloud:<name>`, `direct:<host:port>`, a bare name, or a spacesd URL. Omit for the host checks only. |

| Flag | Type | Default | Env var | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-doctor--image"></span>`--image` | string |  |  | Image to resolve for the image checks (default: the sandbox's). |
| <span id="cua-doctor--arch"></span>`--arch` | string |  |  | Architecture to resolve the image for (default: the sandbox's, else this host's). |
| <span id="cua-doctor--format"></span>`--format` | `human` \| `json` \| `junit` | `human` |  | Output format (`--json` selects json). |
| <span id="cua-doctor--effects"></span>`--effects` | `none` \| `virtual` | `none` |  | Which guest checks may act on the guest. |
| <span id="cua-doctor--only"></span>`--only` | string |  |  | Guest check ids or groups to run (comma separated). Repeatable. |
| <span id="cua-doctor--skip"></span>`--skip` | string |  |  | Guest check ids or groups to skip. Repeatable. |
| <span id="cua-doctor--timeout"></span>`--timeout` | integer | `240` |  | Guest budget in seconds. |
| <span id="cua-doctor--token"></span>`--token` | string |  | `CUA_ENV_TOKEN` | spacesd token for a URL target (default: CUA_ENV_TOKEN). |
| <span id="cua-doctor--shim"></span>`--shim` | string |  |  | Check an image without cua-spacesd through its own API instead: `computer-server=<url>`, `osworld=<url>` or `mcp=<url>`. |
| <span id="cua-doctor--expect-manifest"></span>`--expect-manifest` | path |  |  | The image's claims (manifest JSON), for the shim or to override the guest's own. |
| <span id="cua-doctor--out"></span>`--out` | path |  |  | Also write the JSON report here. |
| <span id="cua-doctor--junit"></span>`--junit` | path |  |  | Also write JUnit XML here. |
| <span id="cua-doctor--expect"></span>`--expect` | string |  |  | Fail unless the build running in the guest is the expected one: COMPONENT=WANT with WANT `sha256:<hex>` (the executable), `git:<sha>` or a version (repeatable). Components: cua-spacesd, cua-driver, or an overlay name. `cua sb create --overlay` prints the sha256 to pass. |
| <span id="cua-doctor--strict"></span>`--strict` | boolean | `false` |  | Fail on warnings and on required checks that were skipped. |
| <span id="cua-doctor--no-host"></span>`--no-host` | boolean | `false` |  | Skip the host checks. |

**Examples**

```bash test="cli-shape" id="ref-cua-doctor"
# Host checks only
cua doctor

# Host, image and guest checks for the sandbox dev
cua doctor dev

# CI: fail on warnings, write JUnit XML
cua doctor cloud:dev --strict --junit doctor.xml
```

## `cua doctor parity`

Eval parity between two variants of one image (rootfs vs containerDisk): doctor on both, fidelity diff, task outcomes.

```text output
cua doctor parity [OPTIONS] <A> <B>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<A>` | string | required | First variant (a sandbox ref or a spacesd URL). |
| `<B>` | string | required | Second variant. |

| Flag | Type | Default | Env var | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-doctor-parity--token"></span>`--token` | string |  | `CUA_ENV_TOKEN` | Token for URL targets (both), default CUA_ENV_TOKEN. |
| <span id="cua-doctor-parity--token-b"></span>`--token-b` | string |  |  | Token for B when it differs from A's. |
| <span id="cua-doctor-parity--tasks"></span>`--tasks` | string | `builtin:form,builtin:file` |  | Tasks (`builtin:form`, `builtin:file`), comma separated. Repeatable. |
| <span id="cua-doctor-parity--allow-diff"></span>`--allow-diff` | string |  |  | Extra fidelity keys allowed to differ. Repeatable. |
| <span id="cua-doctor-parity--out"></span>`--out` | path |  |  | Write parity.json here. |
| <span id="cua-doctor-parity--timeout"></span>`--timeout` | integer | `240` |  | Doctor budget per variant, seconds. |

**Examples**

```bash test="cli-shape" id="ref-cua-doctor-parity"
cua doctor parity local:linux-rootfs local:linux-vm
cua doctor parity local:linux-rootfs local:linux-vm --out parity.json
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
