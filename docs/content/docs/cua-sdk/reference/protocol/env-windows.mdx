## WindowsService

`cua.env.v1.WindowsService`

Window enumeration, window management and app launching.

Windows are addressed with opaque `WindowRef` handles (id + epoch). Native
handles never cross the wire. Nothing here goes through a shell: apps are

## AccessibilityService

`cua.env.v1.AccessibilityService`

The guest accessibility tree (macOS AX, Windows UI Automation, Linux
AT-SPI via cua-driver platform-linux).

Every read returns a snapshot id. Element ids are only meaningful together
with the snapshot id they came from; acting on an element from an older
snapshot fails with `ERROR_REASON_STALE_SNAPSHOT` unless the server can
prove the element is unchanged. Requires capability "a11y".
