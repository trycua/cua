## hotspot_start

Start sharing this machine's network with a Space.

Starts the Space's reverse-SOCKS hotspot (TunnelService.StartHotspot) and serves its egress from this machine, so the Space browses as this machine. Runs until hotspot_stop, delete_space, or this server exiting.

| | |
| --- | --- |
| Providers | all (cloud, local, direct, relay) |
| Platforms | all (macos, windows, linux) |
| Metering | free |
| Approval | permission `spaces:hotspot_start`; destructive |
| Requires (spacesd) | `hotspot` |
| Swift SDK | `connection.hotspot.start(sharingWith:)` |
| Rust | `Spaces::hotspot_start` |

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `bypass` | `string[]` | none | Destinations (CIDRs or host suffixes) that keep using the Space's own network. |
| `set_system_proxy` | `boolean` | `true` | Point the Space's system proxy (and `HTTP(S)_PROXY` for new processes) at the hotspot. Default true. |
| `space` | `string` | required | Space id or name. |

### Result

JSON: the hotspot (`space`, `state`, `hotspot_id`, `socks_address`, `active_connections`, `bytes_out`, `bytes_in`, `served_here`).

### Errors

[`invalid_argument`](/spaces/reference/errors#invalid_argument), [`not_found`](/spaces/reference/errors#not_found), [`ambiguous_sandbox`](/spaces/reference/errors#ambiguous_sandbox), [`spacesd_not_available`](/spaces/reference/errors#spacesd_not_available), [`capability_missing`](/spaces/reference/errors#capability_missing)

### Notes

- Capability-gated rather than cloud-only: any Space whose spacesd supports `hotspot` can borrow this machine's network.
