---
title: Cua Cloud (Fleets) has ended
description: Cua Cloud and Cua Fleets ended on 18 October 2026. What changed and where to run sandboxes now.
---

Cua Cloud, including Cua Fleets (pools, claims, warm replicas and the Terraform
provider), ended on 18 October 2026. The Fleets pages that used to be here have
been removed.

## What still works

The same SDK calls, images and `cua` CLI commands run anywhere else:

| Where | How | Guide |
| --- | --- | --- |
| This machine | `Sandbox.create(...)` (the default), `cua sb create` | [Set up local runtimes](/cua-sdk/guides/local-runtimes) |
| Your own AWS, Google Cloud or Modal account | `on="aws"`, `on="gcp"`, `on="modal"`; `--on aws` in the CLI | [Use your own cloud](/cua-sdk/guides/your-cloud) |
| A machine you run, shared with your team and agents | Cua Spaces | [Cua Spaces](/spaces) |

## In your code

`on="cloud"`, `local=False`, `--on cloud` and `pool:` image references fail
with this message:

```text output
Cua Cloud has ended; use a local sandbox or your own machine. See https://cua.ai/docs/cua-sdk/guides/cua-cloud-ended
```

`Cua.fleet()`, `cua fleet`, `cua pools`, `--pool`, `FLEETS_TOKEN`, cloud image
listings and cloud suspend, resume and extend-lease are removed from the SDKs and
the `cua` CLI.

Replace `on="cloud"` with a local runtime or your own cloud. Sidecars,
services, secrets and images work the same way there:
[Sidecars](/cua-sdk/guides/sidecars), [Services](/cua-sdk/guides/services),
[Secrets](/cua-sdk/guides/secrets), [Images](/cua-sdk/guides/images).

Fleet pool names, claim TTLs and warm-replica settings have no replacement.
Your own cloud gives each sandbox a time limit and cleans up after it
([Time limits and cleanup](/cua-sdk/guides/your-cloud#time-limits-and-cleanup)).
