### DaemonService.GetInfo

`/cua.daemon.v1.DaemonService/GetInfo`, unary: [`GetInfoRequest`](#getinforequest) to [`GetInfoResponse`](#getinforesponse).

Returns the daemon identity and its loopback endpoint.

### DaemonService.OpenMediaBridge

`/cua.daemon.v1.DaemonService/OpenMediaBridge`, unary: [`OpenMediaBridgeRequest`](#openmediabridgerequest) to [`OpenMediaBridgeResponse`](#openmediabridgeresponse).

Opens a media session in a sandbox and returns a loopback WebSocket URL
that relays it. The URL carries a short-lived bridge ticket; the
browser never sees the Fleet bearer or the spacesd token.

### DaemonService.Shutdown

`/cua.daemon.v1.DaemonService/Shutdown`, unary: [`ShutdownRequest`](#shutdownrequest) to [`ShutdownResponse`](#shutdownresponse).

Stops the daemon after the response is sent.
