## `Relay`

The signed-in account's view of a cua-relay.

| Method | Description |
| --- | --- |
| [`new`](#relaynew) | A relay (`None` = `CUA_RELAY_URL`, else `https://relay.cua.ai`) seen as the account behind `account_token` (a cua.ai access token). |
| [`connect`](#relayconnect) | Connects to a machine's spacesd through `<relay>/m/<id>`, with the account token as bearer (the relay swaps it for its signed identity). |
| [`machine`](#relaymachine) | One machine. |
| [`machines`](#relaymachines) | Machines the account owns or that are shared with it. |
| [`start_sharing`](#relaystart_sharing) | Accepts clients again. |
| [`stop_sharing`](#relaystop_sharing) | Cuts every client of a machine the account owns and refuses new ones. |

| Accessor | Returns | Description |
| --- | --- | --- |
| `url()` | `String` | Normalized relay base URL. |
