Recorded `cua do` trajectories.

```text output
cua trajectory [OPTIONS] <COMMAND>
```

Alias: `cua traj`.

## `cua trajectory ls`

List sessions.

```text output
cua trajectory ls [OPTIONS] [MACHINE]
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<MACHINE>` | string | optional | Only sessions of this target (sandbox name or `host`). |

**Examples**

```bash test="cli-shape" id="ref-cua-trajectory-ls"
cua traj ls

# Only the sessions recorded on the sandbox dev
cua traj ls dev
```

## `cua trajectory view`

Zip, serve on loopback and open the hosted viewer.

```text output
cua trajectory view [OPTIONS] [TARGET]
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<TARGET>` | string | optional | Session id or target name (default: the latest session). |

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-trajectory-view--port"></span>`--port` | `-p` | integer | `8089` | Loopback port of the file server. |

**Examples**

```bash test="cli-shape" id="ref-cua-trajectory-view"
# The latest session
cua traj view
cua traj view <session> --port 8090
```

## `cua trajectory clean`

Delete sessions.

```text output
cua trajectory clean [OPTIONS]
```

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-trajectory-clean--older-than"></span>`--older-than` |  | integer |  | Only sessions older than this many days. |
| <span id="cua-trajectory-clean--machine"></span>`--machine` |  | string |  | Only sessions of this target. |
| <span id="cua-trajectory-clean--yes"></span>`--yes` | `-y` | boolean | `false` | Do not ask for confirmation. |

**Examples**

```bash test="cli-shape" id="ref-cua-trajectory-clean"
# Sessions older than a week, without the prompt
cua traj clean --older-than 7 --yes
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
