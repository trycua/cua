What a host reports to whoever places Spaces and jobs on it: `HostNodeStatus` (kinds, runtimes, CPU and memory, jobs) and, in `HostNodeStatus.measured`, what it measures rather than reserves: available memory, memory pressure, and how many more VMs fit when VMs share snapshot memory.

Source: `libs/cua/proto/cua/env/v1/capacity.proto`.

## Types in `cua/env/v1/capacity.proto`

### HostMeasured

What a host measures rather than reserves, for placement
(`HostNodeStatus.measured`). Reservations count what Spaces may use; these
count what they use, so VMs restored from one snapshot, whose unwritten
memory is shared, fit many times more than their reservations say.

| Field | # | Type | Description |
| --- | --- | --- | --- |
| `memory_available_mb` | 1 | `uint64` | Memory the OS says new work can use now, in MiB, whatever reserves it (Linux `MemAvailable`; macOS `kern.memorystatus_level` of physical memory). 0: the OS does not say. |
| `memory_pressure` | 2 | `uint32` | Memory pressure: 0 normal, 1 warn (the OS compresses or swaps), 2 critical (it is about to kill processes). A scheduler sends nothing to a host at 2. |
| `vcpu_overcommit` | 3 | `float` | The host's VM CPU overcommit (`CUA_VM_VCPU_OVERCOMMIT`): a `vm` Space's vCPU reserves 1/this of a host CPU (`millicpus_*`), because VMs of rollouts and agents mostly wait. 0 or 1: none. |
| `vm_memory_known` | 4 | `bool` | `vm_memory_free_mb` and `vm_typical_mb` are measured (the host runs QEMU VMs and its OS reports memory). |
| `vm_memory_free_mb` | 5 | `uint64` | VM memory this host takes now, in MiB: what its VM memory cap (`CUA_VM_MAX_RSS_FRACTION` of physical memory), its available-memory floor and its hypervisor's VM limit leave, counting what VMs restored from one snapshot share once. For a `vm` Space a scheduler checks this, not the reservations in `HostNodeStatus.memory_free_mb`. |
| `vm_typical_mb` | 6 | `uint64` | What a running VM here uses (the median, MiB): what one more is expected to need. 0: no VM runs. |

### HostNodeStatus

A host as one of your machines that run work: what a scheduler reads to place Spaces
and jobs here (`GetHostSpacesResponse.node`, and every
`HostJobsService` answer, which doubles as the node's heartbeat).

| `host_time_ms` | 3 | `int64` | The host's wall clock when it answered (Unix milliseconds), for clock-skew detection. Leases never depend on it. |

| `memory_free_mb` | 7 | `uint64` | Of that, not reserved. |
