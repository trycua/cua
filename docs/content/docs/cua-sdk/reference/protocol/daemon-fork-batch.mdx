### ForkBatchService.ForkSandboxBatch

`/cua.daemon.v1.ForkBatchService/ForkSandboxBatch`, server stream: [`ForkSandboxBatchRequest`](#forksandboxbatchrequest) to [`ForkSandboxBatchResponse`](#forksandboxbatchresponse).

Forks many sandboxes from checkpoints at once, on this machine or
across your machines. Streams each fork as soon as it is ready (or
failed), then one `done`. A fork that fails does not stop the others,
and the batch runs to completion if the caller goes away.
