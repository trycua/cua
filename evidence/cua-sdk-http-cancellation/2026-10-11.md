# HTTP MCP reply cancellation evidence

Prepared by OpenAI Codex at Kevin's instruction. Local SDK correctness evidence,
2026-10-11 UTC, based on `e9dc65780bdbf6e68d42aafa959c1925dbba2a56`.

The transport honors pre-aborted signals and keeps its timer and caller listener
active through response-body consumption. Fetch errors remain `TransportError`;
body-reader errors remain unchanged. Cleanup runs on success and either failure.

Build, typecheck and `git diff --check` passed. Counts overlap between runs.
Native Node fetch and an actual loopback `node:http` fixture reproduced all three
failures. The caller abort is triggered after observed native response headers;
the valid partial body's remainder is released only after rejection is asserted.
The SDK timeout is 0.2 seconds. The external 1.5-second watchdog can only fail a
test, and socket teardown follows the assertion. Success, in-flight abort before
headers, bearer 401, one-time 404 reinitialization, and notifications are covered.
