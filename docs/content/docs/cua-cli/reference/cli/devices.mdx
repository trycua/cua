## `cua devices enroll`

Enroll this device. Right after a fresh `cua auth login` it enrolls at once (and replaces this machine's older device key, if any); otherwise it shows a one-time code to approve from an enrolled device (`cua devices approve <code>` or the Cua Spaces app).

```text output
cua devices enroll [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-devices-enroll--name"></span>`--name` | string |  | Display name (default: the host name). |
| <span id="cua-devices-enroll--relay"></span>`--relay` | string |  | Relay URL. |
| <span id="cua-devices-enroll--wait"></span>`--wait` | boolean | `false` | Wait (up to 10 minutes) until an enrolled device approves. |

**Examples**

```bash test="cli-shape" id="ref-cua-devices-enroll"
cua devices enroll
cua devices enroll --name "work laptop" --wait
```
