## `cua daemon start`

Start the daemon (in the background unless --foreground).

```text output
cua daemon start [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-daemon-start--socket"></span>`--socket` | path |  | Unix socket (default ~/.cua/cua.sock). |
| <span id="cua-daemon-start--loopback"></span>`--loopback` | string | `127.0.0.1:0` | Loopback address (default 127.0.0.1:0; "off" disables). |
| <span id="cua-daemon-start--foreground"></span>`--foreground` | boolean | `false` | Stay in the foreground. |

**Examples**

```bash test="cli-shape" id="ref-cua-daemon-start"
cua daemon start

# In the foreground, for a service manager
cua daemon start --foreground
```

## `cua daemon mcp`

Stdio MCP server backed by the daemon (started if needed): the Spaces contract tools plus the sandbox/computer/skills tools (same server as `cua mcp`).

```text output
cua daemon mcp [OPTIONS]
```

| Flag | Type | Default | Env var | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-daemon-mcp--permissions"></span>`--permissions` | string |  | `CUA_MCP_PERMISSIONS` | Comma-separated permissions or groups (default: all). |
| <span id="cua-daemon-mcp--sandbox"></span>`--sandbox` | string |  | `CUA_SANDBOX` | Default sandbox for computer tools. |

**Examples**

```bash test="cli-shape" id="ref-cua-daemon-mcp"
cua daemon mcp
cua daemon mcp --permissions spaces:all
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
