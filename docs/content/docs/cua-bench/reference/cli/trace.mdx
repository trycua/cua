## `cb trace view`

View a single trace in browser.

```text output
cb trace view <identifier>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<identifier>` | string | required | Run ID or session ID (e.g., "30c12572" or "task-30c12572-click-button-v0"). |

**Examples**

```bash test="cli-shape" id="ref-cb-trace-view"
# Open a run's trace
cb trace view 30c12572

# Open one session's trace
cb trace view task-30c12572-click-button-v0
```

## `cb trace traj`

View agent trajectories from a run in cua.ai/trajectory-viewer.

```text output
cb trace traj [OPTIONS] <identifier>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<identifier>` | string | required | Run ID (e.g., "30c12572"). |

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cb-trace-traj--port"></span>`--port` | `-p` | integer | `8090` | Local file server port (default: 8090). |

**Examples**

```bash test="cli-shape" id="ref-cb-trace-traj"
# Open a run's trajectories
cb trace traj 30c12572

# Serve the files on another port
cb trace traj 30c12572 --port 9000
```
