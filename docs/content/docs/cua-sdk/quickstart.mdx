Run a web server in a sandbox on your machine and call it. Sandboxes run
locally by default, so the code passes no location.

## Prerequisites

- Python 3.11 or newer:

```bash skip="host-install"
pip install cua-sandbox
```

- A container engine (Docker, Podman or Colima). Check the host and
  install what is missing:

```bash test="cli-shape" id="cua-runtime-doctor"
cua runtime doctor
cua runtime setup
```

## Run

<Tabs groupId="quickstart-run" persist items={['Python', 'CLI', 'TypeScript']}>
  <Tab value="Python">

```python title="quickstart.py" test="container" id="local-server" session="local"
import asyncio

from cua_sandbox import Image, Sandbox, http


async def main():
    async with Sandbox.ephemeral(
        Image.from_registry("python:3.12-slim"),
        command=["python", "-m", "http.server", "8000"],
        services={"web": 8000},
        wait_for=http("web", "/"),
    ) as sb:
        print((await sb.service("web").request("GET", "/")).status_code)
        print(await sb.service("web").url())


asyncio.run(main())
```

  </Tab>
  <Tab value="CLI">

```bash test="cli-shape" id="cua-sb-create"
cua sb create python:3.12-slim --name web \
  --service web=8000 --wait http:web/ \
  -- python -m http.server 8000
cua sb url web web
```

  </Tab>
  <Tab value="TypeScript">

```ts test="container" id="typescript"
import { embedded, http, SandboxCreateOptions } from '@trycua/cua';

const sb = await embedded().sandboxes().create(
  SandboxCreateOptions.create({
    image: 'python:3.12-slim',
    command: ['python', '-m', 'http.server', '8000'],
    services: new Map([['web', 8000]]),
    waitFor: [http('web', '/')],
  })
);
console.log(await sb.service('web').url());
await sb.delete_();
```

  </Tab>
</Tabs>

## Result

```text output
200
http://127.0.0.1:53817
```

The first start of an image pulls it, which can take a few minutes.

## Clean up

`Sandbox.ephemeral` deletes the sandbox when the block exits. A CLI sandbox
stays until you remove it: `cua sb rm web -f`. `cua cache du` shows what images and sandboxes
take on disk ([Disk usage](/cua-sdk/guides/disk-usage)).

## Images

Pass any registry reference. Each official tag resolves to the variant the
backend runs. Linux images run as user `cua` with passwordless `sudo`; open the desktop in
the browser with `cua sb view NAME` ([Browser view](/cua-sdk/guides/desktop#browser-view)). Full list:
[image catalog details](/cua-sdk/reference/os-image-catalog).
