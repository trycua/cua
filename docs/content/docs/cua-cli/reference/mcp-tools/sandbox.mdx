## `sandbox_list`

List sandboxes: local, direct and cloud (Fleet) ones by default, each row with location (local, cloud or direct). Pass location to list only one kind. If the cloud cannot be listed, the local rows come back with a warning.

Permission: `sandbox:list`.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="sandbox_list--location"></span>`location` | `"local" \| "cloud" \| "direct"` |  | Only sandboxes in this location: local, cloud or direct (default: all). |

## `sandbox_create`

Create a sandbox from any image. `on` says where (local, the default unless the user configured another with `cua config set default.on`; or cloud), `kind` what (auto, container, vm) and `runtime` which engine (auto, or gvisor, runc, qemu, lume locally; gvisor, kubevirt in the cloud); an impossible combination fails and lists the valid values. To browse the web, pass browser=true (and optionally url): it starts the canonical Linux image, registers it as a Space, launches Chromium with a throwaway profile inside it and returns the space, session, target_id and tab_id to pass to call_tool with the in-sandbox browser tools (browser_navigate, get_browser_state, browser_click, browser_type). Pass command, env and services to run a server in it, for example an MCP server: services &#123;"mcp": 8765&#125;. Without browser=true it does not register a Space: to reach its MCP server with list_tools/call_tool (service="mcp"), use create_space instead (same arguments), or add this one with add_space (address local:&lt;name&gt;).

Permission: `sandbox:create`.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="sandbox_create--browser"></span>`browser` | `boolean` |  | Start a browser in it, ready for the cua-driver browser tools (default image: the canonical Linux image). |
| <span id="sandbox_create--command"></span>`command` | `string[]` |  | Entrypoint override (argv), for example ["python", "-m", "my_mcp"]. |
| <span id="sandbox_create--env"></span>`env` | `object` |  | Environment variables (string values). |
| <span id="sandbox_create--image"></span>`image` | `string` |  | Image reference, any registry (overrides os_type). |
| <span id="sandbox_create--kind"></span>`kind` | `"auto" \| "container" \| "vm"` |  | What kind of machine: auto (default; from the image), container or vm. |
| <span id="sandbox_create--name"></span>`name` | `string` |  | Sandbox name. |
| <span id="sandbox_create--on"></span>`on` | `string` |  | Where it runs: local or cloud (default: the user's default location, else local). |
| <span id="sandbox_create--os_type"></span>`os_type` | `string` |  | linux (default) or macos. |
| <span id="sandbox_create--pool"></span>`pool` | `string` |  | Use this dedicated cloud pool (Fleets advanced; implies on=cloud). |
| <span id="sandbox_create--runtime"></span>`runtime` | `string` |  | Which engine: auto (default) or one the location offers for the kind (local: gvisor, runc, qemu, lume; cloud: gvisor, kubevirt). |
| <span id="sandbox_create--services"></span>`services` | `object` |  | Named services: name to guest port, for example &#123;"mcp": 8765&#125;; each is probed for readiness. |
| <span id="sandbox_create--url"></span>`url` | `string` |  | With browser=true: open this URL first. |

| <span id="sandbox_open_browser--session"></span>`session` | `string` |  | cua-driver session label to use on every later browser call (default: browse). |
| <span id="sandbox_open_browser--url"></span>`url` | `string` |  | Open this URL first. |

**Example arguments**
