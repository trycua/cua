Cua Driver exposes its native tools through MCP and the CLI. Tool names use
`snake_case`; `cua-driver <name> '<JSON-args>'` invokes the corresponding tool
from the shell.

## Native references

Use the reference for the machine running Cua Driver, not the machine running
your agent. Tool availability, arguments, action names, and accessibility
behavior can differ by operating system.

- [macOS MCP tools](/reference/cua-driver/mcp-tools-macos)
- [Linux MCP tools](/reference/cua-driver/mcp-tools-linux)

The Windows reference is pending in this draft migration. Use
`cua-driver list-tools` and `cua-driver describe <tool-name>` on Windows to
inspect its native definitions; neither page above substitutes for them.
