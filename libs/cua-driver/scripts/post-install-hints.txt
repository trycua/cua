  Permission modes:
     • standard is the promptless default for normal automation.
     • To use an existing logged-in Chrome or Edge profile in standard:
         {{BINARY}} mcp --grant existing-profile
       Add the same flag to `serve` when using a long-running daemon.
     • Use bounded with a reviewed manifest to limit tools, apps, browser
       profiles, origins, and file roots:
         {{BINARY}} serve --permission-mode bounded \
           --session-policy ./cua-session.yaml --approve-session-policy
     • unrestricted requires explicit risk acceptance:
         {{BINARY}} serve --permission-mode unrestricted \
           --dangerously-bypass-approvals
