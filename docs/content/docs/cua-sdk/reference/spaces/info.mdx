`SpaceInfo` is one row of a Spaces listing. `spaces_tool_methods` lists every Spaces tool with the method of `Spaces` or `Space` that covers it.

## `SpaceInfo` record

A registered Space.

Returned by [`Space.info`](/cua-sdk/reference/spaces/space#space), [`Spaces.add`](/cua-sdk/reference/spaces#spacesadd), [`Spaces.add_with_service`](/cua-sdk/reference/spaces#spacesadd_with_service), [`Spaces.list`](/cua-sdk/reference/spaces#spaceslist), [`Spaces.rename`](/cua-sdk/reference/spaces#spacesrename), [`Spaces.resolve`](/cua-sdk/reference/spaces#spacesresolve).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `String` |  | Id, for example `direct:10.0.0.5:3211` or `cloud:<name>` (the sandbox ref scheme). |
| `name` | `String` |  | Display name. |
| `display_name` / `displayName` | `String` | `""` | The name it was given with `Spaces.rename`, which apps show in place of `name`; empty when it keeps the one it was created with. A Space that is a machine on the relay is renamed there, so its `name` changes instead. |
| `provider` | `String` |  | `cloud`, `local`, `direct` or `relay` (the location words). |
| `spacesd_version` / `spacesdVersion` | `String` |  | spacesd version at the last handshake. |
| `features` | `Vec<String>` |  | Supported features at the last handshake. |
| `os` | `String` |  | Guest OS family at the last handshake: `linux`, `macos`, `windows`, or empty when not reported. |
| `os_name` / `osName` | `String` |  | Guest OS product or distribution at the last handshake ("Ubuntu", "macOS"), or empty when not reported. |
| `os_pretty_name` / `osPrettyName` | `String` |  | The guest's full OS string at the last handshake ("Ubuntu 24.04.3 LTS", "macOS 26.5.2 (25F84)"), or empty from older drivers. |
| `image` | `String` |  | The image the sandbox runs ("ghcr.io/trycua/linux:24.04"), or empty when unknown (a Space added by address). |
| `image_digest` / `imageDigest` | `String` |  | The digest of the variant that runs ("sha256:..."), or empty. |
| `kind` | `String` |  | `container`, `vm` or `microvm`, or empty when unknown. |
| `arch` | `String` |  | The guest's CPU architecture (`arm64`, `amd64`), or empty when unknown. |
| `services` | `Vec<String>` |  | Declared services (never `env`), reachable with `list_tools` / `call_tool` (`service`). A Space without cua-spacesd has an empty `features` list and only these. |
| `added_at` / `addedAt` | `Option<String>` |  | When it was added (RFC 3339). |
| `host` | `String` |  | For a Space one of your machines provides (created with `on="host:<machine>"`): that host's relay machine id; empty otherwise. Lists group these Spaces under their host. |
| `host_name` / `hostName` | `String` |  | The host's display name, when known. |
| `power` | `String` |  | How it turns off and on again (`Spaces.stop`, `Spaces.start`): `suspend` (its memory is kept), `stop` (its disk is kept), or empty when it cannot (a cloud Space, a Space added by address). |
| `power_state` / `powerState` | `String` |  | `running`, `suspended` or `stopped` as cua last recorded it; empty when unknown (a Space one of your machines provides answers while it runs). |
| `cloud` | `String` |  | A Space in your own cloud: the provider (`aws`, `gcp`, `hetzner`, `modal`); empty otherwise. |
| `cloud_place` / `cloudPlace` | `String` |  | Where it runs ("AWS · us-west-2"). |
| `cloud_delete` / `cloudDelete` | `String` |  | How `delete` would delete it permanently from here: `here` (this device created it), `host:<machine>` (the device that created it, through the relay) or `elsewhere` (only there; `remove` keeps it). Empty for other Spaces. |
| `durable` | `String` | `""` | A durable Space (`SpaceCreateOptions.durable`): its name. It is created again on another of your machines when its machine goes away, and keeps this name. Empty for other Spaces. |
| `stop_reason` / `stopReason` | `String` | `""` | Why a local Space stopped without being asked to, in plain words ("out of memory", "killed", "exited with code 1"); empty otherwise, and once it is started again. |
| `labels` | `HashMap<String, String>` |  | Labels set at create (`SpaceCreateOptions.labels`). |
| `expires_at_unix` / `expiresAtUnix` | `i64` |  | When the Space ends (Unix seconds), as set by `Spaces.set_lifetime`; 0 when it has none. |
| `on_expire` / `onExpire` | `String` |  | What happens then: `delete` or `suspend`; empty without a lifetime. |
| `created_at_unix` / `createdAtUnix` | `i64` |  | When the Space was created (Unix seconds; the time it was added, for a Space added by address); 0 when unknown. |
| `egress` | [`EgressPolicy`](/cua-sdk/reference/spaces#egresspolicy-record) |  | The egress policy last set on the Space; empty when it has none. |
| `egress_enforced` / `egressEnforced` | [`Option<EgressEnforcement>`](/cua-sdk/reference/spaces/space#egressenforcement-enum) |  | Where `egress` is enforced; `None` without one. |
| `network` | [`Option<NetworkSettings>`](/cua-sdk/reference/spaces/network#networksettings-record) |  | Its network settings; `None` for a Space this computer keeps no record of, or one created before they existed (it gets them on its next start). |
| `network_note` / `networkNote` | `Option<String>` |  | Why its network is not what was asked, in plain words (a runtime that can't protect it yet started it without network); `None` otherwise. |
| `network_notice_pending` / `networkNoticePending` | `bool` |  | An update changed its network settings (an old Space moved to the new defaults): say so once. |
| `parent` | `Option<String>` |  | The Space it was created from, by id; `None` for a top-level Space. |
| `root` | `Option<String>` |  | The top-level Space of its tree, by id; `None` for a top-level Space. |
| `depth` | `u32` |  | How far below its tree's top-level Space it is (0: top-level). |
| `children` | `bool` | `false` | It may make child Spaces of its own (`Spaces.set_children`). |
| `tree_address` / `treeAddress` | `Option<String>` | `None` | A VM's address in its tree (`198.19.0.0/16`), where the other members of its tree reach it; `None` otherwise. |
| `clipboard` | `String` |  | When viewers may move the clipboard between this computer and the Space: `viewing` (only while you're viewing, the default), `ask` or `off`. See `Spaces.set_clipboard`. |
| `volume` | `String` |  | What it sees of the Cua Volume: `own` (its own folder, the default) or `off`. See `Spaces.set_volume`. |
| `volumes` | [`Vec<VolumeMount>`](/cua-sdk/reference/spaces/volume#volumemount-record) |  | Named volumes mounted in the Space (see `SpaceCreateOptions.volumes`). |
| `sharing` | [`Option<SpaceSharing>`](/cua-sdk/reference/spaces/sharing#spacesharing-record) | `None` | A Space that is a machine on the relay: who owns it and who else has it, as this account sees it. `None` for other Spaces. |
