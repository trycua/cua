## VM images

VM images boot a guest operating system. A containerDisk is an OCI image that
packages a VM disk; it is not a desktop container that can be started with
`docker run`.

## Docker images

Docker images run desktop userspace in a container rather than booting a VM.
Use the Docker image below for the local Docker runtime, not the VM
containerDisk reference with the same repository name. The `docker-latest` tag
is mutable; pin a resolved digest when you need a reproducible image.

| OS    | Distribution / version | Architecture | Desktop | Docker registry image                                    |
| ----- | ---------------------- | ------------ | ------- | -------------------------------------------------------- |
| Linux | Ubuntu 24.04           | amd64, arm64 | XFCE    | `public.ecr.aws/k5j5w0x5/cua-ubuntu-24.04:docker-latest` |

The NixOS family listed above publishes VM containerDisks only; it does not
publish runnable Docker desktop variants.
