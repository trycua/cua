## `FileEntry` record

A file or directory in the guest.

Returned by [`SpacesdClient.list_dir`](#spacesdclientlist_dir), [`SpacesdClient.make_dir`](#spacesdclientmake_dir), [`SpacesdClient.move_path`](#spacesdclientmove_path), [`SpacesdClient.stat`](#spacesdclientstat).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `String` |  | Base name. |
| `path` | `String` |  | Absolute path. |
| `kind` | `String` |  | `file`, `directory`, `symlink` or `other`. |
| `size` | `u64` |  | Size in bytes. |
| `mode` | `u32` |  | Unix mode bits. |
| `modified_ms` / `modifiedMs` | `Option<i64>` |  | Modification time (Unix ms), when known. |
| `symlink_target` / `symlinkTarget` | `Option<String>` |  | Symlink target. |
| `owner` | `Option<String>` |  | Owning user name (a numeric id when the guest has no such user); `None` where the guest has no owners (Windows). |
| `group` | `Option<String>` |  | Owning group name; `None` where the guest has none (Windows). |
| `metadata` | `HashMap<String, String>` |  | Extended attributes under the call's `xattr_namespace` (default `user.cua.meta.`), without the prefix. Empty when there are none or the guest file system has no extended attributes. |

## `TransferResult` record

Result of an upload or download.

Returned by [`SpacesdClient.download_file`](#spacesdclientdownload_file), [`SpacesdClient.upload`](#spacesdclientupload), [`SpacesdClient.upload_file`](#spacesdclientupload_file).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `u64` |  | Bytes transferred. |
| `sha256` | `String` |  | SHA-256 (hex) of the content. |
| `resumes` | `u32` |  | Resumes after dropped connections. |

## `UploadOptions` record

Upload options.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `create_new` / `createNew` | `bool` | `false` | Fail when the file exists (instead of overwriting). |
| `append` | `bool` | `false` | Append instead of overwriting. |
| `permissions` | `u32` | `0` | Unix permissions (0 = default). |
| `create_parents` / `createParents` | `bool` | `true` | Create missing parent directories. |
| `user` | `Option<String>` | `None` | Guest user to write as: the file (and parents it creates) is owned by that user and the user's permissions apply. Needs a guest agent that runs as root or has passwordless `sudo` (the Linux images do); otherwise the call fails with a permission error that says why. |
| `metadata` | `Option<HashMap<String, String>>` | `None` | Extended attributes to store with the file, published atomically with its content. At most 32 keys; a key is 1-128 bytes of `A-Za-z0-9._:/@+-`, a value at most 1024 bytes, 3072 bytes in all. |
| `xattr_namespace` / `xattrNamespace` | `Option<String>` | `None` | Extended-attribute key prefix for `metadata` (and for the metadata reported back): must start with `user.` and end with `.`. Default `user.cua.meta.`. |
