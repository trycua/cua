## `cua spaces add`

Register a Space after a capabilities handshake with its cua-spacesd (or, for another URL, an MCP initialize). Re-adding an address updates it. The token is stored apart from the registry, 0600.

```text output
cua spaces add [OPTIONS] <URL>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<URL>` | string | required | The Space's cua-spacesd (`http(s)://host:port`, `host:port`, default port 3211), a Space id (`local:<name>`, `cloud:<name>`), or any MCP endpoint URL. |

| Flag | Type | Default | Env var | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-spaces-add--token"></span>`--token` | string |  | `CUA_ENV_TOKEN` | spacesd token (or the bearer an MCP endpoint needs). |
| <span id="cua-spaces-add--name"></span>`--name` | string |  |  | Display name (default: the guest's hostname). |
| <span id="cua-spaces-add--service"></span>`--service` | string |  |  | For an MCP endpoint URL: the service name to register it under (default `mcp`). |
| <span id="cua-spaces-add--host"></span>`--host` | boolean | `false` |  | It is a machine that provides Spaces over its direct address (Tailscale or LAN): `--on host:<name>` finds it without the relay. Its token is stored like any direct Space's. |

**Examples**

```bash test="cli-shape" id="ref-cua-spaces-add"
cua spaces add 10.0.0.5:3211 --token "$TOKEN" --name studio
cua spaces add local:my-sandbox
cua spaces add http://127.0.0.1:8765/mcp --service tools

# A machine that provides Spaces over Tailscale, without the relay (`cua host setup --direct ... --provide-spaces` on it prints this)
cua spaces add 100.101.102.103:3211 --host --name "Mac mini (spare)" --token "$TOKEN"
```

## `cua spaces create`

Create Spaces: on this machine, on one of your machines that provides Spaces (`cua host setup --provide-spaces` there), or in the cloud.

```text output
cua spaces create [OPTIONS] [IMAGE]
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<IMAGE>` | string | optional | Image: an alias (`linux`, `macos`, `macos:26`) or a registry reference. Default: the canonical Linux image. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-spaces-create--on"></span>`--on` | string |  | Where: `local`, `cloud`, `host:<machine>`, or a machine name (`mac-mini`, "spare mac mini"). Default: your default location. |
| <span id="cua-spaces-create--count"></span>`--count` | integer | `1` | How many (1 to 8). |
| <span id="cua-spaces-create--name"></span>`--name` | string |  | Name (with --count, `-2`, `-3`, ... are appended). |
| <span id="cua-spaces-create--kind"></span>`--kind` | string |  | auto \| container \| vm. |
| <span id="cua-spaces-create--runtime"></span>`--runtime` | string |  | auto, or an engine the location offers (lume, runc, gvisor, qemu). |
| <span id="cua-spaces-create--cpus"></span>`--cpus` | integer |  | vCPUs. |
| <span id="cua-spaces-create--memory-mb"></span>`--memory-mb` | integer |  | Memory in MiB. |
| <span id="cua-spaces-create--disk-gb"></span>`--disk-gb` | integer |  | Grow a VM's disk to this many GiB. |
| <span id="cua-spaces-create--gpu"></span>`--gpu` | string |  | A GPU: the runtime's own (`--gpu`), or an option `cua spaces gpus` lists. macOS VMs: GPU acceleration (experimental, Apple silicon; https://cua.ai/docs/lume/guides/gpu-passthrough). |

**Examples**

```bash test="cli-shape" id="ref-cua-spaces-create"
cua spaces create linux

# Two macOS VMs on your spare Mac mini (matched by name)
cua spaces create macos:26 --on "spare mac mini" --count 2
cua spaces create --on host:0123abcd4567ef89 linux --json
```


| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<SPACE>` | string | required | Space id, address or display name. |

| --- | --- | --- | --- |

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
