<Callout title="Cua Spaces app export">
These APIs are part of the Cua Spaces app export for building Spaces UIs. They are source-available under FSL-1.1-MIT and ship for Swift only (`import CuaSpacesFFI`); the Rust tab shows the `cua-spaces-ffi` crate they come from. The open source SDK packages for Python, TypeScript and Kotlin do not include them.
</Callout>

`app_experiments_page` derives the Experiments tab from the saved `AppExperiments`; `app_settings_choose_experiment` applies a switch and saves the New UI choice ("Use classic UI"). `app_settings_resolve_new_ui` applies the New UI default for the update channel and version. Off only hides a feature: a mounted Volume, a connected cloud and existing shares stay as they are.

## `AppExperiments` record

Returned by [`app_experiments_choose`](#app_experiments_choose), [`app_experiments_from_json`](#app_experiments_from_json).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `cua_volume` / `cuaVolume` | `bool` |  | Cua Volume in the first run and Settings, Storage. |
| `your_cloud` / `yourCloud` | `bool` |  | Your own clouds in the New Space wizard. |
| `sharing` | `bool` |  | Sharing a Space with other accounts. On unless turned off: a missing key reads as on (the plans on cua.ai/pricing list sharing). |
| `web_ui` / `webUi` | `bool` |  | The New UI (the shared web UI) is the main window: the user's choice or, without one, `new_ui_default` (`crate.settings.resolve_new_ui`). |
