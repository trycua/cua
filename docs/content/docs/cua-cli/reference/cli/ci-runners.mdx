<span id="cua-ci"></span>

Cua CI, GitHub Actions jobs on Cua Spaces: each job runs in a fresh Space (a macOS VM or a Linux container or VM) registered with a just-in-time runner, then deleted. Connect this computer, then use `runs-on: cua`. An experiment: `cua experiments enable ci-runners`.

```text output
cua ci [OPTIONS] <COMMAND>
```

**Examples**

```bash test="cli-shape" id="ref-cua-ci"
cua ci connect
cua ci status
cua ci logs
cua ci config --budget 50
cua ci disconnect
```

## `cua ci cache`

Empty the dependency caches and repository mirrors of this computer's pools, for a cold run (jobs restore nothing and the first checkout fetches in full).

```text output
cua ci cache [OPTIONS] <COMMAND>
```

**Examples**

```bash test="cli-shape" id="ref-cua-ci-cache"
cua ci cache clear
cua ci cache clear --pool trycua
```

### `cua ci cache clear`

Delete the caches, mirrors and golden saved starts.

```text output
cua ci cache clear [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-ci-cache-clear--pool"></span>`--pool` | string |  | Only this pool (default: every pool of this computer). |

**Examples**

```bash test="cli-shape" id="ref-cua-ci-cache-clear"
cua ci cache clear
cua ci cache clear --pool trycua
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no provider credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `8` | No room on the machine: its VMs are at their memory or CPU limit, or it is low on memory. |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
