Local is the default: `Sandbox.create(image)` runs on this machine, `on="aws"`, `"gcp"` or `"modal"` in your own cloud. `local=False` meant Cua Cloud, which ended on 18 October 2026: it fails with a clear error. `Sandbox.connect(name)` and the class methods take `local=None`: the local sandbox of that name when one exists.
