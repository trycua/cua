### thread_read

Read a Space's thread.

Every Space has one thread: what people and its agent members said, the tasks @mentions created and how they went. Without `after` it returns the newest entries (`before` pages back, `has_more_before` says whether there are older ones); pass the returned `cursor` as `after` to read on; `follow_ms` waits for the next entry (a check-in from any device). `mark_read` moves your read cursor, which `unread` counts from. Entries are never edited: a task's state is the last `task_update` entry for it, folded into `tasks`.

### thread_post

Post to a Space's thread.

Posts as you (the daemon stamps the author; it is never an argument). `@name` of an agent member of this Space makes the message a task for it: the daemon wakes the agent (restoring its home if it was asleep), delivers the message as its next turn, and posts its answer as a reply when the turn ends. An agent with several sessions gives it to its lowest free session (`to_session` picks one); a busy agent gets it after its current turn; a paused one keeps it queued. Text and attachment names that look like a secret are refused: secrets belong in the Keyvault. `view` says what the person is looking at in the Space as they post (its desktop, or a window by app, title and window_id); it is stored with the entry, so an agent reads which window "this" means.

### thread_claim

Claim a task.

Claims a task for one session of the agent, with a lease the daemon renews while that session works on it. A task another session holds is refused with `task_claimed`, naming the holder; when the lease runs out the task is queued again with a note. The daemon claims tasks itself when it gives one to a session; an agent calls this to take a task from its inbox while it works (for its own session).

### agent_set_rights

### thread_settings

Read or change a Space's thread settings.

Reads a Space's thread settings, or (the owner and admins) sets them. `ask_before_join` ("Ask before members' agents join", on by default): an agent redeemed by anyone other than this computer's own user waits until the owner or an admin answers its join request.

| | |
| --- | --- |
| Providers | all (cloud, local, direct, relay) |
| Platforms | all (macos, windows, linux) |
| Metering | free |
| Approval | permission `spaces:thread_settings`; mutating, idempotent |
| Swift SDK | `space.thread().settings(askBeforeJoin:)` |
| Rust | `Persistent::thread_settings` |

#### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `ask_before_join` | `boolean` | none | "Ask before members' agents join". Omit to read the settings. |
| `space` | `string` | required | Space id or name. |

#### Result

JSON: `space` and `ask_before_join`.

#### Errors

[`invalid_argument`](/spaces/reference#invalid_argument), [`not_found`](/spaces/reference#not_found), [`ambiguous_sandbox`](/spaces/reference#ambiguous_sandbox), [`permission_denied`](/spaces/reference#permission_denied)

### thread_device_revoke

Remove the agents connected from a computer.

Removes every agent connected from that computer (its member keys stop at once), with a note in each thread. `cua logout` and removing this computer from the account call it for this computer.

| | |
| --- | --- |
| Providers | all (cloud, local, direct, relay) |
| Platforms | all (macos, windows, linux) |
| Metering | free |
| Approval | permission `spaces:thread_device_revoke`; mutating, idempotent |
| Swift SDK | `Spaces.call_tool_json("thread_device_revoke")` |
| Rust | `Persistent::revoke_device` |

#### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `device` | `string` | required | The computer's device id. |

#### Result

JSON: `removed` (the handles of the agents removed).

#### Errors

[`invalid_argument`](/spaces/reference#invalid_argument), [`permission_denied`](/spaces/reference#permission_denied)
