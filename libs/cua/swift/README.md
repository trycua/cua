# Cua (Swift)

The cua SDK for Swift: `import Cua`. A generated UniFFI binding (`CuaSDK`)
over the Rust `cua-sdk` crate plus small conveniences; the same API as
Python and TypeScript, embedded or through `cua daemon`.

```swift
import Cua

let cua = try Cua.embedded()
let sb = try await cua.sandboxes().connectUrl(url: "http://10.0.0.5:3211", token: "t", name: "dev")
let env = try await sb.spacesd(probeTimeoutMs: nil)
let out = try await env.run(command: SpacesdCommand("uname", ["-a"]))
```

## Packaging

- **Release**: `cua_sdkFFI` is a `.binaryTarget` pointing at
  `CuaSDKFFI.xcframework.zip` (static `libcua_sdk.a` for macOS arm64+x86_64,
  optionally iOS), built by `scripts/build-xcframework.sh --zip`; the
  release workflow writes `releaseURL`/`releaseChecksum` in `Package.swift`.
- **Local XCFramework**: `CUA_SWIFT_XCFRAMEWORK=build/CuaSDKFFI.xcframework`.
- **Development**: `cargo build --release -p cua-sdk`, then
  `node ../scripts/stage-uniffi-library.mjs --only=swift` stages the host
  dylib in `lib/` (git-ignored, never committed); the system-library target
  links it. Re-stage after every SDK rebuild.

`Sources/CuaSDK` and `Sources/cua_sdkFFI` are generated by
`../scripts/generate-uniffi-bindings.mjs` (`--check` in CI).
