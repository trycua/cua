# OS icons

The Space tiles' OS icons (`notch::os_icon`). Every file except
`os-windows.svg` is from [Simple Icons](https://simpleicons.org) 16.32.0
(CC0-1.0); only icons without a copyleft license entry are used. `os-windows.svg`
is the four-square mark drawn here. The marks are trademarks of their owners,
used only to name the operating system a Space runs. The Omarchy mark is
MIT-licensed by the Omarchy project.
