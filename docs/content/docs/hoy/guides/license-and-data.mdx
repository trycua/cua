## License

The Hoy End User License Agreement (EULA) sets the terms of use. It allows
commercial use and any number of Macs. A copy is the `LICENSE` file in the
release folder, `~/.local/hoy/current/LICENSE`. For questions about the license,
write to [hoy@cua.ai](mailto:hoy@cua.ai).

Apple's macOS license applies to every macOS VM you run, and it is where the
[2-VM limit](/hoy/concepts/two-vm-limit) comes from. Hoy contains no Apple
software. You make your images on your own Mac from Apple's restore image.

A license key is optional. The email with your download link has a key that
identifies your install, and `hoy license install <file>` stores it. A key
unlocks nothing, and Hoy never checks it while running.

## Data

Registration gives you a personal download token for the installer, and tells us
which Macs and macOS versions to test next. Cua's
[privacy policy](https://cua.ai/privacy-policy) covers what we do with it.

Hoy sends Cua crash reports and basic usage counts. Each has its own switch,
both are on by default, and turning either off changes no feature. Guest
contents are never collected.

```bash skip="no-runner"
hoy config show
hoy config set crash-reports off
hoy config set usage-data off
```

`DO_NOT_TRACK=1`, `CUA_TELEMETRY=0` and `cua telemetry off` turn both off too.
Usage is sent at most once a day, and crash reports once each, by Hoy's background service. The
exact payloads, how they are sent and how to preview them are in
[Data collection](/hoy/guides/data-collection).

Hoy also asks once a day whether a newer release is out. That is not telemetry,
and you can turn it off: see [Update and rollback](/hoy/guides/update-and-rollback).
