| `Back` | Back one page (not from Welcome or Done). |
| `TelemetryLoaded` | The machine's telemetry setting, as the shell read it. Any page. Fields: `telemetry: AppTelemetryInput` |
| `UsageDataToggled` | Welcome's "Share anonymous usage data" switch (not while the environment decides). The shell writes the setting. Fields: `on: bool` |
| `ExperimentsLoaded` | Settings, Experiments, as the shell read them (at the start, and whenever a switch changes). Any page; turning Cua Volume off on its page moves on. Fields: `experiments: AppExperiments` |
