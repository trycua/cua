## `set_agent_cursor_enabled`

Show or hide the agent cursor owned by a session.

Effect: mutating, idempotent. Platforms: macOS, Linux, Windows.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="set_agent_cursor_enabled--enabled"></span>`enabled` | `boolean` | required | `true` shows the session's agent cursor overlay; `false` hides it. |
| <span id="set_agent_cursor_enabled--session"></span>`session` | `string` | required | Public label of the session that owns the cursor. |

**Example arguments**

```json
{"session":"<session>","enabled":false}
```

| <span id="set_agent_cursor_motion--session"></span>`session` | `string` | required | Public label of the session that owns the cursor. Omitted or null motion fields keep their current value. |
| <span id="set_agent_cursor_motion--style"></span>`style` | `"signature_arc" \| "spring_settle" \| "magnetic" \| "comet_swoop" \| "adaptive" \| "classic"` |  | Trajectory style. `signature_arc` (default) is one arc with a small follow-through; `spring_settle` lands with one soft bounce; `magnetic` is pulled into the target; `comet_swoop` is a wide arc with a short trail; `adaptive` picks a careful approach for small targets and a swoop for long moves; `classic` is the previous Dubins glide. When the theme's reduced motion is on, every move is a short straight glide with no effects. |
| <span id="set_agent_cursor_motion--timing"></span>`timing` | `"native" \| "fitts" \| "fixed"` |  | `native` uses the style's own timing; `fitts` scales the move time with distance and target size; `fixed` uses glide_duration_ms (1430 ms when 0). |

## `set_agent_cursor_theme`

Select an already-installed cursor theme for a session.

Effect: mutating, idempotent. Platforms: macOS, Linux, Windows.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="set_agent_cursor_theme--reduced_motion"></span>`reduced_motion` | `"auto" \| "on" \| "off"` | `"auto"` | Theme animation policy: `on` uses the theme's reduced-motion frames, `off` always animates, `auto` (default) leaves the choice to the host. |
| <span id="set_agent_cursor_theme--session"></span>`session` | `string` | required | Public label of the session that owns the cursor. |
| <span id="set_agent_cursor_theme--theme_id"></span>`theme_id` | `string` | required | Id of an installed cursor theme (see `cua-driver cursor-theme list`). |

**Example arguments**

```json
{"session":"<session>","theme_id":"<theme_id>"}
```
