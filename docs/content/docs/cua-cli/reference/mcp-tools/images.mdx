## `images_list`

List the sandbox image catalog (the images the docs list): ref, OS, container or VM, local and cloud runtime, whether it ships cua-spacesd and which browsers, its other variants, and the command that creates it. browser_tools=true means the in-sandbox cua-driver browser tools can drive its browser. Call this first to choose an image.

Permission: `images:list`.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="images_list--all"></span>`all` | `boolean` |  | Include unpublished entries (benchmark images). |
| <span id="images_list--browser"></span>`browser` | `boolean` |  | Only images whose browser the cua-driver browser tools drive. |
| <span id="images_list--os"></span>`os` | `string` |  | Only this OS: linux, windows or macos. |
