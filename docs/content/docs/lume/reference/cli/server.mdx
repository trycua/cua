## `lume serve`

Start the VM management server.

Serves the HTTP API on localhost, or with --mcp an MCP server over stdio for AI agents.

```text output
lume serve [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume-serve--port"></span>`--port` | integer | `7777` | Port to listen on (HTTP mode only). |
| <span id="lume-serve--mcp"></span>`--mcp` | boolean | `false` | Run as an MCP server (stdio transport) for AI agents. |

**Examples**

```bash test="cli-shape" id="ref-lume-serve"
# HTTP API on http://localhost:7777
lume serve
lume serve --port 7778

# MCP server over stdio (what MCP clients launch)
lume serve --mcp
```

## `lume dump-docs`

Output CLI and API documentation as JSON for tooling and integrations.

Emits the CLI, HTTP API or MCP tool metadata (arguments, options, flags, endpoints, tool schemas, help text, defaults and types) that the generated reference is built from.

```text output
lume dump-docs [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume-dump-docs--type"></span>`--type` | `cli` \| `api` \| `mcp` \| `all` | `cli` | Documentation type to output. |
| <span id="lume-dump-docs--pretty"></span>`--pretty` | boolean | `false` | Pretty-print the JSON output with sorted keys. |

**Examples**

```bash test="cli-shape" id="ref-lume-dump-docs"
lume dump-docs --type cli --pretty

# The MCP server's tool list
lume dump-docs --type mcp
```
