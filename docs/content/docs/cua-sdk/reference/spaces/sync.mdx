`Spaces.sync` sends a host folder to a Space the way git sees it (`.gitignore` and `.git` left out by default) and only the files that changed since the last sync, as one compressed archive. Changed files get the time of the sync, so incremental builds rebuild exactly them; files an earlier sync put there that are gone here are deleted, and nothing else in the destination is touched.

## Sync

Methods of [`Spaces`](/cua-sdk/reference/spaces#spaces).

### `Spaces.sync`

Makes `dest` in Space `space` hold what the host folder `path` holds
now, sending only what changed since the last sync to it (`.gitignore`
and `.git` left out by default). Changed files get the time of the
sync, so incremental builds rebuild exactly them; files an earlier
sync put there that are gone here are deleted; nothing else in
`dest` is touched.

## `SpaceSyncOptions` record

What `Spaces.sync` takes from the folder.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `gitignore` | `bool` | `true` | Leave out what `.gitignore` leaves out. |
| `include_git` / `includeGit` | `bool` | `false` | Take the `.git` directory too. |
| `delete` | `bool` | `true` | Delete files an earlier sync put there that are gone here. |
| `exclude` | `Vec<String>` | `[]` | More to leave out: gitignore-style patterns. |
