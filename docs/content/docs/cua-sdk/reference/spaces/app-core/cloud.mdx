`app_cloud_connect_reduce` applies an action and `app_cloud_connect_view` derives the sheet; its `request` is the `cloud_test` or `cloud_connect` call to run. `app_connected_clouds_from_status_json` turns the SDK's `cloud_status` into the wizard's `clouds`.
