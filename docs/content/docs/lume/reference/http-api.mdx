HTTP API for managing macOS and Linux virtual machines

Documented against Lume **0.7.0**. Run `lume --version` for your installed version.

## Default URL

```
http://localhost:7777
```

Start the server with `lume serve` or specify a custom port with `lume serve --port <port>`.

## MCP tools

`lume serve --mcp` serves these tools over stdio. See [Connect an MCP client](/lume/guides/manage-vms#connect-an-mcp-client) for client setup.

### VM tools

#### `lume_list_vms`

List all virtual machines with their status, IP addresses, and resource allocation.

Effect: read-only, idempotent.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_list_vms--storage"></span>`storage` | `string` |  | Optional storage location name or path to filter VMs. |

#### `lume_get_vm`

Get detailed information about a specific VM including IP address, VNC URL, and SSH availability.

Effect: read-only, idempotent.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_get_vm--name"></span>`name` | `string` | required | Name of the VM. |
| <span id="lume_get_vm--storage"></span>`storage` | `string` |  | Optional storage location name or path. |

**Example arguments**

```json
{"name":"<name>"}
```

#### `lume_run_vm`

Start a VM with optional shared directory for file access. The shared directory will be available at /Volumes/My Shared Files inside the VM.

Effect: mutating.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_run_vm--name"></span>`name` | `string` | required | Name of the VM to start. |
| <span id="lume_run_vm--no_display"></span>`no_display` | `boolean` |  | Run headless without VNC window (default: true). |
| <span id="lume_run_vm--shared_dir"></span>`shared_dir` | `string` |  | Host directory path to share with the VM (appears at /Volumes/My Shared Files). |
| <span id="lume_run_vm--storage"></span>`storage` | `string` |  | Optional storage location name or path. |
| <span id="lume_run_vm--vnc"></span>`vnc` | `"enabled" \| "disabled"` |  | VNC server policy. 'disabled' starts no VNC listener and reports a null vncUrl (default: enabled). |

**Example arguments**

```json
{"name":"<name>"}
```

#### `lume_stop_vm`

Stop a running VM gracefully.

Effect: mutating.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_stop_vm--name"></span>`name` | `string` | required | Name of the VM to stop. |
| <span id="lume_stop_vm--storage"></span>`storage` | `string` |  | Optional storage location name or path. |

**Example arguments**

```json
{"name":"<name>"}
```

#### `lume_clone_vm`

Clone a VM to create a copy. Useful for creating golden images for instant reset.

Effect: mutating.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_clone_vm--name"></span>`name` | `string` | required | Name of the source VM to clone. |
| <span id="lume_clone_vm--new_name"></span>`new_name` | `string` | required | Name for the cloned VM. |

**Example arguments**

```json
{"name":"<name>","new_name":"<new_name>"}
```

#### `lume_delete_vm`

Delete a VM and all its associated files.

Effect: destructive.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_delete_vm--name"></span>`name` | `string` | required | Name of the VM to delete. |
| <span id="lume_delete_vm--storage"></span>`storage` | `string` |  | Optional storage location name or path. |

**Example arguments**

```json
{"name":"<name>"}
```

#### `lume_create_vm`

Create a new macOS VM asynchronously. Returns immediately while the VM is being provisioned. Poll lume_list_vms or lume_get_vm to check progress (status will be 'provisioning' until complete).

Effect: mutating.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_create_vm--cpu"></span>`cpu` | `integer` |  | Number of CPU cores (default: 4). |
| <span id="lume_create_vm--disk_size"></span>`disk_size` | `string` |  | Disk size, e.g., '100GB' (default: 100GB). |
| <span id="lume_create_vm--ipsw"></span>`ipsw` | `string` |  | Path to IPSW file or 'latest' to download (default: latest). |
| <span id="lume_create_vm--memory"></span>`memory` | `string` |  | Memory size, e.g., '8GB' (default: 8GB). |
| <span id="lume_create_vm--name"></span>`name` | `string` | required | Name for the new VM. |
| <span id="lume_create_vm--storage"></span>`storage` | `string` |  | Optional storage location name or path. |
| <span id="lume_create_vm--unattended"></span>`unattended` | `string` |  | Unattended setup preset (e.g., 'tahoe', 'sequoia') for automatic macOS configuration. |

**Example arguments**

```json
{"name":"<name>"}
```

#### `lume_resize_disk`

Grow a stopped VM's disk. For macOS VMs this preserves the paired RecoveryOS partition (relocating it to the new end of disk) and expands the main APFS container so future macOS updates keep working. Grow-only; the VM must be stopped; may take several minutes.

Effect: destructive.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_resize_disk--disk_size"></span>`disk_size` | `string` | required | New disk size, e.g., '100GB'. Must be larger than the current size. |
| <span id="lume_resize_disk--dry_run"></span>`dry_run` | `boolean` |  | Validate and print the resize plan without modifying the disk. Default false. |
| <span id="lume_resize_disk--keep_backup"></span>`keep_backup` | `boolean` |  | Keep the rollback backup after a successful resize; cannot be combined with no_backup. Default false. |
| <span id="lume_resize_disk--name"></span>`name` | `string` | required | Name of the VM to resize. |
| <span id="lume_resize_disk--no_backup"></span>`no_backup` | `boolean` |  | Skip the pre-resize backup (faster, but no automatic rollback on failure). Default false. |
| <span id="lume_resize_disk--storage"></span>`storage` | `string` |  | Optional storage location name or path. |

**Example arguments**

```json
{"name":"<name>","disk_size":"<disk_size>"}
```

### Guest tools

#### `lume_exec`

Execute a command inside a running VM via SSH. Requires SSH to be enabled in the VM (default for VMs created with --unattended tahoe).

Effect: destructive.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume_exec--command"></span>`command` | `string` | required | Shell command to execute inside the VM. |
| <span id="lume_exec--name"></span>`name` | `string` | required | Name of the VM. |
| <span id="lume_exec--password"></span>`password` | `string` |  | SSH password (default: lume). |
| <span id="lume_exec--storage"></span>`storage` | `string` |  | Optional storage location name or path. |
| <span id="lume_exec--user"></span>`user` | `string` |  | SSH username (default: lume). |

**Example arguments**

```json
{"name":"<name>","command":"<command>"}
```

### Maintenance tools

#### `check_for_update`

Check the saved stable/nightly Lume channel for a release on GitHub. Returns current and selected channels. Read-only; never installs. Mirrors `lume check-update --json`.

Effect: read-only, idempotent.

No parameters.
