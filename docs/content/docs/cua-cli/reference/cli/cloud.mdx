## `cua cloud connect`

Connect a cloud account Spaces can be created in (after the checks `cua cloud test` runs). Credentials stay in the cloud's own CLI; Cua stores only the profile, region, project or environment names.

```text output
cua cloud connect [OPTIONS] <PROVIDER>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<PROVIDER>` | string | required | `aws`, `gcp` or `modal`. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-cloud-connect--profile"></span>`--profile` | string |  | AWS profile (`~/.aws/config`) or Modal profile (`~/.modal.toml`). |
| <span id="cua-cloud-connect--region"></span>`--region` | string |  | AWS or Google Cloud region. |
| <span id="cua-cloud-connect--zone"></span>`--zone` | string |  | Google Cloud zone (default: the region's `-a` zone). |
| <span id="cua-cloud-connect--project"></span>`--project` | string |  | Google Cloud project (default: `gcloud config get project`). |
| <span id="cua-cloud-connect--environment"></span>`--environment` | string |  | Modal environment (default: the profile's). |
| <span id="cua-cloud-connect--ttl-hours"></span>`--ttl-hours` | integer |  | Delete each Space there after this many hours (default 8; 0: never; Modal caps a sandbox at 24). |
| <span id="cua-cloud-connect--default"></span>`--default` | boolean | `false` | Also make it the default location (`default.on`). |

**Examples**

```bash test="cli-shape" id="ref-cua-cloud-connect"
cua cloud connect aws --region us-west-2 --default
cua cloud connect aws --profile sandbox
cua cloud connect gcp --project my-project --region us-central1
cua cloud connect modal --environment spaces

# Spaces there delete themselves after 4 hours (default 8; 0: never)
cua cloud connect aws --ttl-hours 4
```

## `cua cloud sweep`

Find what Cua left in your clouds: expired Spaces and resources whose Space is gone (with --all, every Cua resource). Lists them unless --delete. Only resources Cua tagged and recorded are ever touched.

```text output
cua cloud sweep [OPTIONS] [PROVIDER]
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<PROVIDER>` | string | optional | Only this cloud. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-cloud-sweep--delete"></span>`--delete` | boolean | `false` | Delete what it finds (default: list only). |
| <span id="cua-cloud-sweep--all"></span>`--all` | boolean | `false` | Include Cua resources that have not expired (every Space there). |

**Examples**

```bash test="cli-shape" id="ref-cua-cloud-sweep"
cua cloud sweep
cua cloud sweep aws --delete
cua cloud sweep --all --delete
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
