### `Space.put_service`

Keeps a command running in this Space (replacing a service of that
name): restarted by its policy when it ends or fails its health
check, started when the Space boots, its output kept in a log file.

## `SpaceServiceDef` record

A command a Space keeps running (`Space.put_service`).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `String` |  | Name: lowercase letters, digits, `-`, `_`, `.` (1 to 63). |
| `command` | `String` |  | The shell command line it runs. |
| `env` | `HashMap<String, String>` | `[:]` | Extra environment. |
| `cwd` | `Option<String>` | `None` | Working directory. |
| `restart` | `Option<String>` | `None` | When it is started again: `always` (default), `on-failure` or `never`. |
| `probe` | [`Option<SpaceServiceProbe>`](#spaceserviceprobe-record) | `None` | A health check; failing it restarts the service. |
| `start_on_boot` / `startOnBoot` | `Option<bool>` | `None` | Start it when the Space boots. `None`: yes. |

## `SpaceServiceProbe` record

A health check: exactly one of `http`, `tcp`, `command`.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `http` | `Option<String>` | `None` | A URL that answers 2xx or 3xx. |
| `tcp` | `Option<String>` | `None` | `host:port` that accepts a TCP connection. |
| `command` | `Option<String>` | `None` | A shell command that exits 0 when healthy. |
| `interval_secs` / `intervalSecs` | `Option<u64>` | `None` | Seconds between checks (default 10). |
| `failures` | `Option<u32>` | `None` | Failed checks in a row that restart it (default 3). |

## `SpaceServiceInfo` record

A service and how it is doing (`Space.services`).

Returned by [`Space.kept_services`](#spacekept_services), [`Space.put_service`](#spaceput_service), [`Space.restart_service`](#spacerestart_service), [`Space.start_service`](#spacestart_service), [`Space.stop_service`](#spacestop_service).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `String` |  | Name. |
| `command` | `String` |  | The command line. |
| `state` | `String` |  | `starting`, `running`, `unhealthy`, `backoff`, `stopped`, `exited` or `failed`. |
| `pid` | `u32` |  | Its process, while it runs. |
| `restarts` | `u32` |  | Starts after the first. |
| `last_end` / `lastEnd` | `String` |  | How the last process ended, if one did. |
| `probe_error` / `probeError` | `String` |  | The last failed health check, if the last one failed. |
| `restart` | `String` |  | `always`, `on-failure` or `never`. |
| `start_on_boot` / `startOnBoot` | `bool` |  | Starts when the Space boots. |
| `log_path` / `logPath` | `String` |  | Its log file in the Space. |
