## `cb dataset build`

Build a dataset from batch outputs.

```text output
cb dataset build [OPTIONS] <outputs_path> [<max_samples>]
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<outputs_path>` | string | required | Path to outputs folder from batch dump (e.g., ./outputs or /tmp/td_output). |
| `<max_samples>` | integer | optional | Limit number of samples processed (useful for testing). |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cb-dataset-build--mode"></span>`--mode` | string | `aguvis-stage-1` | Processing mode: aguvis-stage-1 (action augmentation) or gui-r1 (low-level click). |
| <span id="cb-dataset-build--dataset-name"></span>`--dataset-name` | string |  | Dataset name when saving to disk (default: td_&lt;mode&gt;_dataset). |
| <span id="cb-dataset-build--save-dir"></span>`--save-dir` | string |  | Directory to save a JSONL dataset (default: &lt;outputs&gt;/processed if not pushing). |
| <span id="cb-dataset-build--repo-id"></span>`--repo-id` | string |  | HF Hub repository ID (e.g., username/repo). Required with --push-to-hub. |
| <span id="cb-dataset-build--push-to-hub"></span>`--push-to-hub` | boolean | `false` | Push the dataset to the Hugging Face Hub. |
| <span id="cb-dataset-build--private"></span>`--private` | boolean | `false` | When pushing to hub, create/update the repo as private. |

**Examples**

```bash test="cli-shape" id="ref-cb-dataset-build"
# Build an aguvis-stage-1 dataset from run outputs
cb dataset build ./outputs

# Build 100 gui-r1 samples
cb dataset build ./outputs 100 --mode gui-r1

# Push a private dataset to the Hugging Face Hub
cb dataset build ./outputs --push-to-hub --repo-id me/cua-clicks --private
```
