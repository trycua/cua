<span id="cua-viewer"></span>

Serve the HTML5 viewer for every sandbox on one loopback port.

```text output
cua viewer [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-viewer--listen"></span>`--listen` | string | `127.0.0.1:0` | Address to listen on (loopback only). |
| <span id="cua-viewer--no-open"></span>`--no-open` | boolean | `false` | Print the URL without opening a browser. |

**Examples**

```bash test="cli-shape" id="ref-cua-viewer"
# List your sandboxes in the browser and open any of them
cua viewer

# Fixed port, print the URL only
cua viewer --listen 127.0.0.1:8211 --no-open
```

| Code | Meaning |

| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
