`set_sleep` says when a Space goes to sleep on its own: `never` (it keeps running), `auto` (once nothing in it runs; it wakes when something needs it) or a duration such as `10m`. A Space with no setting is `never`, except a home an agent works in. `keep_awake` holds a Space awake for up to two hours, whatever its setting says.

### `Spaces.set_volume`

Sets when a Space's viewers may move the clipboard between this
computer and the Space: `viewing` (only while you're viewing, the
default), `ask` or `off`. It applies to viewers opened afterwards.
The agent tools `computer_clipboard_*` act inside the Space and are
not affected. Another word is `InvalidArgument`.
Sets what a Space sees of the Cua Volume: `own` (its own folder) or
`off`. Applies now: `off` unmounts the Volume (named volumes it
mounted stay).

## `KeepAwakeInfo` record

A keep-awake that holds (`Spaces.keep_awake`).

Returned by [`Spaces.keep_awake`](#spaceskeep_awake).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `until_unix` / `untilUnix` | `i64` |  | When it ends, Unix seconds; 0 when none holds. |
| `capped` | `bool` |  | The ask was longer than the two-hour limit and was cut. |
