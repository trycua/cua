# OpenKoalaBots artwork

Original koala artwork for the three OpenKoalaBots samples. Made for this
repository; no third-party marks.

| File | Use |
|---|---|
| `app-icon.svg` | App icon (Tauri icons are rendered from it) |
| `koala-mark.svg` | The mark: sidebar header, avatars, the empty chat |
| `koala-peek.svg` | Empty states (no Space yet) |
| `koala-sleep.svg` | Idle states (a Bot with nothing to do) |

The shapes are circles, ellipses and a few paths, so the Swift sample draws
the same koala with SwiftUI shapes (`Design/KoalaArt.swift`).
