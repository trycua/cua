Encrypted, metadata-only Computer History early preview: lifecycle and local inspection.

The daemon must be admitted for the preview (`cua-driver serve --experimental-history`); `enable` restarts a local daemon with it when needed.

```text output
cua-driver history [OPTIONS] [COMMAND]
```

Without a subcommand, runs `cua-driver history status`.

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-driver-history--socket"></span>`--socket` | string |  | Override the daemon socket or named-pipe path. |
| <span id="cua-driver-history--json"></span>`--json` | boolean | `false` | Emit machine-readable output. |
