## `lume pull`

Pull a prebuilt or custom macOS image from an OCI-compatible registry.

```text output
lume pull [OPTIONS] <image> [<name>]
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<image>` | string | required | Image to pull (format: name:tag). |
| `<name>` | string | optional | Name for the resulting VM (defaults to the image name without its tag). |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume-pull--registry"></span>`--registry` | string | `ghcr.io` | Container registry to pull from. |
| <span id="lume-pull--organization"></span>`--organization` | string | `trycua` | Organization to pull from. |
| <span id="lume-pull--storage"></span>`--storage` | string |  | VM storage location name, or a direct path to the VM location. |
| <span id="lume-pull--username"></span>`--username` | string |  | Registry username for authentication. |
| <span id="lume-pull--password"></span>`--password` | string |  | Registry password for authentication. |
| <span id="lume-pull--force"></span>`--force` | boolean | `false` | Download again even if the image is cached. |
| <span id="lume-pull--verbose"></span>`--verbose` | boolean | `false` | Enable verbose logging. |

**Examples**

```bash test="cli-shape" id="ref-lume-pull"
# Pull an image from ghcr.io/trycua as a VM named macos-tahoe-vanilla
lume pull macos-tahoe-vanilla:latest

# Pull it as my-vm into another storage location
lume pull macos-tahoe-vanilla:latest my-vm --storage external
```

## `lume push`

Push a macOS VM to an OCI-compatible registry.

```text output
lume push [OPTIONS] <name> <image>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<name>` | string | required | Name of the VM to push. |
| `<image>` | string | required | Image tag to push (format: name:tag). |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume-push--additional-tags"></span>`--additional-tags` | string |  | Additional tags to push the same image to. Takes one or more values. |
| <span id="lume-push--registry"></span>`--registry` | string | `ghcr.io` | Container registry to push to. |
| <span id="lume-push--organization"></span>`--organization` | string | `trycua` | Organization to push to. |
| <span id="lume-push--storage"></span>`--storage` | string |  | VM storage location to use. |
| <span id="lume-push--chunk-size-mb"></span>`--chunk-size-mb` | integer | `512` | Chunk size for large files, in MB. |
| <span id="lume-push--verbose"></span>`--verbose` | boolean | `false` | Enable verbose logging. |
| <span id="lume-push--dry-run"></span>`--dry-run` | boolean | `false` | Prepare files without uploading to the registry. |
| <span id="lume-push--reassemble"></span>`--reassemble` | boolean | `false` | With --dry-run, also reassemble the chunks to verify integrity. |
| <span id="lume-push--single-layer"></span>`--single-layer` | boolean | `false` | Push the disk as a single layer (kubelet-compatible, no chunking). |
| <span id="lume-push--legacy"></span>`--legacy` | boolean | `false` | Use the legacy Lume LZ4-chunked format instead of the OCI-compliant format. |

**Examples**

```bash test="cli-shape" id="ref-lume-push"
# Push my-vm as ghcr.io/my-org/my-image:latest
lume push my-vm my-image:latest --organization my-org

# Push one image under several tags
lume push my-vm my-image:1.0 --additional-tags latest stable

# Prepare and verify the chunks without uploading
lume push my-vm my-image:latest --dry-run --reassemble
```

## `lume convert`

Convert a legacy Lume image to OCI-compliant format.

Pulls a legacy Lume image from the registry, pushes it again in OCI-compliant format under a new name and tag, then removes the temporary local VM.

```text output
lume convert [OPTIONS] <source-image> <target-image>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<source-image>` | string | required | Source image to convert (legacy format, for example macos-tahoe:latest). |
| `<target-image>` | string | required | Target image to push in OCI format (format: name:tag). |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume-convert--additional-tags"></span>`--additional-tags` | string |  | Additional tags to push the OCI image to. Takes one or more values. |
| <span id="lume-convert--registry"></span>`--registry` | string | `ghcr.io` | Registry to pull from and push to. |
| <span id="lume-convert--organization"></span>`--organization` | string | `trycua` | Registry organization. |
| <span id="lume-convert--verbose"></span>`--verbose` | boolean | `false` | Enable verbose logging. |
| <span id="lume-convert--dry-run"></span>`--dry-run` | boolean | `false` | Prepare files without uploading to the registry. |
| <span id="lume-convert--single-layer"></span>`--single-layer` | boolean | `false` | Push the disk as a single layer (kubelet-compatible, no chunking). |

**Examples**

```bash test="cli-shape" id="ref-lume-convert"
lume convert macos-tahoe:latest macos-tahoe:latest-oci
```
