## stream_endpoint

Return a ticketed media endpoint for the Space's desktop or one window.

Opens a media session (StreamService.OpenMedia) for the desktop or one window and returns its ticketed WebSocket URL (rcdp wire v2, see libs/cua/proto/MEDIA.md). The ticket is short-lived, bound to that one session, and safe to put in a URL; it is not the Space's token. Works for every provider because the token comes from the SDK, not from the guest.

| | |
| --- | --- |
| Providers | all (cloud, local, direct, relay) |
| Platforms | all (macos, windows, linux) |
| Metering | free |
| Approval | permission `spaces:stream_endpoint`; mutating, idempotent |
| Requires (spacesd) | `desktop_stream` |
| Swift SDK | `Space.streamEndpoint(forceRefresh:)` |
| Rust | `Streams::open` |

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `app_name` | `string` | none | Stream the largest visible window of this app (case-insensitive substring). Ignored when `window_id` is set. |
| `display` | `string` | none | Display id for a desktop stream. Default: the primary display. |
| `max_fps` | `integer` | `30` | Maximum frames per second. Default 30. At least 0. |
| `space` | `string` | required | Space id or name. |
| `ticket_ttl` | `integer` | `60` | Ticket lifetime in seconds (at most 600). Default 60. At least 0. |
| `window_id` | `string` | none | Window handle from `list_space_windows`. Streams that window. |

### Result

JSON: `space`, `media_session_id`, `ws_url` (ticket included), `ticket`, `ticket_expires_at`, `codec` (`h264`, `bgra` or `png`), `wire_version`, `frame_size` and `needs_gateway_headers`.

### Errors

[`invalid_argument`](/spaces/reference/errors#invalid_argument), [`not_found`](/spaces/reference/errors#not_found), [`ambiguous_sandbox`](/spaces/reference/errors#ambiguous_sandbox), [`spacesd_not_available`](/spaces/reference/errors#spacesd_not_available), [`capability_missing`](/spaces/reference/errors#capability_missing), [`stream`](/spaces/reference/errors#stream)

### Notes

- Giving the caller frames is a different act from presenting the Space to an operator.
- Replaces local_rcdp, which only worked for Local macOS Spaces and read its token over ssh.

## list_space_windows

List the windows open inside the Space.

## stream_space_window

Draw one Space window on the operator's desktop.

FOR THE HUMAN. Opens a bidirectional window on the operator's desktop showing one Space window (the Cua Spaces app draws it from a media ticket). Pass app_name to auto-pick that app's largest visible window, or an exact window_id.

| Providers | all (cloud, local, direct, relay) |

| Approval | permission `spaces:stream_space_window`; mutating, idempotent |
| Requires (spacesd) | `window_stream` |
| Requires (this machine) | `operator_display` |
| Swift SDK | `space.operatorDisplay.streamWindowToOperatorDesktop(_:)` |
| Rust | `OperatorDisplay::stream_window` |

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `app_name` | `string` | none | Auto-pick this app's largest visible window, e.g. "Firefox". |
| `space` | `string` | required | Space id or name. |
| `title` | `string` | none | Label for the operator's window. Default: the window title. |
| `window_id` | `string` | none | Exact window handle from `list_space_windows` (overrides `app_name`). |

### Result

### Notes

- Operator-side: the pixels land on the human's machine, so the platform axis is the operator's OS and not the Space's.
