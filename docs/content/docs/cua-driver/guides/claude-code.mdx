title: Claude Code

---

Claude Code can use both Cua products: Cua Driver for the apps on the computer it runs on, and Cua Spaces for other computers.

## Cua Driver

Register Cua Driver as an MCP server, then restart Claude Code:

```bash skip="third-party-cli"
claude mcp add --transport stdio cua-driver -- cua-driver mcp
```

This adds the tools only. To also install the Cua Driver skill, which teaches Claude Code how to use them well, run `cua-driver skills install`. Or use `cua-driver mcp-config --client claude` for the computer-use compatibility profile: it installs the skill and prints the `claude mcp add-json` command for you to run. See [Connect your agent](/cua-driver/guides/connect-your-agent) for the skill, permissions and the other clients.

## Cua Spaces

`cua connect setup --agents claude-code --yes` adds the `cua` skills and MCP server to Claude Code, and the Cua Spaces app does the same on first run. To add it by hand:

```bash skip="third-party-cli"
claude mcp add cua -- cua daemon mcp
```

Then ask Claude Code: "List my Cua Spaces." See [Connect your agent to Cua Spaces](/spaces/guides/connect-your-agent) and [Give your agent Spaces](/cua-cli/guides/mcp-server).
