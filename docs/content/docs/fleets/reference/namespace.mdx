## REST

### Create a namespace

```http
POST /api/namespaces
```

Body (`application/json`):

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | none | Namespace name: a DNS label. |

Returns: `201` with an object with `createdAt` (string), `labels` (map of string), `name` (string), `status` (string).

Errors: [`400`](/fleets/reference/errors#http-400), [`401`](/fleets/reference/errors#http-401), [`409`](/fleets/reference/errors#http-409), [`502`](/fleets/reference/errors#http-502) ([Errors](/fleets/reference/errors#http-status-codes)).

### List namespaces

```http
GET /api/namespaces
```

Returns: `200` with an array; each item is an object with `createdAt` (string), `labels` (map of string), `name` (string), `status` (string).

Errors: [`401`](/fleets/reference/errors#http-401), [`502`](/fleets/reference/errors#http-502) ([Errors](/fleets/reference/errors#http-status-codes)).
