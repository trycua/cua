`cua.fleet()` manages cloud capacity directly: named pools, [claims](/cua-sdk/reference/fleet/claims) and [images](/cua-sdk/reference/fleet/images). Most programs only need `Sandboxes.create` with `on: "cloud"`, which manages pools for you.

Python programs usually use the high-level API instead: [`cua_sandbox.Pool`](/cua-sdk/reference/python/pool#pool).

### `Fleet.apply`

Reconciles pool `name` (= namespace = template) to run `spec` with
`options`: the one pool writer (rolls a new pool back if the
template fails). The image is pinned to the variant the runtime
runs; `spec.registry_secret` is written as the pool's pull Secret.

### `FleetPools.gc_pools`

deleted (with its namespace) once it has no claims and has been idle
for `idle_seconds` (default 0, i.e. now). Pools with live claims are
kept, so a pool another process is using survives. Tests use this to
remove the pools they created.

## `SandboxSpec` record

What a sandbox runs: the one model behind `Sandbox.create`, managed
pools and `Fleet.apply`. Unset fields keep Fleet's defaults (and are
not compared by `Fleet.check_pool_spec`).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `image` | `String` | `""` | Image (a container image runs on gVisor, a containerDisk on KubeVirt). |
| `command` | `Option<Vec<String>>` | `None` | argv replacing the image ENTRYPOINT. |
| `args` | `Option<Vec<String>>` | `None` | Arguments replacing the image CMD. |
| `env` | `HashMap<String, String>` | `[:]` | Plain environment variables (not secrets). |
| `services` | `HashMap<String, u16>` | `[:]` | Named services (name → guest port). |
| `readiness` | [`Option<ReadinessProbe>`](/cua-sdk/reference/sandbox/options#readinessprobe-record) | `None` | Readiness probe (`port`, or a declared `service`; `http_path` for HTTP). A replica binds a claim only once it passes. |
| `cpu` | `Option<u32>` | `None` | vCPUs. |
| `memory_mb` / `memoryMb` | `Option<u32>` | `None` | Memory (MiB). |
| `efi` | `bool` | `false` | UEFI firmware (Windows images). |
| `sidecars` | [`Vec<Container>`](/cua-sdk/reference/sandbox/options#container-record) | `[]` | Extra containers sharing the sandbox's network namespace. |
| `registry_secret` / `registrySecret` | [`Option<RegistrySecret>`](/cua-sdk/reference/image#registrysecret-enum) | `None` | Credentials for a private image: stored as the pool's `cua-registry-*` pull Secret. |
| `registry_secret_name` / `registrySecretName` | `Option<String>` | `None` | An existing `cua-registry-*` pull Secret in the pool namespace (instead of `registry_secret`). |
| `process_mode` / `processMode` | `Option<String>` | `None` | `Legacy` or `Run` (`vmTemplate.processMode`). |
| `claim_secrets` / `claimSecrets` | `bool` | `false` | Per-claim secrets: claims may carry a token delivered at `/run/cua/env-token`. |
