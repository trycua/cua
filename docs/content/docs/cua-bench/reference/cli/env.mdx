## `cb prune`

Clean up cua-bench run data (and 0.2.x image leftovers).

```text output
cb prune [OPTIONS]
```

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cb-prune--keep"></span>`--keep` |  | integer |  | With --runs: keep the N newest runs and remove only older ones. |
| <span id="cb-prune--older-than"></span>`--older-than` |  | number |  | With --runs: remove only runs older than DAYS. |
| <span id="cb-prune--all"></span>`--all` | `-a` | boolean | `false` | Remove runs and 0.2.x image leftovers. |
| <span id="cb-prune--images"></span>`--images` |  | boolean | `false` | Remove 0.2.x stored images (deprecated store). |
| <span id="cb-prune--overlays"></span>`--overlays` |  | boolean | `false` | Remove 0.2.x task overlays (deprecated store). |
| <span id="cb-prune--runs"></span>`--runs` |  | boolean | `false` | Remove run logs and registry. |
| <span id="cb-prune--docker"></span>`--docker` |  | boolean | `false` | Deprecated: cua-bench no longer creates Docker resources. |
| <span id="cb-prune--dry-run"></span>`--dry-run` |  | boolean | `false` | Show what would be deleted without deleting. |
| <span id="cb-prune--force"></span>`--force` | `-f` | boolean | `false` | Skip confirmation prompts. |

**Examples**

```bash test="cli-shape" id="ref-cb-prune"
# Preview what would be removed
cb prune --all --dry-run

# Remove run logs without asking
cb prune --runs --force

# Keep the 20 newest runs, delete the rest
cb prune --runs --keep 20

# Delete runs older than 30 days
cb prune --runs --older-than 30
```
