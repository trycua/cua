`app_picker_app_grid`, `app_picker_window_grid` and `app_picker_remote_grid` build each tab's tiles; an app tile previews its frontmost window. `app_picker_grid_step` moves the selection for the arrow keys and `app_picker_grid_tabs` names the tabs.
