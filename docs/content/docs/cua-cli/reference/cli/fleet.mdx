## `cua fleet pools`

Managed pools (`cua-auto-*`): reused per image and shape, autoscaled from zero, garbage-collected when idle.

```text output
cua fleet pools [OPTIONS] <COMMAND>
```

### `cua fleet pools ls`

List this account's managed pools.

```text output
cua fleet pools ls [OPTIONS]
```

Alias: `cua fleet pools list`.

**Examples**

```bash test="cli-shape" id="ref-cua-fleet-pools-ls"
cua fleet pools ls
```

### `cua fleet pools gc`

Delete managed pools idle for `--idle` and stuck claims.

```text output
cua fleet pools gc [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-fleet-pools-gc--idle"></span>`--idle` | string | `30m` | Idle threshold (`30m`, `2h`, `1d`). |
| <span id="cua-fleet-pools-gc--pool"></span>`--pool` | string |  | Only these pools (repeatable). Default: every managed pool. |

**Examples**

```bash test="cli-shape" id="ref-cua-fleet-pools-gc"
cua fleet pools gc
cua fleet pools gc --idle 2h
```

## `cua fleet pool`

One pool (any pool you own, not only managed ones).

```text output
cua fleet pool [OPTIONS] <COMMAND>
```

### `cua fleet pool export`

Print a pool's spec: the shared sandbox model as JSON, or with `--terraform` the equivalent `fleets_pool` resource block.

```text output
cua fleet pool export [OPTIONS] <NAME>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<NAME>` | string | required | Pool name. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="cua-fleet-pool-export--terraform"></span>`--terraform` | boolean | `false` | Emit Terraform HCL (the cyclops-cs `fleets_pool` resource). |

**Examples**

```bash test="cli-shape" id="ref-cua-fleet-pool-export"
cua fleet pool export ci-linux
cua fleet pool export ci-linux --terraform > pool.tf
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
