Gemini CLI supports local stdio MCP servers. Find the installed Cua Driver path, then add it at user scope:

```bash
command -v cua-driver
gemini mcp add --scope user cua-driver /absolute/path/to/cua-driver mcp
gemini mcp list
```

You can instead add the generic `mcpServers` entry to `~/.gemini/settings.json`. Use the absolute executable path when Gemini CLI may be launched without your shell's `PATH`.

<Callout type="info">
  Cua Driver's legacy `mcp-config --client gemini` alias generates an Antigravity config. It is not
  the Gemini CLI setup above.
</Callout>

Continue with the [generic MCP configuration](/how-to-guides/driver/connect-your-agent#generic-mcp-json) for the server shape and Cua Driver permission guidance.

Upstream: [Gemini CLI MCP server documentation](https://google-gemini.github.io/gemini-cli/docs/tools/mcp-server.html).
