Public API of the `cua-spaces` crate (`cua_spaces`). Summaries and declarations only (`cargo doc -p cua-spaces --open` in `libs/cua` has the full comments); see [Rust crates](/cua-sdk/reference/rust) for stability.

Cua Spaces: interactive sandboxes on any image, and everything a person
or an agent does with one. cua-spacesd, when the image runs it, adds
the desktop, shell, files, streaming and teleport primitives.

More of this crate: [client](/cua-sdk/reference/rust/cua-spaces-client), [agents and MCP](/cua-sdk/reference/rust/cua-spaces-agents-mcp).
