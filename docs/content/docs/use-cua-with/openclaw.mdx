OpenClaw can register Cua Driver as a local MCP server. Generate the current command:

```bash
cua-driver mcp-config --client openclaw
```

The generated command uses the absolute Cua Driver executable path:

```bash
openclaw mcp set cua-driver '{"command":"/absolute/path/to/cua-driver","args":["mcp"]}'
```

<Callout type="warn">
  On macOS, a gateway-spawned MCP process does not inherit OpenClaw.app's Accessibility and Screen
  Recording grants. Grant permissions to the identity that actually runs Cua Driver, or use the
  documented embedding path.
</Callout>

Continue with [Connect your agent to Cua Driver](/how-to-guides/driver/connect-your-agent#other-supported-clients) for the separate MCP architecture. To run the bundled provider inside an isolated Linux Fleet VM, use [Run OpenClaw on Cloud Fleet](/how-to-guides/sandbox/run-openclaw-on-cloud-fleet). For a local macOS VM, use [Run OpenClaw in a Lume VM](/how-to-guides/lume/run-openclaw).
