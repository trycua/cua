`cua.sandboxes()` returns the `Sandboxes` collection; each sandbox is a `Sandbox` handle. The same options run locally and in the cloud: `on` is the switch (`local`, `cloud`, `direct:<addr>`), `kind` and `runtime` pick the machine.

Python programs usually use the high-level API instead: [`cua_sandbox.Sandbox`](/cua-sdk/reference/python/sandbox#sandbox).

A sandbox's `id()` is its ref, and every call that takes a sandbox name accepts one:

| Ref | Meaning |
| --- | --- |
| `local:<name>` | A sandbox on this computer |
| `aws:<name>` | A sandbox in your own cloud (`gcp:` and `modal:` the same way) |
| `direct:<host:port>` | A computer reached by address |
| `relay:<computer-id>` | An account computer reached through the relay (a Space) |
| `<name>` | A bare name, searched across locations; `AmbiguousSandbox` when it matches more than one |

Readiness never assumes a guest agent: the provider reports the sandbox running, then the `wait_for` probes run, and creation fails fast if the sandbox exits.

### `Sandboxes.cancel_create`

Cancels the create of the named sandbox `name` that is still
running (in this process or the daemon): the work in flight stops
(an image download, a boot) and what the create made is
deleted; a sandbox of that name that existed before is never
touched. Finished image downloads stay cached. Returns what was
removed, or `None` when no create of that name was running. The
create itself fails with `Cancelled`.

## `Sandbox`

A sandbox handle.

Returned by [`Sandboxes.connect`](#sandboxesconnect), [`Sandboxes.connect_url`](#sandboxesconnect_url), [`Sandboxes.create`](#sandboxescreate), [`Sandboxes.fork`](/cua-sdk/reference/sandbox/checkpoints#sandboxesfork).

| Method | Description |
| --- | --- |
| [`overlay`](#sandboxoverlay) | Injects binaries (see `Overlay`): each replaces its guest file atomically, is recorded under `/var/lib/cua/overlays` with its sha256, and what runs it is restarted. |
| [`spacesd`](#sandboxspacesd) | Attaches to cua-spacesd inside the sandbox (the `env` service or guest port 3211). |
| [`viewer_url`](#sandboxviewer_url) | A browser link to this sandbox's desktop in the cua-spacesd HTML5 viewer (`/viewer` on the `env` service): video, audio, input, clipboard, file drop and folder sharing, in any modern browser. |
| [`agents`](/cua-sdk/reference/agents#sandboxagents) | Coding agents inside this sandbox (needs cua-spacesd): run a harness over ACP, stream normalized events, follow up, interrupt, collect results; runs outlive this handle. |
| [`delete`](/cua-sdk/reference/sandbox/lifecycle#sandboxdelete) | Deletes (local: removes it; direct: forgets it; your cloud: deletes the machine). |
| [`expires_at_unix`](/cua-sdk/reference/sandbox/lifecycle#sandboxexpires_at_unix) | When this sandbox's lifetime ends (`Sandbox.set_lifetime`), as Unix seconds; `None` when it has none. |
| [`forward`](/cua-sdk/reference/services#sandboxforward) | Forwards a loopback port to guest `port`: a TCP forward locally (and over cua-spacesd's tunnel when the image has it). |
| [`guest_display`](/cua-sdk/reference/spacesd#sandboxguest_display) | The guest display without cua-spacesd: the VM's VNC endpoint and a host command that opens it (`lume attach`). |
| [`guest_screenshot`](/cua-sdk/reference/spacesd#sandboxguest_screenshot) | Captures the guest framebuffer as PNG without cua-spacesd. |
| [`guest_sh`](/cua-sdk/reference/spacesd#sandboxguest_sh) | Runs `line` with `/bin/sh -c` in the guest without cua-spacesd, to completion (default timeout 120 s). |
| [`keep_alive`](/cua-sdk/reference/sandbox/lifecycle#sandboxkeep_alive) | Extends the sandbox's lease by `seconds`, for a provider that has one. |
| [`mcp`](/cua-sdk/reference/services#sandboxmcp) | An MCP client (the official Rust SDK) for the MCP server behind `service` at `path` (default `/mcp`). |
| [`mcp_config`](/cua-sdk/reference/services#sandboxmcp_config) | Where the MCP server behind `service` is (URL of its endpoint at `path`, default `/mcp`, plus the headers every request needs), for any MCP client. |
| [`open_media_bridge`](/cua-sdk/reference/spacesd/computer#sandboxopen_media_bridge) | Opens a media session and returns a loopback WebSocket bridge for a webview (daemon mode). |
| [`public_url`](/cua-sdk/reference/services#sandboxpublic_url) | A shareable URL for `service` that stops working after `ttl_seconds` (60 s to 24 h, default 1 h): a loopback URL with its own token, served by the cua daemon (started if needed; `CUA_BIN` names the CLI). |

### `Sandbox.overlay`

Injects binaries (see `Overlay`): each replaces its guest file
atomically, is recorded under `/var/lib/cua/overlays` with its
sha256, and what runs it is restarted. Local containers go through
the container engine; other sandboxes need cua-spacesd and root (or
passwordless sudo) in the guest. `timeout_ms`
bounds a cua-spacesd restart (default 180 s).
