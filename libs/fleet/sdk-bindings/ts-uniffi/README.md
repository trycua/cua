# Cyclops TypeScript UniFFI bindings

Generated by `scripts/generate-sdk-bindings.sh` using the pinned
`uniffi-bindgen-react-native`. Node.js retains direct record factories through
the existing compatibility normalizer; Browser/WASM retains its builder API.
Both roots participate in canonical `--check`. Runtime packaging remains a
separate validation step; do not edit generated files.

Runtime requires `@ubjs/core`, `@ubjs/node`, and a colocated
`libcyclops_sdk` cdylib. Browser source is generated in
`../ts-uniffi-browser`; packaging its WASM crate requires a project
`ubrn.config.yaml` and a wasm build pipeline.
