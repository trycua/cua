---
title: Coding agents in a Space
description: Start Claude Code, Codex and other coding agents inside a Space or sandbox, and follow their work from your own agent, the CLI or code.
---

A coding agent can run inside a computer of its own, so it works on a copy you can watch and discard instead of on your machine.

- **From an agent you already use.** An agent with the Spaces tools can start other agents inside a Space as long-lived runs: see [Run an agent inside a Space](/spaces/guides/connect-your-agent#run-an-agent-inside-a-space). Add Spaces to your agent first with [Connect your agent to Cua Spaces](/spaces/guides/connect-your-agent).
- **From code.** `sandbox.agents()` installs a harness (Claude Code, Codex, Gemini CLI, OpenCode, Goose and others) in a sandbox, streams its events, takes follow-ups and collects the result: see [Run a coding agent in a sandbox](/cua-sdk/guides/run-a-coding-agent).
- **With an agent framework.** [Run agent frameworks in a sandbox](/cua-sdk/guides/agent-frameworks) runs OpenAI Agents, Codex, Cursor and OpenClaw in Cua sandboxes.
