Create a new virtual machine.

```text output
lume create [OPTIONS] <name>
```

| <span id="lume-create--os"></span>`--os` | string | `macOS` | Operating system to install: macOS or linux. |
| <span id="lume-create--cpu"></span>`--cpu` | integer | `4` | Number of CPU cores. |
| <span id="lume-create--memory"></span>`--memory` | string | `8GB` | Memory size (8, 8GB or 8192MB; a bare number is GB). |
| <span id="lume-create--disk-size"></span>`--disk-size` | string |  | Disk size (100, 100GB or 102400MB; a bare number is GB). Defaults to 100GB for macOS and 50GB for Linux. |
| <span id="lume-create--display"></span>`--display` | string | `1024x768` | Display resolution as WIDTHxHEIGHT. |
| <span id="lume-create--ipsw"></span>`--ipsw` | string |  | Path to a macOS restore image (IPSW), or 'latest' to download the latest supported version. Required for macOS VMs. |
| <span id="lume-create--storage"></span>`--storage` | string |  | VM storage location name, or a direct path to the VM location. |
| <span id="lume-create--unattended"></span>`--unattended` | string |  | Prepare macOS unattended setup offline after install. Built-in presets: sequoia, tahoe; a YAML path is accepted for compatibility. macOS VMs only. |
| <span id="lume-create--debug-dir"></span>`--debug-dir` | string |  | Compatibility option; ignored by offline setup. |
| <span id="lume-create--vnc-port"></span>`--vnc-port` | integer | `0` | Port for the temporary verification VNC server (0 picks a free port). |

| <span id="lume-create--debug"></span>`--debug` | boolean | `false` | Compatibility flag; ignored by offline setup. |

**Examples**

```bash test="cli-shape" id="ref-lume-create"
# A macOS VM from the latest IPSW, set up unattended (SSH user lume/lume)
lume create macos-tahoe --ipsw latest --unattended tahoe

# A Linux VM
lume create dev --os linux --cpu 4 --memory 8GB --disk-size 50GB

# Bridge the VM onto the host's en0 network
lume create macos-tahoe --ipsw latest --network bridged:en0
```

## `lume set`

Set new values for CPU, memory, and disk size of a virtual machine.

```text output
lume set [OPTIONS] <name>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<name>` | string | required | Name of the VM. |

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="lume-set--cpu"></span>`--cpu` | integer |  | New number of CPU cores. |
| <span id="lume-set--memory"></span>`--memory` | string |  | New memory size (8, 8GB or 8192MB; a bare number is GB). |
| <span id="lume-set--disk-size"></span>`--disk-size` | string |  | New total disk size, increase only. For macOS VMs this relocates the recovery partition and grows the main APFS container; the VM must be stopped and it may take several minutes. |
| <span id="lume-set--display"></span>`--display` | string |  | New display resolution as WIDTHxHEIGHT. |
| <span id="lume-set--machine-identifier"></span>`--machine-identifier` | string |  | New machine identifier: 'random', or a base64 identifier from `lume get --format json` to give this VM an existing machine identity (per-machine licenses then see one machine). macOS VMs only; the VM must be stopped. |
| <span id="lume-set--mac-address"></span>`--mac-address` | string |  | New MAC address: 'random' (locally administered) or aa:bb:cc:dd:ee:ff. The VM must be stopped. The DHCP lease follows the MAC, so two running VMs with one MAC claim the same IP. |
| <span id="lume-set--storage"></span>`--storage` | string |  | VM storage location name, or a direct path to the VM location. |
| <span id="lume-set--no-backup"></span>`--no-backup` | boolean | `false` | Skip the pre-resize disk backup (macOS resize only). Faster, but a failure cannot be rolled back. |
| <span id="lume-set--keep-backup"></span>`--keep-backup` | boolean | `false` | Keep the pre-resize backup after a successful macOS resize. |
| <span id="lume-set--dry-run"></span>`--dry-run` | boolean | `false` | Validate the disk-resize plan and print it without changing anything (macOS resize only). |

**Examples**

```bash test="cli-shape" id="ref-lume-set"
lume set my-vm --cpu 8 --memory 16GB

# Check a disk resize plan, then run it without --dry-run
lume set my-vm --disk-size 120GB --dry-run
lume set my-vm --mac-address random
```
