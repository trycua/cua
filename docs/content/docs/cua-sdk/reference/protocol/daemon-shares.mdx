### ShareService.CreateShare

`/cua.daemon.v1.ShareService/CreateShare`, unary: [`CreateShareRequest`](#createsharerequest) to [`CreateShareResponse`](#createshareresponse).

Shares a port on this machine, a port in a Space, or a file or folder
(read-only), and returns the link. The machine must be on the cua.ai
relay (`cua host setup`); there is no localhost fallback.

### ShareService.ListShares

`/cua.daemon.v1.ShareService/ListShares`, unary: [`ListSharesRequest`](#listsharesrequest) to [`ListSharesResponse`](#listsharesresponse).

The active shares.

### ShareService.StopShare

`/cua.daemon.v1.ShareService/StopShare`, unary: [`StopShareRequest`](#stopsharerequest) to [`StopShareResponse`](#stopshareresponse).

Stops one share, or all of them. The link stops working at once.

### ShareService.CheckShare

`/cua.daemon.v1.ShareService/CheckShare`, unary: [`CheckShareRequest`](#checksharerequest) to [`CheckShareResponse`](#checkshareresponse).

Opens the share's link once, as its owner would, and reports what came
back, so an agent can confirm the link works before handing it over.

### ShareService.ApproveShare

`/cua.daemon.v1.ShareService/ApproveShare`, unary: [`ApproveShareRequest`](#approvesharerequest) to [`ApproveShareResponse`](#approveshareresponse).

Lets a share that waits for the owner go live: a public share an agent
in a Space asked for, or the first share through a share edge in a
cloud (the owner agrees to the edge's cost). Owner only; never on a
Space's spawn channel.

### ShareService.DenyShare

`/cua.daemon.v1.ShareService/DenyShare`, unary: [`DenyShareRequest`](#denysharerequest) to [`DenyShareResponse`](#denyshareresponse).

Turns down a waiting share.

### ShareService.GetShareSettings

`/cua.daemon.v1.ShareService/GetShareSettings`, unary: [`GetShareSettingsRequest`](#getsharesettingsrequest) to [`GetShareSettingsResponse`](#getsharesettingsresponse).

Where public TCP shares may land, the daily data cap, the default
allowlist and the approval rule.

### ShareService.SetShareSettings

`/cua.daemon.v1.ShareService/SetShareSettings`, unary: [`SetShareSettingsRequest`](#setsharesettingsrequest) to [`SetShareSettingsResponse`](#setsharesettingsresponse).

Changes those settings. Owner only.

### ShareService.RemoveShareEdge

`/cua.daemon.v1.ShareService/RemoveShareEdge`, unary: [`RemoveShareEdgeRequest`](#removeshareedgerequest) to [`RemoveShareEdgeResponse`](#removeshareedgeresponse).

Removes the share edge from the owner's cloud now (its shares end).
