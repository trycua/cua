Antigravity CLI can run local stdio MCP servers, so it can use Cua Driver as its computer-use layer.

| Start here when…                  | Recommended path                                                                               |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| You use Antigravity CLI           | [Connect Antigravity CLI to Cua Driver](/use-cua-with/antigravity-cli)                         |
| You are migrating from Gemini CLI | Follow Google's [migration guide](https://antigravity.google/docs/cli/gcli-migration)          |
| You configure MCP with JSON       | [Use the generic MCP configuration](/how-to-guides/driver/connect-your-agent#generic-mcp-json) |

Google ended Gemini CLI service for individual Google AI Pro, Ultra, and free-tier accounts on June 18, 2026. Enterprise licenses and paid API-key access remain supported, but Cua recommends Antigravity CLI for new terminal setups. Cua Driver keeps `--client gemini` as a legacy alias for the Antigravity configuration.

See Google's [transition announcement](https://github.com/google-gemini/gemini-cli/discussions/28017) and [Antigravity MCP documentation](https://antigravity.google/docs/mcp) for the current client behavior.
