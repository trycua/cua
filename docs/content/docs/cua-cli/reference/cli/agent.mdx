## `cua agent run`

Start a coding agent in a sandbox (returns at once unless --follow).

```text output
cua agent run [OPTIONS] <SANDBOX> <HARNESS> <PROMPT>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<SANDBOX>` | string | required | Sandbox (`local:NAME`, `cloud:NAME`, `direct:HOST:PORT`, or NAME). |
| `<HARNESS>` | string | required | Harness (`cua agent harnesses`). |
| `<PROMPT>` | string | required | The task. |

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cua-agent-run--env-from-host"></span>`--env-from-host` |  | string |  | Forward a provider key from this shell's environment (repeatable), for example ANTHROPIC_API_KEY. The value never appears in argv. |
| <span id="cua-agent-run--repo"></span>`--repo` |  | string |  | Git repository cloned into the working directory first. |
| <span id="cua-agent-run--branch"></span>`--branch` |  | string |  |  |
| <span id="cua-agent-run--cwd"></span>`--cwd` |  | string |  | Working directory in the sandbox. |
| <span id="cua-agent-run--model"></span>`--model` |  | string |  |  |
| <span id="cua-agent-run--base-url"></span>`--base-url` |  | string |  | A custom model endpoint (proxy or compatible server). |
| <span id="cua-agent-run--wire"></span>`--wire` |  | string |  | Its wire format: anthropic, openai-responses, openai-chat, gemini. |
| <span id="cua-agent-run--mcp"></span>`--mcp` |  | string |  | An MCP server for the agent: NAME=URL (HTTP, as reachable inside the sandbox) or NAME=cmd:COMMAND ARGS... (stdio, run in the sandbox). Repeatable. |
| <span id="cua-agent-run--file"></span>`--file` |  | path |  | Attach a local file to the prompt (repeatable). |
| <span id="cua-agent-run--label"></span>`--label` |  | string |  |  |
| <span id="cua-agent-run--local"></span>`--local` |  | boolean | `false` | Look NAME up among local sandboxes only (same as `local:NAME`). |
| <span id="cua-agent-run--cloud"></span>`--cloud` |  | boolean | `false` | Look NAME up among cloud sandboxes only (same as `cloud:NAME`). |
| <span id="cua-agent-run--no-sandbox-mcp"></span>`--no-sandbox-mcp` |  | boolean | `false` | Do not give the agent the sandbox's own MCP tools. |
| <span id="cua-agent-run--no-skills"></span>`--no-skills` |  | boolean | `false` | Do not copy the cua skills into the harness. |
| <span id="cua-agent-run--exit-when-idle"></span>`--exit-when-idle` |  | boolean | `false` | Stop (resumably) once the prompt is answered. |
| <span id="cua-agent-run--follow"></span>`--follow` | `-f` | boolean | `false` | Stream events until the turn ends. |

**Examples**

```bash test="cli-shape" id="ref-cua-agent-run"

```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure, or `cua do` reported an error. |
| `2` | Invalid argument, or an ambiguous sandbox name (qualify it: `local:NAME`, `cloud:NAME`). |
| `3` | Not found: sandbox, window, skill or image (or an image not published yet). |
| `4` | Not supported, or not configured (for example no Fleet credentials). |
| `5` | No cua-spacesd answered, or a transport failure. |
| `6` | Unauthenticated or permission denied (by Cua, Fleet or your cloud account). |
| `7` | Not enough free disk space (see `cua cache`). |
| `130` | Cancelled (Ctrl-C during a create): what it made was removed. |
