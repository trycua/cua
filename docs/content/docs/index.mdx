## Cua Spaces

- [Quickstart](/spaces/quickstart): install the app, connect your agent and run a first task in about five minutes.
- [Connect your agent](/spaces/guides/connect-your-agent): add Spaces to Claude Code, Codex, Cursor and other agents.
- [Add a computer](/spaces/guides/add-a-computer): connect another Mac, Linux or Windows computer you own.
- [Teams](/spaces/guides/teams): share computers with your team, and what each plan includes.
- [How Spaces works](/spaces/concepts/how-spaces-works): what runs where, in plain words.

## Cua Driver

- [Quickstart](/cua-driver/quickstart): install Cua Driver and have your agent use a calculator.
- [Connect your agent](/cua-driver/guides/connect-your-agent): add Cua Driver to Claude Code, Codex and other agents.
- [Tool reference](/cua-driver/reference): every command and every tool.

## More tools

- [Cua CLI](/cua-cli): the `cua` command for Spaces, sandboxes, sign-in and MCP.
- [Cua SDK](/cua-sdk): create and drive computers from your own code, in Python, TypeScript, Swift and Rust.
- [Lume](/lume): macOS and Linux virtual machines on Apple silicon.
- [Cua Bench](/cua-bench): run and score computer-use tests on your machine.
- [Docs for agents](/docs-for-agents): give a coding agent these docs as Markdown or over MCP.

## Examples

- [Cua Bots](/spaces/examples/cua-bots): bots that each have their own computer, in a Mac and iPhone app. The same kind of app in TypeScript, Rust and Swift is in [Use Spaces from code](/spaces/guides/create-a-space-with-the-sdk).
- [Background computer use with Cua Driver](/cua-driver/guides/recipes): your agent builds and tests a Windows app while you keep working ([video](https://x.com/trycua/status/2059688966085853245)).
