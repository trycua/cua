# Provenance: IR-02

**Apply settings while a notification-style banner covers the button.** An original Cua task, written for this benchmark (first committed
2026-10-10). It runs in BenchLab, the test app in [`../../swift`](../../swift), and
is checked by [`evaluate.py`](evaluate.py) from the app's own state and event
log.

* **Author:** Cua AI, Inc. The task, its brief, its seeded data, the BenchLab
  mode it uses and its checker are original. Names, values and labels are
  generated from the trial seed or invented.
* **Sources:** none declared by the author. BenchLab uses system fonts only
  and draws its icons in code.
* **Related work:** not yet reviewed against public benchmarks (see below).
* **Review:** the interruption tasks were written on 2026-10-10, after Cua's
  similarity review of the other tasks that day, so that review does not cover
  them. No external source is declared; a similarity check against public
  benchmarks is still to be done.
