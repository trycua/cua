## `AgentStartReport` record

Result of `Space.agent_start`.

Returned by [`Space.agent_start`](#spaceagent_start).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `run_id` / `runId` | `String` |  | Run id. |
| `agent` | `String` |  | Agent. |
| `space` | `String` |  | Space. |
| `process_tag` / `processTag` | `String` |  | spacesd process tag of the first turn. |
| `notes` | `Vec<String>` |  | Preparation steps that could not be completed. |
| `json` | `String` |  | The whole report as JSON. |

## `AgentRunStatus` record

One agent run's status.

Returned by [`Space.agent_list`](#spaceagent_list), [`Space.agent_status`](#spaceagent_status).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `run_id` / `runId` | `String` |  | Run id. |
| `agent` | `Option<String>` |  | Agent. |
| `status` | `String` |  | Status (`running`, `done`, `failed`, ...). |
| `reason` | `String` |  | Why. |
| `phase` | `String` |  | Finer grain: `installing`, `working`, `waiting`, `exited`, ... |
| `result_text` / `resultText` | `Option<String>` |  | The last turn's final text (`agent_status` only). |
| `accepts_message` / `acceptsMessage` | `bool` |  | A follow-up sent now starts the next turn (the server's rule: idle, or a crashed or failed run it restarts; not mid-turn). Read this, never derive it from `status`. |
| `output_tail` / `outputTail` | `Option<String>` |  | Output tail. |
| `json` | `String` |  | The whole status as JSON. |

| `json` | `String` |  | The whole report as JSON. |

## `SpaceAgentOptions` record

Options for `Space.agent_start` beyond the harness and prompt.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `env_from_host` / `envFromHost` | `Vec<String>` | `[]` | Provider key variables forwarded from the Spaces host's environment. |
| `env` | `HashMap<String, String>` | `[:]` | More environment for the agent, for example `HERMES_HOME` (stored 0600 in the run, redacted from its output; not for provider keys). |
| `repo` | `Option<String>` | `None` |  |
| `branch` | `Option<String>` | `None` |  |
| `cwd` | `Option<String>` | `None` |  |
| `model` | `Option<String>` | `None` |  |
| `base_url` / `baseUrl` | `Option<String>` | `None` | A custom model endpoint. |
| `exit_when_idle` / `exitWhenIdle` | `Option<bool>` | `None` | Stop (resumably) once the prompt is answered. |
| `home` | `Option<String>` | `None` | Run as this persistent agent: its home in the Cua Volume is restored first and saved after every turn (see `Spaces.persistent_agent_send`). |
