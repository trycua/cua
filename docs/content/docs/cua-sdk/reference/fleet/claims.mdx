A claim binds one sandbox of a pool to you until you release it or its TTL passes.

Python programs usually use the high-level API instead: [`Pool.claim`](/cua-sdk/reference/python/pool#poolclaim).

| Field | Type | Default | Description |

| `json` | `String` |  | The resource as JSON. |

## `FleetClaimOptions` record

Claim options for `Fleet.acquire_with`.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `Option<String>` | `None` | Claim name; an existing claim with it is reattached. |
| `ttl_seconds` / `ttlSeconds` | `Option<u32>` | `None` | Claim TTL (seconds). |
| `claim_token` / `claimToken` | `Option<String>` | `None` | Per-claim env token (see `fleet_generate_claim_token`); the pool's spec must set `claim_secrets`. Acquire waits (at most 90 s) until the sandbox has it, else releases the claim and raises `ClaimSecretsNotDelivered`. |

## `FleetSandbox` record

A bound sandbox.

Returned by [`Fleet.acquire`](#fleetacquire), [`Fleet.acquire_with`](#fleetacquire_with), [`Fleet.attach_claim`](#fleetattach_claim).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `String` |  | Sandbox name. |
| `namespace` | `String` |  | Namespace. |
| `claim` | `String` |  | Claim name. |
| `services` | `Vec<String>` |  | Declared service names. |
