## `cb agent init`

Create a new agent from template.

Scaffold a new custom agent with working sample code.

```text output
cb agent init [OPTIONS] <name>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<name>` | string | required | Agent name (e.g., 'my-agent'). |

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| <span id="cb-agent-init--output-dir"></span>`--output-dir` | `-o` | string |  | Output directory (default: ./&lt;name&gt;). |

**Examples**

```bash test="cli-shape" id="ref-cb-agent-init"
# Scaffold an agent in ./my-agent
cb agent init my-agent

# Scaffold it into another directory
cb agent init my-agent --output-dir ./agents/my-agent
```
