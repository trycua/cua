## REST

### Call a service

```http
GET /api/svc/{namespace}/{service}/{path}
```

| Parameter | In | Description |
| --- | --- | --- |
| `namespace` | path | The pool's namespace. A pool, its namespace and its template share one name. |
| `service` | path | The Kubernetes Service of the sandbox service: `<sandbox>-<service>`. |
| `path` | path | The upstream path, forwarded verbatim (it must start with `/`). Optional. |

Returns: `200`. Upstream response.

Errors: [`400`](/fleets/reference/errors#http-400), [`401`](/fleets/reference/errors#http-401), [`403`](/fleets/reference/errors#http-403), [`502`](/fleets/reference/errors#http-502) ([Errors](/fleets/reference/errors#http-status-codes)).

### Create a signed URL

```http
POST /api/signed-service-urls/{namespace}
```

Creates a temporary bearer link for one logical sandbox service.

| Parameter | In | Description |
| --- | --- | --- |
| `namespace` | path | The pool's namespace. A pool, its namespace and its template share one name. |

Body (`application/json`):

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `claim` | `string` | required | The claim that holds the sandbox. |
| `expiresInSeconds` | `integer` | required | Lifetime of the URL, in seconds. 60 to 86400. |
| `label` | `string` | none | A label for the URL, at most 120 UTF-8 bytes. At most 120 characters. |
| `logicalService` | `string` | required | The service as the template names it, for example `env`. |
| `sandbox` | `string` | required | The sandbox name (`status.sandbox.name` of the claim). |
| `service` | `string` | required | The sandbox's Service: `<sandbox>-<logicalService>`. |

Returns: `201` with an object with `claim` (string), `createdAt` (string), `expiresAt` (string), `id` (string), `label` (string), `logicalService` (string), `namespace` (string), `revokedAt` (string), `sandbox` (string), `service` (string), `url` (string).

Errors: [`400`](/fleets/reference/errors#http-400), [`401`](/fleets/reference/errors#http-401), [`404`](/fleets/reference/errors#http-404), [`500`](/fleets/reference/errors#http-500), [`503`](/fleets/reference/errors#http-503) ([Errors](/fleets/reference/errors#http-status-codes)).
