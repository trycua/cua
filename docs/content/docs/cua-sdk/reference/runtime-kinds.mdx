Each kind of Space has its own setting, `runtime.container`, `runtime.vm` and `runtime.microvm` (`auto`, `builtin` or `system`), and with `system` a `runtime.<kind>_path` naming the program to use. `runtime_kinds` reads them with what is installed for each kind; `runtime_check_path` tells what a binary is before it is saved. The Cua app's Settings, Advanced shows the same, and `cua` and the daemon use the same program.

## Runtime per kind methods

Methods of [`Local`](/cua-sdk/reference/cua#local).

### `Local.runtime_kinds`

Each kind of Space (`container`, `vm`, `microvm`) with its runtime
setting (`runtime.<kind>`), the runtimes installed on this machine
for it and what the path in use is. Read-only: runs each runtime's
`--version`, nothing else; probed in this process (the daemon runs
on the same host).

## `RuntimeKindState` record

One kind of Space's runtime, as Settings shows it.

Returned by [`Local.runtime_kinds`](#localruntime_kinds).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `kind` | `String` |  | `container`, `vm` or `microvm`. |
| `source` | `String` |  | `runtime.<kind>`: `auto`, `builtin` or `system`. |
| `path` | `Option<String>` |  | `runtime.<kind>_path`, when set. |
| `detected` | [`Vec<RuntimeDetected>`](#runtimedetected-record) |  | What is installed here for the kind, the one used first. |
| `check` | [`Option<RuntimePathProbe>`](#runtimepathprobe-record) |  | The path in use (the custom one, else the first detected), probed. |
| `expected` | `Vec<String>` |  | The names of the tools the kind takes here (`Docker`, `Podman`). |

## `RuntimeDetected` record
