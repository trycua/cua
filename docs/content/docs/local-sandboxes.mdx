---
title: Local Sandboxes
description: Create and use isolated computers on your own hardware.
---

The Cua Sandbox SDK represents one isolated computer. In the local path, a
runtime on your own hardware creates and runs that computer; you do not need a
hosted Fleet pool or claim.

Start with [Create and manage a local Sandbox](/how-to-guides/sandbox/manage-local-lifecycle)
to choose a supported runtime, create a Sandbox, reconnect when needed, and
clean it up. Check [Sandbox runtime support](/reference/sandbox-sdk/runtime-support)
before choosing an operating system or image kind.
