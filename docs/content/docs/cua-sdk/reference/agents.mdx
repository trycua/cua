| `branch` | `Option<String>` | `None` |  |

| `mcp_servers` / `mcpServers` | [`Vec<AgentRunMcpServer>`](#agentrunmcpserver-record) | `[]` |  |
| `sandbox_mcp` / `sandboxMcp` | `Option<bool>` | `None` | Give the agent the sandbox's own MCP (cua-driver). Default true. |

## `AgentTranscript`

A run's events folded into conversation items, the same rule in every
language: the agent's message chunks join into `message` items, the
prompt is a `user` item (never repeated as agent text), and consecutive
activity of one turn folds into one `activity` group. Absorbing an event
twice changes nothing, so a poll can re-read a page.

| Method | Description |
| --- | --- |
| [`new`](#agenttranscriptnew) | An empty transcript. |
| [`absorb`](#agenttranscriptabsorb) | Adds events from `AgentRun.events`. |
| [`absorb_json`](#agenttranscriptabsorb_json) | Adds the events of an `agent_events` result (`Space.agent_events`, the MCP tool), or a JSON array of events. |
| [`note`](#agenttranscriptnote) | Adds a line the app itself produced (a start note, "queued") as an activity step of `turn`. |

| Accessor | Returns | Description |
| --- | --- | --- |
| `cursor()` | `u64` | The highest `agent_events` cursor absorbed: pass it back to read on. |
| `items()` | [`Vec<AgentTranscriptItem>`](#agenttranscriptitem-record) | The items so far. |
| `preview()` | `Option<String>` | The agent's last message on one line (a roster preview), `None` before it has said anything. Activity is never a preview. |
| `revision()` | `u64` | Changes whenever the items do. |
