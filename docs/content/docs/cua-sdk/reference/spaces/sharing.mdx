`Space.share` gives a person access to a Space, `Space.shares` lists who has it, and `Space.unshare` takes it back.

## Sharing

Methods of [`Space`](/cua-sdk/reference/spaces/space#space).

### `Space.share`

Lets `who` (a verified email or an account id) watch (`viewer`,
the default) or use (`editor`) this Space through the relay. A Space
that is not a host is attached to the relay on its first share.

## `SpaceShareEntry` record

One account a Space is shared with.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `who` | `String` |  | The email or account id, as shared. |
| `role` | `String` |  | `viewer` or `editor`. |
| `connected` | `bool` |  | Connected through the relay right now. |

## `SpaceShares` record

Who a Space is shared with.

Returned by [`Space.share`](#spaceshare), [`Space.shares`](#spaceshares), [`Space.unshare`](#spaceunshare).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `space` | `String` |  | The Space. |
| `machine` | `String` |  | The relay machine it is shared as (empty when not shared). |
| `invitee_space` / `inviteeSpace` | `String` |  | What the people it is shared with open (`relay:<machine>`). |
| `url` | `String` |  | The relay URL of the machine. |
| `online` | `bool` |  | The machine is on the relay now. |
| `shares` | [`Vec<SpaceShareEntry>`](#spaceshareentry-record) |  | The accounts and their roles. |
