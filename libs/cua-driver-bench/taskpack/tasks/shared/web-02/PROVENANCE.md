# WEB-02 provenance

All scenario text, fixture code, values, UI and checks are self-written for Amendment 24.3. No third-party site content is included. Licence: FSL-1.1-MIT.

The seed selects `seed % len(variants)` in Python; setup records the variant once. The server reads that trial and owns its in-memory records. Evaluation derives expectations independently from the reported seed and pinned scenario; the runner compares that seed to the trusted row. Only final server state is graded.

The evaluator installation is assumed to preserve this task directory, not sibling directories. `evaluator/common.py` is generated by `python3 ../web-common/vendor_evaluator.py`; it vendors the shared standard-library helpers so the hidden evaluator works with only this task tree. Tests copy exactly that layout and invoke evaluation from another working directory.

The generic service listens only on 127.0.0.1:4192; an occupied port fails startup. Chrome has a fresh per-trial profile. The server makes no outbound requests. `/__state` is evaluator-only by policy; the runner peek control detects access, not HTTP authorization. Runtime reset verification hashes all manifest inputs, including sibling shared files.
