## Cua Driver

The [Cua Driver installer](/cua-driver/quickstart) connects Cursor for you. If you installed Cursor later, run `cua-driver connect`: it adds an MCP server named `cua-driver` to `~/.cursor/mcp.json` and installs the Cua Driver skill. Restart Cursor afterwards. See [Connect your agent](/cua-driver/guides/connect-your-agent) for the other clients.

## Cua Spaces

`cua connect setup --agents cursor --yes` adds the `cua` skills and MCP server to `~/.cursor/mcp.json`, and the Cua Spaces app does the same on first run. Then ask Cursor: "List my Cua Spaces." See [Connect your agent to Cua Spaces](/spaces/guides/connect-your-agent) and [Give your agent Spaces](/cua-cli/guides/mcp-server).
