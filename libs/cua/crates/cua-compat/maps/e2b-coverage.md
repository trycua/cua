# E2B coverage matrix

Every public symbol of the E2B Python SDK (sync and async) and the `e2b` npm package, and what the Cua gateway (`cua-compat`) does with it. Generated by `tests/compat/e2b/coverage.py` from the committed SDK surface snapshots and `coverage.json`; `coverage.py --check` fails when an SDK release adds a symbol no row covers.

Status: **implemented** (tested by the named cases, which run against the real E2B and the gateway), **native-error** (E2B's own error shape, with the reason).

SDK versions covered: Python `e2b` 2.42.0, 2.56.0, 2.58.0; npm `e2b` 2.42.0, 2.56.0, 2.58.0. Sources: the installed wheels (`surface.py`) and the `.d.ts` of the npm packages (`surface_ts.mjs`), read as data.
