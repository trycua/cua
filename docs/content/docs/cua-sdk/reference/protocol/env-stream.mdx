Media sessions (video and audio over the media wire, see `libs/cua/proto/MEDIA.md`) and presence for shared sessions.

## StreamService

`cua.env.v1.StreamService`

Control plane for video streaming.

Video never travels over gRPC. This service discovers targets, negotiates
codec and limits, and mints a short-lived media ticket. The client then
opens the media plane (rcdp wire v2, see `libs/cua/proto/MEDIA.md`) on the
`/media` WebSocket of the same port, or on direct QUIC, authenticating
with the ticket. The ticket is bound to one media session and target and
is safe to put in a URL; it is not the root token.

Audio is a first-class track next to video: a media session may carry
zero or one video track plus any number of downlink audio tracks (desktop
mix or per-app), and optionally one uplink audio track (client microphone
into a guest virtual source). All tracks share one media clock; see
MEDIA.md §12.

## PresenceService

`cua.env.v1.PresenceService`

Multi-user presence: who is looking at the guest and where their cursors
are. Agent cursors are published automatically when an agent principal
drives `ComputerService` or cua-driver tools.

Cursor updates are unary (`UpdateCursor`) so browsers on gRPC-Web can send
them; events arrive on the `Join` server stream.

### AudioUplinkOptions

Client-to-guest audio (for example the user's microphone), played into a
guest virtual audio source so apps inside can "hear" the user.

Off by default and gated separately from video and input: it requires the
"audio.uplink" feature, a session policy other than
`SESSION_POLICY_VIEW_ONLY`, and the caller's principal to be allowed by
`InitRequest.audio_uplink`. A denied uplink does not fail `OpenMedia`; the
response reports why in `AudioUplinkGrant`.

### CursorShape

A pointer shape, in a small portable vocabulary. Clients draw their own art
for each value in the participant's color.

| Value | # | Description |
| --- | --- | --- |
| `CURSOR_SHAPE_UNSPECIFIED` | 0 | Unknown or not probed. Draw the arrow. |
| `CURSOR_SHAPE_ARROW` | 1 | The ordinary arrow. |
| `CURSOR_SHAPE_TEXT` | 2 | Text insertion (I-beam). |
| `CURSOR_SHAPE_POINTER` | 3 | A link or other clickable control (pointing hand). |
| `CURSOR_SHAPE_RESIZE_NS` | 4 | Resize along the vertical axis (top or bottom edge). |
| `CURSOR_SHAPE_RESIZE_EW` | 5 | Resize along the horizontal axis (left or right edge). |
| `CURSOR_SHAPE_RESIZE_NESW` | 6 | Resize along the rising diagonal (top-right or bottom-left corner). |
| `CURSOR_SHAPE_RESIZE_NWSE` | 7 | Resize along the falling diagonal (top-left or bottom-right corner). |
| `CURSOR_SHAPE_WAIT` | 8 | Busy; input is not accepted. |
| `CURSOR_SHAPE_PROGRESS` | 9 | Working in the background; input is still accepted. |
| `CURSOR_SHAPE_NOT_ALLOWED` | 10 | The action is not permitted here. |
| `CURSOR_SHAPE_CROSSHAIR` | 11 | Precise selection. |
| `CURSOR_SHAPE_GRAB` | 12 | Open hand over something draggable. |
| `CURSOR_SHAPE_GRABBING` | 13 | Closed hand while dragging. |
| `CURSOR_SHAPE_MOVE` | 14 | Move in any direction. |

### CursorShapeSource

How a cursor shape was determined.

| Value | # | Description |
| --- | --- | --- |
| `CURSOR_SHAPE_SOURCE_UNSPECIFIED` | 0 | Not reported. |
| `CURSOR_SHAPE_SOURCE_HIT_TEST` | 1 | Accessibility hit-test at the participant's position (role of the element under the point, window edges). Never moves the guest pointer. |
| `CURSOR_SHAPE_SOURCE_SYSTEM` | 2 | The guest's real cursor, read while this participant's input is what positioned the pointer. |
| `CURSOR_SHAPE_SOURCE_PROBE` | 3 | The guest's real cursor, read by briefly moving the idle pointer to the participant's position and restoring it (see `PresenceSettings`). |

### LeaveReason

Why a participant left.

| Value | # | Description |
| --- | --- | --- |
| `LEAVE_REASON_UNSPECIFIED` | 0 | Not reported. |
| `LEAVE_REASON_LEFT` | 1 | It called `Leave`. |
| `LEAVE_REASON_DISCONNECTED` | 2 | Its `Join` stream ended. |
| `LEAVE_REASON_TIMEOUT` | 3 | No activity within the server's timeout (agents without a stream). |
| `LEAVE_REASON_RUN_ENDED` | 4 | The agent run or driver session that owned the cursor ended. |
