# Cloud logos

The vendors' own marks, byte for byte as they publish them (only the file names
are prefixed with the vendor). They draw the clouds in Computers and in
"Connect a cloud" (`src/components/cloud-logo.tsx`). Downloaded on 2026-10-24.

| `azure-logo_azure.svg` | Microsoft Azure | https://learn.microsoft.com/en-us/media/logos/logo_azure.svg |
| `hetzner-apple-icon-180x180.png` | Hetzner (the H mark) | https://www.hetzner.com/_resources/themes/hetzner/images/favicons/apple-icon-180x180.png |
| `modal-favicon.svg` | Modal | https://modal.com/assets/favicon.svg |

The logos belong to their owners (Amazon Web Services, Google, Microsoft,
Hetzner Online, Modal Labs) and are shown only to name the cloud they stand
for. Replace a file with the vendor's current one; never redraw or recolor it.
