`cua.local()` checks and sets up the local runtimes and moves images in and out of the local engines.

Python programs usually use the high-level API instead: [`cua_sandbox` runtimes](/cua-sdk/reference/python/runtimes).

## `Local`

Local runtimes and images.

Returned by [`Cua.local`](/cua-sdk/reference/cua#cua).

| Method | Description |
| --- | --- |
| [`build_image`](#localbuild_image) | Builds an image from an `images.cua.ai/v1alpha1` Image resource (JSON) on `base`; pushes to `push` when set. |
| [`doctor`](#localdoctor) | Inspects local runtimes (read-only: never installs or starts anything). |
| [`pull_image`](#localpull_image) | Pulls an image (container engine for container refs, the image cache for `vm:` containerDisks). |
| [`push_image`](#localpush_image) | Copies an image (host architecture) to `destination`; returns the pushed manifest digest. |
| [`setup`](#localsetup) | Provisions `components` (`qemu`, `lume`; `runsc` reports its plan). |
| [`storage`](#localstorage) | Free space where local Spaces are written (Lume's VM storage, the cua home for QEMU, the container engine's data disk) and which catalog images are already pulled. |

## `DoctorReport` record

Doctor output.

Returned by [`Local.doctor`](#localdoctor).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `checks` | [`Vec<RuntimeCheck>`](#runtimecheck-record) |  | One check per backend. |
| `report_json` / `reportJson` | `String` |  | The full cua-vmm host report as JSON. |

## `LocalImage` record

A local image.

Returned by [`Local.pull_image`](#localpull_image).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `reference` | `String` |  | Reference. |
| `kind` | `String` |  | `container` or `vm`. |
| `location` | `String` |  | Disk path (VM) or engine image reference (container). |
| `size_bytes` / `sizeBytes` | `u64` |  | Size in bytes, when known. |

## `LocalStorage` record

What local Spaces have room for (see `Local.storage`).

Returned by [`Local.storage`](#localstorage).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `host_arch` / `hostArch` | `String` |  | This host's architecture (`arm64`, `amd64`). |
| `reserve_bytes` / `reserveBytes` | `u64` |  | Bytes cua keeps free on a volume: a create that would leave less fails (`CUA_DISK_MIN_FREE`, default 5 GiB). |
| `lume` | [`Option<StorageVolume>`](#storagevolume-record) |  | Where Lume writes macOS VMs. |
| `qemu` | [`Option<StorageVolume>`](#storagevolume-record) |  | Where QEMU writes VM disks and the containerDisk cache. |
| `container` | [`Option<StorageVolume>`](#storagevolume-record) |  | The container engine's data disk (Colima, Docker Desktop, OrbStack, `/var/lib/docker`), when its free space can be read. |
| `pulled` | `Vec<String>` |  | Catalog image refs already pulled here at their published digest. |

## `StorageVolume` record

Space on the volume a local engine writes to.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `available_bytes` / `availableBytes` | `u64` |  | Bytes available to this user. |
| `total_bytes` / `totalBytes` | `u64` |  | Volume size in bytes. |
| `name` | `String` |  | What a person calls it: `Macintosh HD`, `Colima`, `Docker Desktop`. |
