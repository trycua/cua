## `Screenshot` record

A captured screenshot.

Returned by [`Sandbox.guest_screenshot`](/cua-sdk/reference/sandbox/without-spacesd#sandboxguest_screenshot), [`Space.screenshot`](/cua-sdk/reference/spaces/space#spacescreenshot), [`SpacesdClient.screenshot`](#spacesdclientscreenshot).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `image` | `Vec<u8>` |  | Encoded image. |
| `format` | [`ImageFormat`](#imageformat-enum) |  | Encoding. |
| `width` | `u32` |  | Pixel width. |
| `height` | `u32` |  | Pixel height. |
| `scale` | `f64` |  | Image pixels per logical point. |
| `screenshot_id` / `screenshotId` | `String` |  | Id for screenshot-space input. |

## `ScreenshotOptions` record

Screenshot options.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `display` | `Option<String>` | `None` | Display id (primary when unset). |
| `format` | [`Option<ImageFormat>`](#imageformat-enum) | `None` | Encoding (PNG when unset). |
| `quality` | `Option<u32>` | `None` | Lossy quality 1–100. |
| `max_dimension` / `maxDimension` | `Option<u32>` | `None` | Long-edge cap in pixels. |
| `include_cursor` / `includeCursor` | `bool` | `false` | Draw the cursor. |
