import asyncio

async def main():
    guest = await cua.embedded().spacesd(URL, TOKEN)
    proc = await guest.spawn(cua.SpacesdCommand(program="cat", args=[], stdin=True))

## `SpacesdProcess`

A guest process, from `spawn` or `attach`.

Returned by [`SpacesdClient.attach`](#spacesdclientattach), [`SpacesdClient.spawn`](#spacesdclientspawn).

| Method | Description |
| --- | --- |
| [`close_stdin`](#spacesdprocessclose_stdin) | Closes stdin. |
| [`detach`](#spacesdprocessdetach) | Stops receiving output without affecting the process. |
| [`kill`](#spacesdprocesskill) | SIGKILL. |
| [`next_event`](#spacesdprocessnext_event) | Next output chunk or the exit; `None` after the exit was returned. |
| [`resize`](#spacesdprocessresize) | Resizes the PTY. |
| [`signal`](#spacesdprocesssignal) | Sends a signal by name (`term`, `kill`, `SIGINT`, ...). |
| [`wait`](#spacesdprocesswait) | Collects the remaining output until exit. |
| [`write_pty`](#spacesdprocesswrite_pty) | Writes PTY keystrokes. |
| [`write_stdin`](#spacesdprocesswrite_stdin) | Writes stdin (PTY input for PTY processes), exactly once across retries. |

| Accessor | Returns | Description |
| --- | --- | --- |
| `pid()` | `u32` | Guest pid. |
| `tag()` | `Option<String>` | Tag, when set. |

## `ProcessOutput` record

Collected output of a finished process.

Returned by [`Sandbox.guest_sh`](/cua-sdk/reference/sandbox/without-spacesd#sandboxguest_sh), [`SpacesdClient.run`](#spacesdclientrun), [`SpacesdClient.sh`](#spacesdclientsh), [`SpacesdProcess.wait`](#spacesdprocesswait).

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `exit` | [`ExitInfo`](#exitinfo-record) |  | Exit. |
| `stdout` | `Vec<u8>` |  | stdout bytes. |
| `stderr` | `Vec<u8>` |  | stderr bytes. |
| `pty` | `Vec<u8>` |  | PTY bytes. |

## `ExitInfo` record

How a process ended.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `code` | `Option<i32>` |  | Exit code for a normal exit. |
| `signal` | `Option<String>` |  | Terminating signal (`kill`, `term`, ...). |
| `timed_out` / `timedOut` | `bool` |  | Stopped by its timeout. |
| `error` | `Option<String>` |  | Supervisor error (for example "executable not found"). |
| `success` | `bool` |  | `code == 0`. |

## `ProcessEvent` record

| Field | Type | Default | Description |
